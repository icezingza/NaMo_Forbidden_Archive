เรื่องเสียวแนวครอบครัว เย็ดเมียลูกชายตอดควยสุดๆ ผมมีลูกชายคนเดียวอายุ 18 ปี หนังสือหนังหาไม่เรียนวันๆ เที่ยวเล่นสนุกสนานไปเรื่อยบ่อยครั้งที่มัน ไปมีเรื่องมีราวมา ผมก็ต้องตามเคลียร์ให้ตลอด อย่างว่าตามใจมันมาแต่เล็กแต่น้อยเงินทองก็ไม่ใช่ ปัญหา มีใช้จ่ายไม่ขาดมือ ต่อมามันพาผู้หญิงคนหนึ่งเข้าบ้านรุ่นราวคราวเดียวกัน ชื่อใบหม่อน หน้าตา จิ้มลิ้มแบบวัยรุ่นตัวเล็กกระทัดรับอกว่าเป็นเมียมัน ผมก็ต้องตามไปเคลียร์กับพ่อแม่ฝ่ายหญิง เพื่อไม่ให้ เอาเรื่องโดยยอมเสียค่าขอขมาก็พอ เพราะผมมั่นใจว่ามันคงอยู่กันไม่ยืดแน่ ตอนแรกเจ้าลูกชายผม มันก็อยู่ติดบ้านอยู่หรอกแม้จะขลุกอยู่กับเมียมันมากกว่าจะมาช่วยงานผม แต่ก็ยังดีที่ไม่ไปหาเรื่องหาราวมาให้ผมตามล้างตามเช็ด แต่ไม่นานมันก็ออกลายเข้าอีหรอบเดิม หา เที่ยวกินเหล้ากินยากับเพื่อนๆจนไม่กลับบ้าน บางครั้งเป็นอาทิตย์ก็มี ต้องปล่อยให้ใบหม่อนเมียของมัน อยู่บ้านกับผมตามลำพัง เมื่อลูกชายไม่อยู่ผมก็ต้องมาดูแลใบหม่อนเพิ่มขึ้น และสังเกตุใบหม่อนว่าซึมๆ ไป ก็แน่ละผัวไม่ค่อยมาดูแล มีแต่พ่อผัว ซึ่งก็ไม่สนิทใจนัก อีกทั้งพ่อแม่ใบหม่อนก็ย้งโกรธเธออยู่ จึง ไม่สามารถกลับบ้านได้ ผมก็จะคอยบอกใบหม่อนให้ออกไปเที่ยวเปิดหูเปิดตาบ้าง โดยเงินทองก็ยื่นให้ ใช้จ่ายตลอด พักหลังดูใบหม่อนสดชื่นยิ้มหัวดี อาทิตย์นึงก็จะมีเพื่อนมารับไปเที่ยวสัก 2-3 ครั้งการ แต่งตัวก็ประมาณวัยรุ่นเสื้อรัดรูปกางเกงขาสั้น ใบหม่อนเป็นคนผิวสีคล้ำหน่อยๆ แต่ที่เด่นจริงๆ คือ หน้าอกเธอใหญ่เกินตัวเวลาใส่เสื้อรัดรูปแล้วมันชูขันเห็นได้ชัด จนผมต้องแอบกลืนน้ำลาย แต่ก็ยังคิด ว่าใบหม่อนเป็นลูกสะใภ้ ไม่คิดอะไรเกินนั้น ต่อมาวันนึงด้วยอารมณ์เปลี่ยวที่อยู่คนเดียว ขณะอาบน้ำ ตอนเย็น ผมก็กระถอกกระดออย่างเมามันส์ ตาผมเหลือบไปเห็นที่ประตูห้องน้ำ เห็นใบหม่อนเธอนุ่ง ผ้าขนหนูกระโจมอกจะมาอาบน้ำเช่นกัน ไอ้ผมก็ว่าล็อคลูกบิดห้องน้ำดีแล้วนา!! สายตาของใบหม่อนมองที่ควยผมไม่วางตา ผมตกใจหยุดปฎิบัติการ เสียงใบหม่อนร้องอู๊บเบาๆ ที่เห็นผมมองเธอ ใบหม่อนรีบขอโทษผมก่อนจะงับประตู ด้วยความรู้สึก ใดๆไม่ทราบครอบงำผม ผมนุ่งผ้าเช็ดตัวออกจากห้องน้ำ เห็นหลังใบหม่อนไวๆ ผมตามใบหม่อนไปที่ ห้องนอนเคาะประตูเรียกเธอ ประตูเปิดเห็นใบหม่อนในชุดเดิมแต่มีผ้าคุมไหล่อีกชั้นนึง “พ่อคะใบ หม่อนขอโทษค่ะที่เปิดประตูเข้าไปเห็นว่าไม่ได้ล็อคคิดว่าไม่มีใคร” ใบหม่อนละลำละลักขอโทษผม “พ่อไม่ว่าหรอก พ่อเองที่ผิดคิดว่าล็อคประตูดีแล้วพ่อต้องขอโทษใบหม่อนด้วยที่ทำสิ่งนั้นให้ใบหม่อนเห็น “ผมพูดกับเธออย่างนั้น “พ่อไม่ผิดหรอกค่ะ พ่ออยู่คนเดียว เอ่อ…พ่อคงจะเหงาน่าดู” “ก็มีบ้างก็ไม่มี คนดูแลนี่”ผมจ้องมองในตาหวาน เธอหลบดูอายๆ” หรือว่าใบหม่อนจะเป็นคนดูแลพ่อ หือ…” ใบหม่อน หันมาสบตาผม ผมมองเห็นความเร่าร้อนในตาเธอ ไม่รอช้าผมช้อนเธอเข้ามาจูบ ใบหม่อนขัดขืน เล็กน้อย แต่เมื่อลิ้นของผมสอดตวัดเข้าปากเธอ ใบหม่อนก็อ่อนแรงมือที่ขัดขืนก็เป็นโอบกอดผมและ เล่นลิ้นกับผมเป็นพัลวัน ผมอุ้มร่างเล็กๆ ของใบหม่อนไปที่เตียงนอนของเธอ อารมณ์ที่ร้อนเร่าผม กระตุกผ้าขนหนูออกจากตัวใบหม่อนเผยเห็นนมอันเต่งตึงของวัยสาวน่าเฟ้นฟอน ผมก้มหน้าลงบนอก ของใบหม่อน ลงลิ้นรอบปทุมถันเสียงของใบหม่อนครางไม่ได้ศัพท์ “อืม…พ่อขา เสียวววว………อูยยย ……” ผมเล่นนมเธอจนหนำใจแล้วก็เลื่อนลงต่ำสู่ร่องเสียว รูปร่างเธอกระทัดรัดรูปหีเธอจึงไม่ใหญ่โต อะไรก็สมส่วนดี ผมอ้าขาใบหม่อนออกกว้างแล้วลากลิ้นอย่างเมามันส์ “พ่อขา อูยยยยย….ซี๊ดดดด …..เสียวจังงงงงง…ซี๊ดดดดดดด….” ใบหม่อนบิดตัวเร่าๆ มือเธอจิกศีรษะผมเกร็งแล้วกระตุก เฮือกกรีดร้อง ” กรี๊ดดดดดด…เสร็จแล้วววววววว…ซี๊ด…..” ผมปล่อยให้ใบหม่อนนอนพักเอาแรง ครู่นึงก่อนจะจูบปากเธอเพื่อเริ่มเร้าอารมณ์ใหม่อีกครั้ง ซึ่งเธอก็ยอมรับแต่โดยดี ผมค่อยๆประคอง เจ้า 6*6 นิ้วของผมเข้าร่องสวาทของใบหม่อน เธอตาลุกวาว “พ่อขา เบาๆ หน่อยค่ะ มันใหญ่กว่า ของผัวใบหม่อนมากเลย” ผมค่อยๆ ขับเข้าออกเบาๆ เสียงใบหม่อนร้องอือๆ เบา “มันเสียวมากค่ะ พ่อขา….ขนาดยังเข้าไม่หมดยังเสียวขนาดนี้ อูยยย…ถ้าเข้าหมดจะขนาดไหน ซี๊ดดดดดดดดด” เดี๋ยวก็ รู้อีหนูผมดันควยเข้าไปช้าๆ มันเข้าได้ครึ่งนึงแล้ว “อูยยย…ใบหม่อนเอ๊ย หีใบหม่อนนี่มันตอดรัดควยพ่อตุบๆ หีของใบหม่อนนี่มันดีจริงๆ เลยซี๊ดดด” “ถ้าหีใบหม่อนดีจริง ก็กระแทกมาเลยคะ อ๊ายยยยย….ใบหม่อนรับได้” ผมเริ่มสาวควยเข้าออกแรงขึ้นจนเข้าร่องหีของใบหม่อนมิดด้าม ใบหม่อนเธอก็สู้ไม่ถอยรับแรงกระแทกของผมได้ไม่หวั่น “อือ…ซี๊ดดดด พ่อขาควยใหญ่พ่อเย็ดมันส์มา กกกกกกกก…ซี๊ดดด” หีใบหม่อนก็เย็ดมันเหมือนกัน อูยยยยยย…ตอดควยพ่อตุบๆ” ผมจับขาของใบหม่อน พาดบ่ากระแทกผ้บๆ สักพักใบหม่อนก็เกร็งร่างหวีดร้องอย่างสุขสม “อ๊ายยยย……ออกแล้ววววววววว” เหงื่อกาฬของผมแตกพลักผสมเหงื่อของใบหม่อนเป็นกลิ่นแปลกใหม่สำหรับผม ผมจับใบหม่อนคลุกเข่า คลาน น้ำเงี่นใบหม่อนเต็มหว่างขา มันทำให้ผมสอดใส่ควยได้ง่ายขึ้น ผมดันเข้าสุดแล้วซอยผับๆ อย่างเมามันส์ “ซี๊ดดดด…เสียวววววววว…อูยยยยย…อ๊ายยยยยย” “ใบหม่อนจ๋า….พ่อมีความสุขมากกก ….” “ใบหม่อนก็มีความสุขมากกกกกกกก สุขสุดๆ ซี๊ดดดดดด” ท่าด๊อกกิ้งทำให้ผมเสียวสุดๆ และ สามารถสาวควยได้ลึกอีกทั้งมีสะโพกงามๆ มารองรับการกระแทกอีก ทำให้ผมกระแทกควยสุดชีวิต “อูย..ใบหม่อนจ๋า…พ่อจะออกแล้ววววววววว” “ใบหม่อนก็เหมือนกันซี๊ดด…ออกมาเลยค่ะพ่อ ออกมา ในหีใบหม่อนเลย ใบหม่อนต้องการน้ำจากควยใหญ่ๆ ดดดดด..” ผมสาวควยออกจนสุดแล้วกระแทก เข้าไปสุดแรงเกิด “โอ๊ยยยย…ใบหม่อนจ๋า…พ่อเสร็จแล้วววววววววววว…ซี๊ดดดด” “ซี๊ดดด…ใบหม่อนก็ เหมือนกันนนนนนนนนนน..อ๊ายยย…” ผมพ่นน้ำเข้าร่องหีของใบหม่อนอย่างรุนแรงมันรีดออกมา มากมายกว่าทุกครั้ง หีของใบหม่อนตอดรัดแท่งของผมตุบๆ ผมฟุบลงบนหลังของใบหม่อนอย่าง เหนื่อยอ่อนแต่ก็สุขสม เสียงลมหายใจของใบหม่อนหอบเฮือกๆ ผมพรมจูบเธอเบา ใบหม่อนยิ้มให้ ผม กับเธอนอนก่ายกกกันทั้งคืนผมเล่นเธอไป 4 ดอกจนลืมอายุของตัวเอง แหมก็ของหวานเธอดีจริง ทั้งรัดทั้งตอดสุดยอดหี ใบหม่อนสารภาพว่าเห็นผมชักว่าวอยู่ในห้องน้ำและเห็นควยของผมมันใหญ่กว่า
