แม่มาก ผมมีเพื่อนสนิท คนหนึ่งชื่อไอ้กอล์ฟ มันเล่าว่ามันแอบดูแม่มันประจำ มันชอบมาที่บ้านผม แล้วชอบมองแม่ผม บอกว่าแม่ ผมน่าเย็ดมาก มันพูดทีไรผมควยแข็งทุกที และก็เลยหาวิธีแอบดูแม่ จนกระทั่งได้เห็นแม่แก้ผ้า หีแม่ ใหญ่มาก นมก็ใหญ่ อวบแต่ไม่อ้วน ขาว พ่อผมรับราชการอยู่ต่างจังหวัดทางอีสาน ปกติแม่ผมจะหวงตัวมาก วันนั้นเป็นวันปีใหม่ ไอ้กอล์ฟชวน ผมไปเที่ยวกับมัน บอกว่ามันนัดหญิงมาเย็ด ให้ผมไปสวิงกิ้ง กับมัน มันอวดยานอนหลับแบบปลุกเซ็กส์ด้วย เก็บไว้ในรถ ผมตื่นเต้นมาก แต่ขอมันกลับไปบอกแม่ที่บ้านก่อน ไอ้กอล์ฟใจร้อนก็เลยขับรถมาที่บ้านผม แต่พอมาถึงบ้านก็เห็นแม่ร้องไห้โฮๆ แม่เพิ่งกลับจากที่ทำงาน นุ่งกระโปรงสั้นมาก ผมตกใจ ถามว่าแม่เป็นอะไร แม่บอกว่าป้าที่ต่างจังหวัดเพิ่งโทรมาบอกว่าพ่อมีเมียน้อย แม่เสียใจที่ไม่เคยคิดนอกใจพ่อเลย แม่อยากจะไปดูให้เห็นกับตา อาการของแม่ทำให้ไอ้กอล์ฟตัดสินใจว่าให้ผมขับรถพาแม่ไป แผนการวัน นี้เป็นอันล้มเลิก ผมออกจากกรุงเทพราว 5 โมงเย็น กะว่าไปถึงขอนแก่นก็ราว 4 ทุ่ม แต่ระหว่าง ทางแม่ก็เสียใจร้องไห้จนหลับไป ผมเห็นแม่มีไข้ขึ้นก็เลยหาซื้อยาแก้แพ้กับยาแก้หวัดให้แม่กินด้วย ปรับเบาะให้เอนลง ทำให้กระโปรงแม่เลิกขึ้นมา ขาอ่อนขาวมาก แม่หลับไม่รู้เรื่องเลย แต่พอไปถึง ในตัวจังหวัดเราถึงได้รู้ว่าเขามีงานกัน โรงแรมที่คิดว่าจะพักก่อนถูกจองหมด แม่ตื่นขึ้นมาพอดี ผม ถามว่าจะเอายังไง แม่บอกว่าให้หาที่พักในเมืองก่อน เพราะอำเภอที่พ่ออยู่ต้องออกไปอีกไกล แต่ เราก็หาโรงแรมไม่ได้ จนเห็นข้างทางเขียนว่ารีสอร์ท ก็สร้างเป็นกระท่อมเป็นหลังๆ นะครับ ผมเห็นก็รู้ว่าน่าจะเป็นโรงแรมให้คนมาเย็ดกันมากกว่า แต่แม่ก็ยืนยันว่าอยากอาบน้ำและอยากนอนให้ เร็วที่สุด ผมบอกว่าน่าจะเป็นม่านรูด แม่บอกว่าเราแม่ลูกกันไม่เป็นไรหรอก พอไปถึง แม่ก็ขอตัวเข้า ห้องน้ำก่อน นึกถึงยาที่ไอ้กอล์ฟให้มาได้ ก็เลยอยากลองดู แต่ยังไม่กล้าหรอกครับ กลัวว่าเกิดยา ออกฤทธ์ขึ้นมาจะทำยังไง ระหว่างที่แม่ยังอยู่ในห้องน้ำ ผมก็ลองเปิดทีวีแต่ไม่เปิดเสียงนะครับ ปรากฏว่ามีหนังเอ็กซ์ด้วย ก็รีบปิด เพราะตอนนี้ควยแข็งจนปวดไปหมด พอแม่ออกมา ผมเปลี่ยนเป็นช่องอื่นแล้ว และก็เปิดเสียงดัง ทำเป็นว่าดูรายการปกติ แม่บอกว่าไม่มี เสื้อผ้าเปลี่ยนเลย ผมบอกว่ามีเสื้อผ้าไอ้กอล์ฟ แต่เป็นบ๊อกเซอร์กับเสื้อยืด มีหลายตัว แม่ก็บอกว่าดี กว่าใส่ชุดนี้ตอนนั้นผมหยิบเสื้อผ้าออกจากรถ ก็เลยแอบหยิบขวดยาเล็กๆ ใส่กระเป๋ามาด้วย ไม่ลืม หยิบน้ำดื่มที่มีติดอยู่ในรถมาพร้อมสรรพ ผมบอกว่าจะอาบน้ำก่อน ก็เข้าไปอาบ สำรวจดูที่ประตู เห็น ตรงขอบๆ มีรอยแตกอยู่ ก็มองออกไป (กระท่อมแคบ ๆ มีห้องน้ำด้านหนึ่ง ตรงกับเตียงนอนพอดี) เห็นแม่นอนอยู่แล้วสักพักก็ลุกขึ้นถอดเสื้อผ้า เอากางเกงไอ้กอล์ฟใส่ ไม่น่าเชื่อว่าผมจะได้เห็นหีแม่ ชัดเจนอย่างนี้ ผมจัดการชักว่าว ให้อารมณ์ พลุ่งพล่านหายไป ตอนนี้เสียงทีวีหายไป ตอนแรกคิดว่าแม่คงปิดทีวี แต่ก็อดคิดไม่ได้ว่าแม่อาจจะเจอ หนังโป๊ก็ได้ ผมรีบอาบเสร็จก็ออกมา แม่เปลี่ยนเป็นนุ่งกางเกงขาสั้น เรียบร้อย กระโปรงแม่ถอดไว้ เห็นกางเกงในสอดไว้แต่ปิดไม่มิด ใจผมเต้นแรงมาก นึกถึงตอนแอบเอามาพันควยแล้วชักว่าวไม่ได้ แม่บอกว่าแม่จะอาบบ้าง ก็เอาผ้าเช็ดตัวเข้าไปในห้องน้ำ ทันทีที่ได้ยินเสียงน้ำ ผมก็รีบแอบดูแม่แก้ผ้า อาบน้ำทันทีครับ ที่สำคัญผมเห็นแม่ช่วยตัวเองด้วย หน้าตาเหยเกเลยครับ ผมตัดสินใจแล้วว่าเป็นไงก็เป็นกัน ก็เลยรินน้ำใส่แก้วหยดยาไปหนึ่งหยด แล้วทำเป็นนอนหันหลังให้ เหมือนเหนื่อยมาก แต่หนังที่เปิดไม่ได้ยินเสียงครับ เป็นหนังเอ็กซ์แม่ออกมา คงยืนมองทีวีอยู่ ก็บ่นว่า ไม่ยอมปิดทีวีจะหลับก็หลับเลย แล้วเสียงแม่เดินไปกินน้ำที่ผมรินไว้ให้ ปิดไฟ แต่แม่ก็ไม่ยอมปิดทีวีนะ ครับ เสียงลมหายใจฟืดฟาดดังมา ผมแกล้งพลิกตัวแม่รีบกดรีโมทปิดทีวี คราวนี้มืดไปเลย สักพัก แม่ก็ดิ้นเหมือนคนนอนไม่หลับ ผมหรี่ตาดู เห็นแม่ล้วงไปในกางเกง บิดตัว แล้วพลิกตัวมานอน เบียดผม ผมทำเป็นไม่รู้เรื่องก็กอดแม่ ทีนี่เรากอดกันแน่นเลย ที่สำคัญแม่จับควยผมที่กำลังแข็งเต็มที่ ชักเข้าชักออก ผมเสียวจนสุดตัว “แม่เงี่ยนเหรอ” “เป็นอะไรไม่รู้นนท์” “ให้ผมช่วยมั้ย” แม่ไม่ตอบ แต่ซุกหน้าลงกับซอกคอผม ตัวสั่นสะท้านผมจัดการดูดนมแม่ ไม่อยากเชื่อว่าบทจะง่ายก็ง่ายอย่างนี้ ผมเลื่อนตัวไปข้างล่าง หีแม่หอมและใหญ่มาก หมอยไม่ค่อยมี ผมจัดการผลักแม่นอนหงายแล้วซุกหน้า ลงไปที่หี เลียน้ำหีที่ทะลักออกมานอง แม่ดิ้นส่ายตัวแทบคลั่ง “เย็ดแม่.. เย็ดแม่เถอะนนท์” แม่บอก อย่างนี้ ผมจะรอช้าหรือครับ
