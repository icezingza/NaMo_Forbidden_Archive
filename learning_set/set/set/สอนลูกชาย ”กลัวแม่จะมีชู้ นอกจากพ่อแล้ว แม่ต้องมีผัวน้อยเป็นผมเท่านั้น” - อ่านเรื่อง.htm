น้านีพูดสั่นๆ”ภายในสามสิบนาทีต้องมาถึง ถ้ารู้ว่าแวะที่อื่น ผมจะโทรหาพ่อผมให้คนตามห่างๆด้วย อย่าลองดี ไม่งั้นเละแน่”เพื่อนผมโทรมารายงานว่า แม่ น้านี กะไอ้นั่น แยกตัวออกมาก่อนไอ้นั่นเป็นคนขับ ผมเผ้ากระเซิง แต่ก็ดูเซ็กซี่ แม่สุของผมนี่มัน น่า…..นักแม่โซซัดโซเซประคองตัวไปอาบน้ำ สภาพเมาหนักที่ประตูห้องน้ำผมแอบเอาเศษผ้าไปขัดไว้ไม่ให้ปิดประตูได้ง่าย ตอนแม่เข้าไปอาบน้ำ ด้วยความเมาแม่ปิดประตู
