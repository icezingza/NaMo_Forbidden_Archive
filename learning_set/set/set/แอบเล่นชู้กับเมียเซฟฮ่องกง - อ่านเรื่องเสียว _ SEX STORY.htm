ผมเองรับงานมาทำที่บ้าน เกี่ยวกับบัญชีและภาษี เลยมีเวลาอยู่บ้าน หลายครั้งที่ผมเจอเจ๊หยู ออกมาเดินข้างล่าง หรือบางทีก็ลงมาว่ายน้ำที่สระ ผมเองแอบลอบมอง จน บางทีเจ๊หยูแกก็จับสายตาผมได้ ดูแกจะยิ้มๆ มีอะไรบ้างบอกไม่ถูก สองสาม อย่าง ดูน่ากิน เจ๊หยูบอกผมว่าให้ผมนั่งทานไป แกจะขอตัวไปอาบน้ำ ผมมองดูรูปร่างเจ๊หยู อย่างไม่มีมรรยาท ซึ่ง เจ๊หยูเองก็ดูเหมือนจะรู้ว่า ผมมองแกในลักษณะใด สายตาเจ๊หยูที่ผมเห็น เหมือนกับจะท้าทายนิดๆ เมื่อเดินเข้าห้องน้ำไป ไม่รู้ว่าผมคิดไปเองหรือเปล่า ผมนั่งทานอาหารไปอย่างเอร็ดอร่อย เจ๊หยู เดินออกมาจากห้องน้ำมีผ้าเช็ดตัวผืนเดียว และอีกผืนคลุมหัว ผมยังมองแกอยู่ไม่วางตา เจ๊หยูทำเอา ผมสะดุ้ง เมื่อแกบอกกับผมว่า “เห็นคุณกมลมองเจ๊บ่อยๆ เจ๊มีอะไรที่คุณกมลอยากมองเหรอ” (ผมแปลได้ความว่าอย่างนี้ การ สนทนาเป็นภาษาอังกฤษโดยตลอด) “เอ่อ ผม.. ก็เห็นเจ๊หยู… สวยจัง…” แต่ยังไม่กล้า จนกระทั่ง เจ๊หยูมายืนคร่อมขาของผมเอาไว้ นั่นหละผมถึงได้ ค่อยๆ แกะผ้าเช็ดตัวของแกออก อูววววววววววว…… พระเจ้าช่วย… หน้าอกของเจ๊หยูชูชันไปข้าง หน้า ผมเองไม่คิดทำอย่างอื่นนอกจากจับนมทั้งสองข้างของแกเอาไว้ แล้วดูดเลียสลับ กันไปมา หัวหน่าวเจ๊หยูปรกคลุมไปด้วยไหมสีดำ แต่ก็เพียงหยิบมือ หาได้ดกรกอย่างที่คิดไว้ เจ๊หยูเองก็เก็บอาการไว้ไม่อยู่ เมื่อผมเอานิ้วค่อยๆ ไล้ไปตามร่องสวาท ของแก สักพักน้ำหี เหนียวๆ ก็ซึมๆ ออกมา ผมค่อยๆ พาเจ๊เดินไปที่โซฟาช้าๆ เจ๊หยูนอนลงบนโซฟา ขาสองข้างค่อยอ้าออก ด้วยมือของผมที่ดันเอาไว้ ร่องหี สีแดงคล้ำตัดกับผิวขาวอมชมพู น้ำเหนียวๆ ใสๆ ซึมเปรอะไปทั่ว ผมก้มลงตวัดลิ้น ลากเลียไปทั่วร่องสวาทและกลีบเนื้อด้านใน เจ๊หยูครางครวญอย่างไม่เก็บอารมณ์ ดีที่กลางวันไม่มีใครอยู่เท่าไหร่ และห้องก็เปิดแอร์เย็นสบาย กลิ่นหอมของร่องสวาทเจ๊หยู ยั่วยวนให้ผมดูดเลียอย่างเมามัน ติ่งสวาทของแกเมื่อโดนลิ้นสัมผัส มันก็ ชูชันขึ้นมา ผมยิ่งเลียเร็วแรงเท่าไหร่ เจ๊หยูดูจะมีความสุขมากเท่านั้น ท่อนสวาทของผมมันชี้ไปข้างหน้า เจ๊หยูมองท่อนควย ของผมแล้วมองหน้า ทำตาเยิ้มเชื่อมกับผม จากนั้นเจ๊หยูค่อยๆ เอามือลูบคลำและเอาปากดูดของผมช้าๆ ผมเองก็เป็นครั้งแรก
