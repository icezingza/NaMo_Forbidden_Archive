เรื่องเสียวแนว ครอบครัว เปลวไฟลับในคอนโดใจกลางเมือง ผมชื่อธันวา อายุ 22 ปี เพิ่งย้ายมาอยู่กับพี่สาว—มิรา อายุ 27 ปี—ในคอนโดหรูใจกลางกรุงเทพฯ หลังจากได้งานใหม่ มิราเป็นสาวสวย ผมยาวสีน้ำตาลเข้ม หุ่นเป๊ะเหมือนนางแบบ หน้าตาคมเข้ม แถมยังมีเสน่ห์ที่ทำให้ผู้ชายทุกคนต้องเหลียวมอง แต่สำหรับผม เธอคือพี่สาวที่ทั้งเข้มงวดและแสนดีมา ตลอด... จนกระทั่งคืนหนึ่งที่ทุกอย่างเปลี่ยนไป คอนโดของมิราอยู่ชั้นสูง มองเห็นแสงสีของเมืองยามค่ำคืน ห้องกว้างขวาง ตกแต่งทันสมัย มีกลิ่น อายของความหรูหรา แต่ในความเงียบสงบนั้น ผมเริ่มสัมผัสได้ถึงความตึงเครียดบางอย่างระหว่าง เรา มิราเพิ่งเลิกกับแฟน เธอดูเหงาและอ่อนไหวมากขึ้น ส่วนผม... ผมเริ่มมองเธอในมุมที่ไม่ควร จุดเริ่มต้นของความลับต้องห้าม คืนวันศุกร์ มิรานั่งอยู่บนโซฟาหน้าทีวี สวมชุดนอนสายเดี่ยวสีดำที่บางจนเห็นส่วนเว้าส่วนโค้ง เธอ กำลังจิบไวน์แดง ผมเดินออกจากห้องนอนหลังอาบน้ำ สวมแค่กางเกงขาสั้น “มานั่งด้วยกันสิ ธัน” เธอเรียก เสียงนุ่มนวลแต่แฝงด้วยอะไรที่ทำให้ใจผมเต้นแรง ผมนั่งลงข้างๆ เธอ กลิ่นน้ำหอมหวานๆ จากตัวเธอโชยมา ผมพยายามจ้องจอทีวี แต่สายตากลับ เลื่อนไปที่ขาอ่อนเรียวยาวของเธอ “พี่ดูเหงาๆ นะ” ผมพูดโดยไม่รู้ตัว มิราหันมามอง แววตาคู่สวย ของเธอเหมือนมีไฟ “นายก็รู้ทันนะ” เธอยิ้ม มือของเธอแตะที่แขนผมเบาๆ /สัมผัสนั้นมันร้อนเหมือนไฟ/ จูบแรกที่จุดไฟในใจ เราเงียบไปครู่หนึ่ง บรรยากาศเริ่มหนักอึ้ง มิราขยับเข้ามาใกล้จนผมรู้สึกถึงลมหายใจของเธอ “ธัน ... ถ้าพี่ไม่ใช่พี่สาวนาย นายจะมองพี่ยังไง?” คำถามของเธอเหมือนระเบิดในหัวผม ผมกลืน น้ำลาย มองหน้าเธอ “ผม... คงอยากได้พี่เป็นของผม” คำพูดนั้นหลุดออกมาโดยไม่ทันคิด มิรายิ้มเจ้าเล่ห์ แล้วโน้มตัวเข้ามา *จูบ* ของเธอมันร้อนแรง ริมฝีปากนุ่มนวลกดลงบนปากผม ลิ้น ของเธอสอดเข้ามา วนเวียนอย่างช้าๆ แต่เต็มไปด้วยความหิวกระหาย ผมจับไหล่เธอ ดึงเธอเข้า มาแนบชิด มือของผมลูบไปตามแผ่นหลังเรียบเนียน /มันผิด แต่มันหยุดไม่ได้/ เล้าโลมที่เร่าร้อน มิราผลักผมลงนอนบนโซฟา เธอคร่อมตัวผม ชุดนอนเลื่อนขึ้นเผยให้เห็นต้นขาขาวเนียน เธอก้มลงจูบ คอผม ลิ้นของเธอเลียไล่ลงไปจนถึงอก ผมครางออกมาเมื่อเธอดูดที่ผิวหนังอย่างแรง “พี่... โอ้ย” ผมพูด มือจับสะโพกเธอแน่น เธอยิ้ม “ชอบใช่มั้ย?” เสียงของเธอแหบพร่า มือของเธอล้วงลงไปในกางเกงผม สัมผัสที่ *แข็งขึง* ของผม เธอขยับมือช้าๆ จนผมต้องแอ่นตัวรับ “ธัน... ใหญ่จัง” เธอกระซิบ ผมทนไม่ไหว ดึงชุดนอนของเธอออก เผยให้เห็นหน้าอกกลมกลึง ผม ก้มลงดูดเลียที่ยอดอกของเธอ ลิ้นวนเป็นวง ขณะที่มิราครางออกมา มือของเธอกดหัวผมลงแน่น ความดิบที่ปะทุ ผมพลิกตัวให้มิรานอนลงบ้าง ผมถอดกางเกงของตัวเองออก แล้วเลื่อนมือไปสำรวจระหว่างขาของ เธอ /เปียกชุ่ม/ จนผมยิ้มออกมา “พี่... พร้อมขนาดนี้เลย” ผมพูด เธอหน้าแดงแต่ยิ้ม “อย่าพูดมา ก ทำเลย” เธอสั่ง ผมก้มลง *เลีย* ที่จุด敏感ของเธอ ลิ้นของผมขยับเร็วขึ้น ฟังเสียงครางของ เธอที่ดังขึ้นเรื่อยๆ มิราดึงผมขึ้นมา จับผมนอนหงาย แล้วคร่อมผมอีกครั้ง เธอค่อยๆ สอดผมเข้าไปในตัวเธอ /รัดแน่น/ จนผมต้องกัดฟัน เธอเริ่มขยับสะโพก ช้าๆ ก่อนจะเร็วขึ้น ผมจับเอวเธอ ช่วยควบคุมจังหวะ “ธัน ... เสียวจัง” เธอคราง ผมตบก้นเธอแรงๆ เธอร้องออกมาแต่ยิ้ม /เธอชอบ/ จุดสุดยอดที่ระเบิด ผมพลิกมิรานอนคว่ำ จับสะโพกเธอยกขึ้น แล้วสอดใส่จากด้านหลัง *แรงและลึก* ทุกการกระแทกทำ ให้เธอร้องครางดังขึ้น ผมเร่งจังหวะ มือบีบก้นเธอแน่น “มิรา... ผม... จะ...” ผมพูดไม่จบ เธอหันมามอง “ปล่อยมาเลย” เธอสั่ง ผมถึงจุดสุดยอด ปลดปล่อยทุกอย่างในตัวเธอ ขณะที่มิราเอง ก็สั่นสะท้าน ถึงจุดของเธอพร้อมกัน เรานอนกอดกัน หอบหายใจ มิรามองผมด้วยแววตาที่ปนเปไปด้วยความรักและความรู้สึกผิด “นี่คือ ความลับของเรา” เธอกระซิบ ผมพยักหน้า /มันคือเปลวไฟที่เราจะเก็บไว้/ ผลกระทบของความสัมพันธ์ หลังจากคืนนั้น ทุกครั้งที่เราอยู่ด้วยกัน ความปรารถนามันเหมือนจะปะทุขึ้นได้ทุกเมื่อ มิราพยายามทำ ตัวเป็นพี่สาวเหมือนเดิม แต่สายตาของเธอบอกว่าเธอต้องการผมมากกว่านั้น ผมเองก็สับสน—ผมรัก เธอในฐานะพี่สาว แต่ความหิวกระหายนี้มันกลืนกินทุกอย่าง เรารู้ว่าสังคมจะไม่ยอมรับ แต่ในคอนโดนี้ ในโลกส่วนตัวของเรา เราเป็นมากกว่าพี่น้อง ผมเริ่ม กลัววันหนึ่งที่ความลับนี้จะถูกเปิดเผย แต่ตอนนี้ ผมแค่ยอมให้เปลวไฟนี้เผาผลาญตัวเอง อนาคตที่มืดมิด ผมไม่รู้ว่าเราจะไปต่อยังไง มิราบอกว่าเราควรหยุด แต่ทุกครั้งที่เธอแตะตัวผม มันเหมือนทุกอย่าง เริ่มต้นใหม่
