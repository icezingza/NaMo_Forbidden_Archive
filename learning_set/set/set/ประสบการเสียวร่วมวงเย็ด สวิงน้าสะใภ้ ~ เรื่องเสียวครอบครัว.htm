ความที่ผมมีจิตใจฝักใฝ่ไปในทางลามกอยู่เรื่อยๆ ทำให้ถึงขนาดเจาะฝาห้อง นอนของน้าชายและน้าสะใภ้ เป็นรูไว้ถ้ำมองทั้งมีอะไรกัน ซึ่งทุกครั้งน้าทั้งสองจะไม่ค่อยปิดไฟ ภาพ ด้วยเหตุนี้ผมจึงอดคิดลามกกับน้าสะใภ้ไม่ได้ ตลอดเวลาที่อยู่ด้วยกันในบ้าน ผมจะแอบมอง จ้องที่ สะโพกบ้าง บั้นท้ายบ้าง หรือถ้าเผลอๆ ก็เนินสามเหลี่ยมของน้ากันเลย ผมมักเอาลีลาการร่วมรัก ของน้าสะใภ้ที่ทำกับน้าชายมานั่งฝันเสมอ และอดนึกไม่ได้ว่าสักวันต้องเป็นผมบ้างที่จะมาแทนน้าชาย ความใฝ่ฝันนั้นถ้าดูๆ ไปแล้ว ก็รู้สึกจะเป็นไปไม่ได้ แต่ในวันหนึ่งมันก็เป็นไปแล้ว เมื่อผมกำลังนั่งทาน ข้าวอยู่คนเดียว ขณะที่น้าชายนอนอยู่ในห้อง น้าสะใภ้ก็มาโอบหลังโอบไหล่ผมเอาดื้อๆ ทำเอากลืน ข้าวไม่ลงเลยทีเดียว “…น้ารู้นะว่ามีคนแอบดูน้ากับน้าผู้ชายนอนด้วยกัน…” น้าพูดขึ้นมาเบาๆ พอให้ผมได้ยิน ผมถึงกับเกิดอาการชาไปทั่วร่างกายอย่างกระทันหัน ไม่กล้าหันไป สบตากับน้า /“…อย่ากลัวไปเลย น้าไม่ว่าอะไรหรอก เพราะของแบบนี้ใครๆ ก็อยากเห็น แต่น้าสงสารเธอนะสิ ดูอย่างเดียว จะอกแตกตายเสียก่อน…”/ น้าสะใภ้ไม่พูดเปล่าน้ายังใช้มือสอดเข้าไปควานตรงเป้ากางเกงผมด้วย ทำเอาท่อนเอ็นของผมแข็ง ขึงขึ้นมาทันที่ ผมใจหายวาบ นี่น้าสะใภ้กำลังมาแผนไหนกันแน่? แต่ก็ยังหาคำตอบให้ตัวเองไม่ได้ ซิบ กางเกงก็ถูกรูด ดุ้นของผมก็โผล่หัวออกมาสูดอากาศในโลกกว้างอีกหน ขณะที่น้าสะใภ้ก็นั่งคุกเข่าลง กับพื้น แล้วก้มหน้าลงดูดมัน โอย… ตอนนี้ผมรู้สึกเหมือนกำลังขึ้นสวรรค์ทั้งเป็น จิตใจสับสนไม่รู้จะทำอย่างไร นอกจากนั่งตัวเกร็ง แต่ ไม่วายใช้มือไปลูบที่ศีรษะของน้า หลังจากให้น้าสะใภ้ได้ดูดดื่มกับความเปรี้ยวหวานมันเค็มของเอ็นอยู่ พักใหญ่แล้ว ผมก็ทนต่อไม่ไหว ทำท่าจะลุกขึ้นมาคร่อมน้าสะใภ้เสียให้รู้แล้วรู้รอด แต่โธ่เอ๋ยไม่ทันเสีย แล้ว ไอ้ท่อนเอ็นดันกระฉูดออกมาเสียก่อน น้ำรักสาดกระเซ็นไปบนใบหน้าน้าเต็มไปหมด ซึ่งน้าเองก็ ใช้ลิ้นเลียส่วนที่ไหลเยิ้มอยู่แถวริมฝีปาก อย่างกับมันเอร็ดอร่อยนักหนา เมื่อเอ็นคลายพิษสงแล้วอ่อน ตัว ผมก็เข่าอ่อนลงนอนราบกับพื้นห้อง แต่ใจก็อดนึกกลัวน้าชายจะเข้ามาเห็นไม่ได้ ไม่เท่านั้นน้า สะใภ้ยังขึ้นมานอนแนบร่างประกบริมฝีปากกับผมต่ออีก ทำเอาผมแทบหายอ่อนเปลี้ยไปเลย ขณะที่ผมกำลังนอนเอาแรงอยู่นั้น น้าก็เอาลิ้นของน้ากวาดพันเข้ามาในปากผม แล้วเริ่มไต่ไล้ไล้ ยั่วอารมณ์กระสัน จนเอ็นค่อยๆ พองตัวขยายขึ้นอีก เมื่อเอ็นฟื้นตัว ผมก็กดน้าสะใภ้ให้นอนลง ไม่ สนน้าชายที่อยู่ในห้องนอนแล้ว กะว่าคืนนี้ยังไงต้องเผด็จศึกน้าให้ได้บ้าง พอน้าสะใภ้คนสวยถูกทาบทับ น้าก็กางขาออกโดยอัตโนมัติ แล้วแอ่นร่องเสียวให้อ้ารับเอ็นที่จะสวนเข้าไป พอเอ็นฝังลึกเข้าไปใน ตัวน้า น้าก็หุบหน้าขาเข้าหากัน ใช้ปลายขารัดรอบบั้นเอว แล้วโยกร่องเสียวขึ้นลงเป็นการต้อนรับ เอ็นที่โถมเข้ากระหน่ำอย่างชนิดไม่ยั้งแรงเอาไว้ ผมกระแทกเอ็นถี่ๆ เสียงก้นน้าสะใภ้กระแทกพื้นดัง บึ้กๆ ความกลัวที่น้าชายจะได้ยิน ผมจึงผ่อนแรงลง แต่น้าสะใภ้ก็บอกว่า ไม่ต้องกลัว เต็มที่เลย น้า ชายเขารู้อยู่แล้ว เดี๋ยวเขาก็จะออกมาร่วมวงด้วย ไม่ขาดคำน้าชายเดินออกมาจากห้องจริงๆ มานั่ง ดูผมอัดน้าสะใภ้ตาเป็นมัน ถึงตอนนี้เอ็นชักห่อเหี่ยวหดลงไปบ้าง เพราะมีอย่างที่ไหนแอบดูก็ไม่ว่า ดันมานั่งดูด้วยอย่างนี้ มันรู้สึก แปลกๆ ชอบกล “…เฮ้ย…แรงๆ หน่อยซิวะ…ไม่ถึงใจ...กูไม่ให้เอาเมียกูนะเอ้า…” เสียงน้าชายดังขึ้น เร่งให้ผมเกิดความกล้าขึ้นมา แล้วเอ็นก็แข็งปั๋งขึ้นมาอีก คราวนี้ผมจึงซัดเอ็นเข้า ใส่ร่องเสียวกลางโคกนูน อย่างชนิดไม่ยั้ง เสียงน้าสะใภ้หอบหายใจดังหนักหน่วงขึ้นมา แล้วตัวน้าก็ เกร็งผวาเข้ากอดผมแน่น ตอนนั้นผมไม่รู้หรอกว่านั่นหมายความว่าน้าเสร็จไปแล้ว มารู้เมื่อน้าผละ ออกจากร่างผม แล้วนอนหอบหายใจระรัว ผมยอมรับละว่า ไม่ประสาเลย ก็พอจะรู้บ้างก็จากการได้ แอบดูน้าชายกับน้าสะใภ้เล่นสนุกกันเมื่อแล้วมา และยิ่งรู้สึกไม่ประสาใหญ่ เมื่อน้าชายเข้ามาสานต่อ ความรักกับน้าสะใภ้ อีกคน ขณะที่น้ายังนอนแบอยู่กับพื้น “…เป็นยังไงที่รัก…ครั้งเดียวไม่เคยพอ…ไม่ใช่หรือ…” น้าชายพูดออกมา ผมหูผึ่ง ครั้งเดียวไม่เคยพอบ้าอะไร ผมชักงงๆ ตอนนั้นยอมรับว่ายังไม่ทันเกม เพราะอ่อนเดียงสาจริงๆ พอน้าถูกผัวขึ้นคร่อมแล้วแทงเสยด้วยเอ็นลำคุ้นเคย กับถูกดูดที่ปลายถัน พร้อมทั้งขบเบาๆ ด้วยไรฟัน น้าสะใภ้ผู้หิวกระหาย แล้วจ้องมองร่องเสียวที่กลีบเนื้อเยื่อตีวงรอบลำเอ็น แล้วกลืนมันเข้าๆ ออกๆ ด้วยหัวใจสั่นเสียว เลือดลมกลับซู่ซ่าขึ้นมาอีก “….ดูอะไร…เอาเปรียบกันนี่…แบบนี้น้าไม่ยอมนะ…” เสียงน้าสะใภ้สะโพกผายหันมาค้อนขวับๆ แล้วจึงไล้มาที่แคมปริตึง ถึงตอนนี้น้าสะใภ้เริ่มร้องอูยๆ ออกมา เสียงลั่น ทำเอาผมมีลูกฮึดเร่งเลียหนักขึ้น _“…ดีจังเลย…แบบนี้เดี๋ยวเย็ดต่อกับน้าอีกนะจ๊ะ….คนเก่ง…”_
