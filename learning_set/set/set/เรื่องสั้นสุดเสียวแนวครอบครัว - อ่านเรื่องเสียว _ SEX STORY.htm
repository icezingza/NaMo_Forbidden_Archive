เรื่องเสียว *เรื่องสั้นสุดเสียวแนวครอบครัว* สวัส ดีครับเรื่องเสียว /เย็ดหีพี่สาวตั้งแต่เด็กจนโต/ ที่ผมจะเล่าเป็นเรื่องจริง100% ผมนอนกับพี่สาว พี่ สาวขอมีอะไรกันกับผมมาตั้งเเต่ ม.ต้น แรกๆ พี่สาวชวนลองทำ ผมมีอะไรกันกับพี่สาวแรกๆ ก็ทำไม่ เป็นหรอก ผมเอาควยใส่หีพี่สาวแปบเดียวก็เสร็จเเต่ใส่ถุงนะ ช่วงหลังๆ ทำตามคลิป แล้วมันมีอยูวันหนึ่ง ผมเย็ดหี พี่สาวอยู่เเล้วไม่รับ สายเเม่ เเม่โทรมา เราก็มีอะไรกันในห้อง เเล้วเเม่เข้ามาเห็นเเม่ตกใจมาก ผมทำอะไรไม่ถูก เลย เเม่ไปหยิบไม้กวาดมาฟาดใส่พี่สาวแบบแรงมาก พี่สาวล้มลงร้องให้เลย ผมน้ำตาซึมเลย เเม่ ด่า มึงทำเหี้ยอะไรกัน มึงเป็นพี่น้องกันนะ ด่าเสียงดังมาก เเม่บอกใส่ชุด ลงไปข้างล่างโทรเรียก พ่อมา วันนั้นวันนรกสำหรับผมจริงๆ พ่อมาถึงพ่อก็ด่าไปเยอะ พี่สาวผมน่าจะร้องทั้งคืน เเม่เเยกห้อง ผมมานอนข้างล่าง ให้พี่สาวนอนข้างบนคนเดียว ผมไม่ได้คุยกับพี่สาวเป็นอาทิตย์ พอผมโตมา พี่สาวมีครอบครัว ผมก็เรียนจบไปฝึกงานใกล้ๆ บ้านพี่สาวในกรุงเทพเลยไปพักกับพี่สาว พี่สาวผมกำลังตั้งท้องนะ อวบขึ้นเยอะเลยมาก อยู่ได้ประมาณอาทิตย์กว่าพี่สาวมาหาผมที่ห้อง บอกว่า อยากลองทำอีก ผมไม่กล้าทำผมกลัวตั้งเเต่นั้นมาอีกอย่างไม่มีถุงด้วย พี่สาวก็ขอให้ผมทำจนได้ เเต่ ครั้งนี้พี่สาวผมทำให้ผมทุกอย่าง เเล้วบอกให้ผมเลียด้วยเป็นครั้งเเรกเลย พี่สาวก็อวบขึ้นผมมีอารมณ์ มาก พี่สาวบอกผมอุ้มพี่สาวเอาท่ายืนไม่ถึง 1นาที น้ำผมแตกใน หีพี่สาวก็กอดผมเเน่น พี่สาวบอกยังไม่เสร็จเลย พี่สาวบอกมีเรื่องจะบอกผม เรื่องที่หนึ่ง พี่สาวรักผมตั้งเเต่เด็กๆ รักแบบ แฟนอยากอยู่ด้วยกันแบบแฟน เรื่องที่สองพี่สาวบอกอย่าตกใจนะ พี่เคยมีอะไรกันกับพ่อหลังจากที่เเม่ จับผมกับพี่สาวได้ พ่อก็มาปลอบใจมาถามพี่สาวแล้วก็เย็ดกันเเต่ผมไม่ได้ถามเยอะ รู้เเค่ว่าพี่สาวมา สารภาพกับผม หลังจากนั่นมาผมก็มีอะไรกันกับพี่สาวมาตลอด ปัจจุบันลูกชายพี่สาว 2 ขวบเเล้ว *เรื่องเสียว แอบเห็นพ่อเย็ดกับแม่* อยากจะเล่าบางอย่างที่เปิดเผยไม่ได้ คือหนูแต่งงานแล้วแยกครอบครัวไปอยู่กับแฟนซึ่งเราคบหากัน ตั้งแต่เรียนมหาลัยจนมีลูกชายหนึ่งคนตอนนี้ก็ห้าขวบ แล้วเรื่องมันเกิดขึ้นเมื่อสองปีที่แล้วหนูกลับบ้านที่ ต่างจังหวัดเพื่อไปเยี่ยมพ่อแม่ซึ่งท่านอยู่กันแค่สองคน น้องชายหนูแต่งงานแล้วย้ายไปอยู่กับแฟนเขา นานๆ ทีมาเยี่ยมที่ มีดิฉันนี่แหละไปเยี่ยมบ่อยหน่อยสอง สามเดือนไปที บังเอิญดิฉันไปสองคนกับลูกสามีติดธุระกับงานทุกครั้งไปก็จะอยู่ประมาณสามสี่วัน คืนวัน เสาร์ดิฉันรู้สึกปวดเยี่ยวเลยเดินลงมาชั้นล่างจะไปเข้าห้องน้ำซึ่งก็ต้องผ่านห้องพ่อแม่ที่นอนอยู่ชั้นล่าง ช่วงนั้นประมาณตีหนึ่งดิฉันเห็นไฟเหมือนทีวีจึงคิดว่าพ่อแม่ทำไมนอนดึกจังตอนแรกว่าจะเคาะประตู เรียกแต่ไม่รู้อะไรดลใจดิฉันเห็นเก้าอี้วางอยู่เลยยกมายืนปีนดูตรงช่องลมว่าทำไมไม่หลับไม่นอนเสียง ทีวีก็ดังดิฉันคิดว่าถ้าท่านหลับก็จะเคาะประตูเรียกให้ตื่นมาปิดทีวี แต่ตาเจ้ากรรมดิฉันเห็นคือแม่ดิฉัน นอนแก้ผ้าหลับตาครางเบาๆ โดยพ่อดิฉันเอาหน้าซุกตรงหีของแม่ ส่วนมือสองข้างก็ลูบคลำบีบที่เต้านมแม่ แม่เอามือกดหัวพ่อ ดิฉันสั่นๆ ใจหนึ่งก็จะไม่ดูสุดท้ายดูต่อจนพ่อดิฉันลุกขึ้นถอดกางเกงขาก้วย สิ่งที่ดิฉัน เห็นมันช่างแตกต่างจากของสามีดิฉันมากพ่อทำกับแม่นุ่มนวลมากดิฉันตัดสินใจลงจากเก้าอี้เข้าห้องน้ำ เงียบๆ โดยไม่เปิดไฟกลัวพ่อกับแม่รู้กลับขึ้นห้องไปช่วยตัวเอง ดิฉันจินตนาการว่าพ่อมีอะไรกับดิฉัน พ่ออายุห้าสิบกว่าแล้วแต่ดูดีดูไม่แก่ แม่ดิฉันดูแก่กว่ามากขนาดอายุน้อยกว่าพ่อตั้งสี่ห้าปี ดิฉันกลับบ้านก็คิดถึงแต่เหตุการณ์ในวันนั้นจนต้องลงกับสามี แต่มันเหมือนอะไรๆ คาในใจดิฉัน ประหลาดใจคนแก่มีอายุขนาดนี้ทำไมถึงรู้จักการใช้ลิ้น *เรื่องเสียว ให้ลูกชายเย็ดหีแม่แก้เงี่ยน* นึกว่ามีแต่คนเดียวที่มีใจอย่างนี้พ่อน้องเคนครับ ผมอีกคนที่มีความคิดอย่างคุณคือผมเคยอ่านเจอชีวิตคน ของญี่ปุ่นเมื่อสมัยสี่สิบปีที่แล้วคือสามีจะทำงานหนักคนดูแลลูกๆ จึงเป็นหน้าของภรรยา กรณีนี้ผมจะเล่า เฉพาะแม่ลูกเพราะชีวิตผมอยู่ในเหตุการณ์นี้คือสามีไม่คอยมีเวลาให้ภรรยาหน้าที่เย็ดหีนี้จึงตกเป็นลูก ชายพ่อก็ยอม ดีกว่าภรรยาไปมีคนอื่นจนครอบครัวแตกแยก เคยอ่านเจอนะครับประมาณ 70% ของเด็กผู้ชายญี่ปุ่นจะมีแม่เป็นคนปลดปล่อยความใคร่ให้เด็กจะ ตั้งใจเรียนมาก อีกอย่างเด็กๆ จะไม่มีเรื่องเครียดเหมือนมีอะไรกับแฟนไม่ต้องกลัวว่าแฟนจะท้องมั้ย จะติดโรคมั้ยเพราะแม่ต้องเตรียมพร้อมในเรื่องนี้อยู่แล้วก่อนจะมีอะไรกับลูกชาย เคยอ่านเจอนะครับ พ่อรู้เห็นเป็นใจให้ลูกชายมานอนกับภรรยาตอนเขาไปทำงาน ที่เล่ามานี้ผมคนหนึ่งที่ทำ จนปัจจุบันนี้ลูกชายก็แต่งงานไปมีครอบครัวที่อบอุ่นมีหลานๆ มาให้อุ้ม แต่พ่อ น้องเคนต้องปรับความเข้าใจกับลูกเมียคุณด้วยนะครับคืออย่าให้ใครคนใดคนหนึ่งต้องยึดติดเพราะทุก อย่างที่สามคนรวมทั้งผมด้วยทำลงไปคือการปลดปล่อยความใคร่ ส่วนความรักห่วงหาอาทรนั้นอีก ประเด็นหนึ่ง ทุกอย่างจะอยู่ใจจิตสำนึกของการเป็นพ่อแม่ลูกกัน ผมให้ลูกชายผมเรียนรู้ตอนอยู่ ปอ6 ครับ ตั้งแต่เขายังไม่มีหมอยไม่มีน้ำว่าวเลย จนขึ้นมอ 1 ถึงมีทุก อย่าง ครอบครัวผมก็รักกันดีนะครับลูกชายมาเยี่ยมก็กอดหอมแม่เขาจำได้ว่าตั้งแต่ลูกชายแต่งงานไปนี่ ก็สี่ปีแล้วภรรยาผมกับลูกชายมีอะไรกันแค่สองครั้ง ที่มีเพราะลูกชายขอร่วมด้วยอยากจะรำลึกถึงอดีต ตอนเด็กๆ ลูกชายก็ยังเก่งเหมือนเดิมคนที่มีความสุขที่สุดคือภรรยาผม เธอครางเสียงดังมาก 5555 ผมและลูกชายต่างมอบความเสียวให้กับคนที่เรารักอย่างเต็มที่ ปีนี้ผมก็ 48 ภรรยา 46 ผมยังมีอะไร กับภรรยาอาทิตย์ล่ะสองครั้ง ลูกน้องชายผมกำลังเรียนปอ 6 ปีหน้าเข้า มอ1น้องชายเปรยๆ ว่า อยากให้ผมช่วยเรื่องเรียนเพราะเขามีลูกหลายคนต้องส่งเสีย ผมอยู่กับภรรยาแค่สองคนผมกับภรรยาตกลง หลานชายผมรูปร่างหน้าตาดีมากครับพูดง่ายๆ คือลูกชายผมไม่ได้ครึ่งเขาเลยเพราะลูกชายผมออก อวบๆ แต่หลานชายผมหุ่นนักกีฬาครับปีหน้าปิดเทอมใหญ่เขาจะขึ้น มอ1ต้องมาสอบเข้าโรงเรียนที่นี่ที่ บ้านผม ขอบคุณมากๆครับคณ XYZ ที่ทำให้ผมเหมือนไม่ได้อยู่ในโลกคนเดียว ลูกชายไม่รู้นะครับว่าผม รู้ว่าเขามีอะไรกับแม่ ผมกลัวว่าเขาจะอาย รู้แต่ผมกับภรรยาผมอ้อนเธอขอร้องเธอจนเธอใจอ่อน ผมยกเหตุผลสารพัดผมแกล้งไม่เอาเธอเป็นเดือนสองเดือนบอกว่าไม่มีอารมย์บ้างบอกว่าเหนื่อยจาก งานบ้างจนเดี๋ยวนี้ภรรยาผมกับดีใจที่ช่วยให้ผมและลูกชายมีความสุขผ มชอบให้ภรรยาผมไปนอนกับลูก ชายก่อนเสร็จแล้วค่อยมาที่ห้อง ซึ่งผมจะมีอารมย์ผมจะเอาหน้าซุกตรงนั้นแล้วดูดกินน้ำควยลูกชายแล้ว จึงเย็ดกับเมีย ลูกชายเขายังเด็กอายุ 14/15 เองแต่ผมแอบดูตอนเขาเย็ดกับแม่ เขาเก่งมากยิ่งเอวเร็วมากภรรยาบอกว่าเขาต้องสองยกถึงจะพอใครได้ลูกชายผมเป็นสามีรับรองโชคดีมากเอาเก่งเรียนเก่งรูปหล่ออีกต่างหาก *เรื่องเสียว แอบดูแม่บ้านเอากับลูกชาย* สามีเราทำงานต่างจังหวัดวันหยุดถึงจะกลับมาบ้าน วันธรรมดาเราก็จะอยู่กับแม่บ้านสองคน แม่บ้าน อายุไล่เรี่ยกับเราคือประมาณสี่สิบกว่า ๆ แม่บ้านจะพักประจำที่บ้านเราเลยโดยเราจัดห้องพักให้อยู่ ต่างหากด้านหลังของบ้าน แม่บ้านแกเป็นหม้ายเลิกกับสามีนานแล้ว แกมีลูกชายคนหนึ่งเรียนอยู่ที่ต่าง จังหวัดพักอยู่กับยาย แม่บ้านคนนี้นิสัยดีเรียบร้อยขยันทำงาน ไม่เคยไปไหนเลยนอกจากออกไปซื้อกับข้าว หรือไปซี้อของใช้ ส่วนตัว นาน ๆ จะขออนุญาตกลับไปเยี่ยมบ้านที่ต่างจังหวัดสักครั้ง มีอยู่ช่วงหนึ่งลูกชายแม่บ้านปิด เทอมขอมาเที่ยวกรุงเทพและแม่บ้านขออนุญาตเอาลูกชายมาพักที่บ้านด้วยเราก็อนุญาต ลูกชายแม่บ้านอายุประมาณ สิบเจ็ดสิบแปดปี ผิวคล้ำรูปร่างสูงใหญ่เป็นนักบาสเก็ตบอลของโรงเรียน วันที่ลูกชายแม่บ้านมาถึงแม่บ้านก็พาแนะนำตัวกับเรา ดูแล้วนิสัยค่อนข้างเรียบร้อยเหมือนกับแม่ ช่วงที่ ลูกชายมากลางวันแม่บ้านก็ขออนุญาตพาลูกชายไปเทียวกลางคืนก็กลับมานอนบ้าน คืนนึงประมาณสี่ทุ่มเรานึกขึ้นมาได้ว่าลืมบอกให้แม่บ้านไปเอาโน๊ตบุ๊คที่ลืมไว้ที่บ้านเพื่อนแต่เช้าเพราะ เพื่อนจะไปต่างจังหวัดหลายวัน
