ดิฉันชื่อ ‘นันทภัค’ อายุ 50 ปี รับราชการเป็นผู้พิพากษาอยู่ในศาลแห่งหนึ่งในกรุงเทพฯ นี่เองค่ะ ดิฉันยังเป็นคนสวยหุ่น ดี นมใหญ่ก้นใหญ่ หัวนมยังสีน้ำตาลแดง เต้านมยังกลมกลึงเต่งตึง รวมทั้งฉันเองก็ยังเงี่ยนอยากโดน เย็ดอยู่แต่ต้องปกปิดความเงี่ยนไว้เพราะตำแหน่งหน้าที่มันค้ำคออยู่ ส่วนสามีรับราชการเป็นผู้ว่าราชการจังหวัดแถวชายแดนมาหลายปีแล้ว นานๆ ทีถึงจะกลับบ้านแล้วก็ ไม่ได้เย็ดดิฉันมาเป็นสิบๆ ปีแล้ว ส่วนลูกชายปีนี้อายุ 18 ปี เรียนอยู่ปีหนึ่งคณะนิติศาสตร์มหาวิทยาลัย ชื่อดังแห่งหนึ่ง ดิฉันเป็นอีกคนหนึ่งที่แอบเย็ดกับลูกชายตัวเอง เราได้เสียกันมาปีกว่าแล้ว โดยวันหนึ่งลูกชายมาแอบ เห็นดิฉันใช้ควยเทียมช่วยตัวเองในห้องนอน เขามาขอดิฉันว่าจะช่วยแม่ให้มีความสุข ตัวดิฉันเองตอน นั้นหน้ามืดรับปากไปด้วยอารมณ์เงี่ยน บอกลูกขอให้เขาใช้ปากดูดนมกับเลียหีให้แค่นั้น ไม่นึกว่าเกิน เลยถึงขั้นเอาควยสอดใส่หี “โอ้ยลูกจ๋าหยุดก่อนแม่เจ็บหี ลูกควยใหญ่ มากเลย คับแน่นรูหีแม่จนหีแม่จะแหกแล้ว” ดิฉันร้องด้วยความเจ็บแต่ทั้งๆ ที่เจ็บฉันก็ยังร่อนหีและเด้ง หีให้ลูกชายดิฉันเย็ดด้วยความเงี่ยน ลูก ชายฉันเขาก็ค่อยๆ คลึงควยกับเม็ดแตดและดูดเม้มหัวนมจนน้ำเงี่ยนดิฉันแตกอีก เขาก็ดันควยเย็ดเข้า ไปจนได้ครึ่งท่อนควย ดิฉันเจ็บจนทนไม่ไหวต้องให้เขาหยุดแทงควยเข้ารูหีและให้เขาเอาควยออก เพราะ มันแน่นคับหีและเจ็บไปหมดเขาก็ค่อยๆ คลึงควยกับเม็ดแตดดิฉันและค่อยๆ ดึงควยออกช้าๆ ควยครูดกับเม็ดแตดจนดิฉันเสียวสุดอีกพร้อมกับน้ำเงี่ยนแตกทะลักออกมาอีก ดิฉันก็เลยแอ่นหีตามควย เขาขึ้นไปเขาเห็นฉันแอ่นหีตามควยและมีน้ำเงี่ยนทะลักออกมาเขาก็เลยทะลวงควยเย็ดหี ดิฉันพรวดเดียวมิดท่อน ควยจนหัวควยเขาเข้าไปกระทุ้งกับปากมดลูกดิฉันเลยฉันต้องร้องลั่นด้วยความเจ็บที่โดนควยเขา ทะลวงรูหีทีเดียวมิดควย เขากดควยแช่อยู่อย่างนั้นแล้วก็ค่อยๆ สาวควยเย็ดหีฉันช้าเบาๆ จนเห็นฉันเริ่มชินกับความใหญ่ยาว ของควยเขาเขาก็เริ่ม สาวควยเย็ดหีฉันยาวขึ้นและเร็วขึ้นส่วนฉันเองไม่ได้เจอควยจริงๆ มานาน และมา เจอขนาดใหญ่ถึงใจก็ทำให้เงี่ยนจนหายเจ็บ ”ซี๊ดๆๆๆๆ หีหี ลูกจ๋าเย็ดหีแม่แรงๆ หน่อย ลูกจ๋าควยหนูยาวใหญ่เย็ดหีแม่มันดีจัง เย็ดแรงๆ อีกทะลวงควยเย็ดหีแม่ให้แหกเลยลูกจ๋า อย่างนั้นละ มันดีจังโอ้ยซี๊ดน้ำแม่แตกอีกแล้วเย็ดแรงๆ เลย” ลูกชายดิฉันทะลวงควยเย็ดหีฉันจนน้ำเงี่ยนฉันแตกไม่ รู้กี่รอบจนในที่สุด “ซี๊ดคุณแม่หีคุณแม่ดูดตอดควยผมแรงและถี่จังโอ้ยซี๊ดน้ำจะแตกแล้วซี๊ดน้ำแตกแล้ว” “ซี๊ดผัวขาเมียก็น้ำเงี่ยนแตกแล้ว” ลูกชายดิฉันอัดควยเย็ดเข้าไปสุดๆ จนหัวควยกระทบปากมดลูกดิฉันดังกึกแล้วลูกชายดิฉันก็ฉีดน้ำควย ของเขาเข้าไปในโพรงหีฉันมันพุ่งแตกใน แรงมากจนเข้าไปในโพรงมดลูก จน ฉันรู้สึกร้อนวาบในท้องน้อยเลยลูกชายดิฉันก็ซอยควยเย็ดหีฉันรีดน้ำควยอีกห้าหกทีดิฉันเองน้ำเงี่ยนก็ แตกทะลักออกมาชะโลมควยลูกชายฉันจนเยิ้มแล้วลูกชายฉันก็นอนซบกับอกดิฉันโดยที่ควยยังเสียบคาอยู่ ในรูหีดิฉันและบอกว่า “หีคุณแม่นี่เย็ดมันดีจังยิ่งเย็ดยิ่งมันทั้งดูดทั้งตอดแรงมากเลย” เขานอนพักอยู่สักครู่ก็จับฉันนอนตะแคง โดยควยเขาก็ยังคาอยู่ในรูหีดิฉันตอนนี้ดิฉัน นอนตะแคงโดยที่ ลูกชายฉันยืนคร่อมขาดิฉันอยู่ข้างหนึ่งควยก็ยังเสียบคารูหี เขาจับขาฉันอีกข้างหนึ่งขึ้นบนบ่าทำให้หีฉัน แหกอ้ามากขึ้นแล้วเขาก็เริ่มทะลวงควยเย็ดหีฉันต่อโดยที่ไม่ได้เอาควยออกจากหีเลย น้ำควยก็ยัง อัดแน่นอยู่ในรูหีฉันเขาเย็ดหีฉันจนน้ำควยแตกเป็นครั้งที่สองในโพรงหีฉัน แล้วก็จับฉันนั่งคุกเข่า โก้งโค้งแล้วเย็ดหีฉันทางด้านหลัง พอเย็ดกันจนน้ำแตกก็คิดมากร้องไห้ที่ทำตัวทำตัวอย่างนี้ ไม่น่าจะเย็ดกับลูกชายตัวเอง อายลูกมาก พยามยามเลี่ยงไม่ยอมพบหน้าลูกจนลูกทนไม่ไหว เขามายกมือไหว้ดิฉันขอโทษและกอดดิฉันๆ หอมแก้ม บอกไม่เป็นไรและร้องไห้กอดเขาจากกอดลูกเปลี่ยนเป็นจูบปากดิฉัน จนดิฉันก็ทนไม่ไหวโดนลูกชาย เย็ดอีก และพวกเราก็แอบเย็ดกันมาเรื่อยๆ ตอนสามีไม่อยู่ลูกจะเข้ามานอนกับดิฉันแล้วก็เย็ดหีแม่เขา ตลอด ทุกวันดิฉันมีความสุขมากหน้าใสจนเพื่อนๆ ทักว่าใช้ครีมบำรุงอะไร หน้าอกดิฉันก็รู้สึกตึงขึ้นใส่ ยกทรงตัวเก่าไม่ได้ก้นผายขึ้นไม่รู้เจ้าลูกชายตัวดีเขากระแทกควยใส่มากไป และบีบหน้าอกมากไป หรือเปล่า เรื่องมันเริ่มเกินเลยมากขึ้นเพราะมีอยู่ครั้งหนึ่งลูกขับรถพาเข้าโรงแรมม่านรูดบอกดิฉันว่าอยากจะ เปลี่ยนบรรยากาศ ดิฉันก็ไม่ว่าอะไรพอเข้าม่านรูด ลูกชายก็รีบจับดิฉันแก้ผ้าแล้วเย็ดอย่างหื่นกระหาย ดิฉันกำลังมันส์รู้แต่ว่าลูกเปิดประตูไปรับเครื่องดื่มจากหน้าประตู สักพักเสียงประตูปิดซึ่งดิฉันก้มหน้า ซบหมอนไม่ได้เอี้ยวตัวหันไปดู รู้สึกว่าถูกควยแทงอีกรอบแต่ครั้งนี้รู้สึกว่ามันคับขึ้นมาก หันไปดูกลาย เป็นพนักงานโรงแรมวัยรุ่นอายุน่าจะแค่ 15-16 น้อยกว่าลูกดิฉันอีกแต่ควยใหญ่ทุกคนที่เย็ดหีดิฉันอยู่ อย่างเอาเป็นเอาตาย แล้วยังมีพวกพนักงานรุ่นราวคราวเดียวกันอีก 4 คน เข้าคิวรอเย็ดดิฉันอยู่ เจ้าลูกชายตัวดีเอาท่อนควยของเขามาให้ดิฉันอม ตอนนั้นเสียวมากเลยยอมให้ทำ ทีนี้พวกเขาก็จับ ดิฉันเปลี่ยนท่าแล้วก็เข้าคิวผลัดกันมาดูดนมเลียหี แล้วให้ดิฉันดูดควย ให้ไปด้วย หน้าตา พวกเขาแต่ละคนเหยเกบิดเบี้ยวด้วยความเสียวซ่าน แล้วก็ผลัดกันเอาควยทิ่มหีดิฉัน จนครบทุกคน แล้วเปลี่ยนมาทำในท่ากวางเหลียวหลังจากด้านหลัง โดยลูกชายดิฉันเขาขอเย็ดตูด ของดิฉัน ตอนแรกดิฉันจะไม่ยอมแต่เขาบอกว่ามีเควายเจลทาไม่ต้องกลัวตูดฉีกหรอก ดิฉันก็อยากลองเหมือนกัน เพราะเกิดมายังไม่เคยโดนเย็ดตูดเลย พอพวกเขาเย็ดตูดดิฉันจนครบทุกคนแล้ว ก็มาเย็ดดิฉันในท่า แซนด์วิชแบบเย็ดหีเย็ดตูดพร้อมกัน ดิฉันยอมรับว่าเสียวซ่านสุดๆ จนหน้าตาเหยเก ร้องโอ้วอ้าวๆๆๆ ซี้ด…ซ้าดๆๆๆๆ ดังลั่นห้อง ก่อนที่พวกเขาจะมาปล่อยน้ำควยแตกใส่หน้าดิฉันจนครบทุกคน ชายก็จะเย็ดหีดิฉันไปด้วย ดิฉันจะรู้สึกผิดทุกครั้งที่โทรตอนเย็ดกับลูกชาย แต่มันทำให้ดิฉันมีอารมณ์ อย่างมาก ที่ต้องกลั้นเก็บเสียงไม่ให้สามีรู้และได้ยิน เดี๋ยวนี้เขาจะขอดิฉันเดือนละครั้งให้ไปนอนโรงแรมม่านรูด และทุกครั้งดิฉันจะถูกพนักงานโรงแรม พวกนั้นเย็ดตลอด แบบรุมเย็ดนี่แหละ โดยพวกเขาเข้าใจไปว่าดิฉันกับลูกชายเป็นแค่คู่ขาต่างวัยกัน เท่านั้น หลังจากนั้นฉันกับลูกชายก็แอบหาความสุขด้วยการเย็ดกันเรื่อยๆ มาโดยที่ไม่ให้ผัวรู้ แถมตอน หลังดิฉันให้ลูกชายชวนเพื่อนที่ไว้ใจได้ มาร่วมกันลงแขกเย็ดฉันแบบเย็ดทั้งหีทั้งตูดพร้อมกันปากก็อมดูด ควยไปด้วย แถมบางครั้งเวลามีคนรอคิวไม่ไหวก็เข้ามาเย็ดหีเย็ดตูดแบบสองควยในรูเดียวอย่างกับในหนังเอ๊กซ์ เลยค่ะ แล้วก็ปล่อยน้ำควยแตกคาปากฉันเลย ฉันกลืนกินมันอย่างมีความสุขไม่รังเกียจแม้กลิ่นมันจะ คาวๆ บ้าง บางทีก็มาครั้งละสี่คนบ้างห้าคนบ้าง มากที่สุดก็เคยถึงยี่สิบคน มันเป็นความสุขที่ฉันไม่เคย ได้รับมาก่อนจนบรรยายไม่ถูกเลยค่ะ แล้วมันก็ยังทำให้ฉันดูสาวดูสวยเปล่งปลั่งกว่าคนในวัยเดียวกัน โดยลืมไอ้แก่ผัวฉันไปเลย ดิฉันรู้สึกภูมิใจมากที่มีประสบการณ์สุดวิเศษที่น่าจะไม่มีใครได้เคยทำแบบนี้ แล้วมั้งคะ เรื่องเสียวอื่น ๆ นัดเย็ดกับผู้ชายทางเน็ต สวัสดีค่ะ
