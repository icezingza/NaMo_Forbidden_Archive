เรื่องเสียวแนวครอบครัว แอบเลียหีแม่เลี้ยง เรื่องเสียวเริ่มต้นขึ้นในวันที่ผมเองทนไม่ไหวแล้วจริงๆ เพราะว่าผมไม่อยากจะมีแม่ใหม่ เธอคนนี้ที่ เข้ามาในบ้าน อายุไม่ได้ต่างจากผมมากนัก ไม่ถึงสิบปีด้วยซ้ำ แต่พ่อกลับให้ผมเรียกเธอว่าแม่ ทั้งๆ ที่เธอสวยน่าเย็ดขนาดนี้ แถมบางครั้งผมก็สังเกตว่าเธอมองผมด้วยท่าทางอ่อยเหยื่อเลยด้วยซ้ำ เลย ทำให้ผมนั้นไม่รอช้า ในคืนนี้ที่พ่อไม่อยู่*ผมตัดสินใจเผด็จศึก…แม่เลี้ยง แล้วถ้ามันจะโวยวาย ก็จะเอา เรื่องสมบัติของพ่อมาอ้าง…ถ้ามันอยากจะเกาะพ่อผมแดก ก็ต้องยอมให้ผมเย็ด แค่นั้นเอง* เธอนอนหลับอยู่ในห้อง วันนี้ดื่มมานิดหน่อย บอกว่าไปวันเกิดเพื่อนมา พอเข้ามาในบ้านก็ทิ้งตัวลงนอน ทันที ผมเปิดประตูเข้าไปด้วยกุญแจสำรอง…บ้านผม ผมจะทำอะไรก็ได้ ค่อยๆ เปิดไฟที่หัวเตียง ก่อน ที่จะค่อยๆ มองดูเธอที่หลับใหลไม่รู้เรื่องราว ขนาดตอนหลับยังสวยน่าเย็ดเลย สวยๆ ขนาดนี้ ถ้าไม่ได้อยากจะมาเกาะพ่อผมแล้วมันจะหมาย ความว่าอะไรล่ะ ? ผมค่อยๆ ลูบไล้ร่างกายของเธอช้าๆ จากใบหน้า แก้มนุ่มๆ ลงมาที่ลำคอเรียวระหง ตามมาด้วยเนิน นมใหญ่ที่ตั้งเต้าเต่งตึง แล้วลงไล้มาที่หน้าท้อง ค่อยๆ แกะซิปที่กางเกงของเธอก่อนที่จะดึงมันลง อย่างง่ายดาย เธอคงจะเมาไม่น้อยแล้วละแบบนี้ ผมค่อยๆ ดึงกางเกงที่ไม่ใช่ส่วนสำคัญออก แล้ว ค่อยๆ แหวกแคมหีของเธอทันทีที่ได้เห็นเนินหีใหญ่ของเธออยู่ตรงหน้า มันมองอะไรไม่ชัดหรอก แต่ เธอหีสวยไม่เบาเลยทีเดียว คิดว่าผิวกายขาวเหมือนไข่ปอกขนาดนั้น หีชมพูแน่นอน แสงโคมไฟไม่เป็นใจ แต่ไม่ได้เป็นอุปสรรคต่อลิ้นของผมสักเท่าไหร่นัก ผมค่อยๆ ลงลิ้นเลียหีให้เธอ ทันที ตอนที่กำลังเงี่ยนอย่างได้ที่ กลิ่นหีหอมๆ ของเธอทำให้ผมนั้นละเลงลิ้นเลียหีให้เธออย่าง สาแก่ใจอยาก ทั้งดูด ทั้งดุน ทั้งเลียอย่างเต็มที่จนควยแข็งขึ้นมาแล้วถอดกางเกงของผมออก จับควย ชักว่าว ควยแข็งจนเจ็บไปหมดแล้ว ชักไป เลียหีไปจนน้ำเงี่ยนของผมเองก็ไหล รีบจัดการลุกขึ้นมา บนเตียง ตั้งตาจับขาของเธอยก มองดูจากตรงนี้ เธอก็ควรที่จะเป็นเมียของผมมากกว่า ผมค่อยๆ เอาลำควยใหญ่ยาวค่อยๆ ถูไถไปตามร่องหีของเธอที่มีเมือกเงี่ยนลื่นๆ อาบไล้อยู่ และมันก็ทำให้ ผมนั้นเสียวควยจนสุดจะทน ดันควยพรวดเข้าไปในรูหีของเธอแล้วกระหน่ำเย็ดเธอทันที เสียงครางของผมดังขึ้นมา และยิ่งได้เย็ดหีของเธอ ดูเหมือนว่าผมเองจะไม่สามารถหยุดได้แล้ว ทั้งๆ ที่ตั้งใจจะทำให้มันเบากว่านี้ แต่รูหีของเธอตอด ควยผมมากเกินจนสุดท้ายแล้วผมก็ยกเอวกระหน่ำรูหีของเธอไปจนเธอตื่นขึ้นมาในที่สุด ทว่าเสียงของเธอที่ดังขึ้นมาเสียงแรกกลับเป็นเสียงคราง ผมแปลกใจ ที่เธอไม่ได้ร้องโวยวายอะไร แต่กลับครางออกมาลั่น แถมยังร่อนหีใส่ควยของผมอีก ต่างหาก ในตอนนี้เหมือนว่าเธอเองก็คงจะเมาจนเงี่ยนนั่นแหละ
