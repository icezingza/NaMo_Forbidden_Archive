เมื่อช่วงปีใหม่ที่ผ่านมาผมได้มีโอกาสไปเยี่ยมเพื่อนที่ต่างจังหวัดมา เพื่อนของผม คนนี้ชื่อว่า “ชัย” ผมกับมันเป็นเพื่อนรักกันมาก เราสองคนเคยเที่ยวด้วยกันเป็นประจำ หลังจากที่ เพื่อนผมคนนี้ย้ายบ้านกลับไป อยู่บ้านเดิมของมัน จึงทำให้เราต้องห่างเหินกันในเรื่องอย่างว่า แต่ เราสองคนก็ยังคงติดต่อกันทางโทรศัพท์อยู่เสมอๆ จึงทำให้เราเหมือนกับอยู่ใกล้กันเหมือนเดิม มัน โทรมาหาผมครั้งสุดท้าย แล้วมันก็บอกกับผมว่ามันแต่งงานแล้ว มันแต่งกันอย่างเงียบๆ ไม่ได้เชิญใคร นอกจากญาติของมันเท่านั้นแล้วมันยังพูดเสริมท้ายด้วยว่าต้องการให้ผมไปเที่ยวที่บ้านของมัน เพื่อต้อง การสร้างประสบการณ์ให้กับเมียของมันหน่อย มันต้องการให้เมียของมันเซอร์ไพรส์เล่นๆ น่ะครับเมื่อ เป็นอย่างนี้แล้วผมจะพลาดได้อย่างไรล่ะครับ จากนั้นผมก็ออกเดินทางเลย พอไปถึงบ้านเพื่อนผม ผมก็รู้สึกตื่นเต้นจนแทบจะควบคุมอารมณ์ความรู้สึก เอาไว้ไม่อยู่ เมื่อผมได้พบกับเมียของมัน เธอมีชื่อว่า “จอย” อายุของเธอเพียงแค่ 19 เท่านั้นเอง รูปร่างหน้าตาของเธอก็เหมือนนางงาม ผิวก็ช่างขาวนวลเนียน อวบอั๋นเนื้อแน่นหนึบไปทั้งตัวเลย ทำ ให้ผมต้องแอบกลืนน้ำลายลงคออยู่บ่อยครั้งที่ผมแอบมองเธอใจผมอยากจะเร่งให้ถึงเวลากลางคืนเร็ว ๆ ผมคิดว่าเธอก็คงจะรู้เรื่องการมาของผมเป็นอย่างดี เพราะว่าบางทีเธอก็แอบส่งสายตาหวานมา ทางผมอยู่บ่อยครั้งเหมือนกัน เมียของเพื่อนก็เหมือนเมียของเรา ผมคิดอย่างนั้นอยู่ในใจ และคิดว่า ไอ้ชัยมันคงจะบอกให้เมียของมันรับรู้เรื่องก่อนหน้านี้แล้วเป็นแน่หลังจากที่เราชวนกันออกไปกินข้าว นอกบ้านเสร็จ เราสามคนก็รีบกลับมาที่บ้านทันที เรามานั่งพักผ่อนพูดคุยกันจนอาหารย่อยดีแล้ว เพื่อน ของผมก็เริ่มเดินเครื่องเลยทันทีเหมือนกัน โดยมันบอกให้ผมเข้าไปอาบน้ำเสียก่อน เมื่อผมอาบเสร็จ เรียบร้อยออกมา เมียสาวของเพื่อนก็เข้าไปอาบต่อ และในระหว่างที่เธออาบน้ำอยู่นั้น เพื่อนของผม ก็เล่าเรื่องราวของจอยเมียของมันให้ฟังอย่างละเอียด และมันก็ไม่ลืมที่จะบอกจุดเสียวของเธอตามที่ ต่างๆ ให้ผมได้รับรู้ผมนั่งฟังมันบรรยายสรรพคุณของเมียมัน จนท่อนควยของผมแข็งไปหมดทั้งลำ ก็จะ ไม่ให้แข็งได้อย่างไรล่ะครับ ก็มันเล่นบอกสิ่งสำคัญในเรือนร่างของเธออย่างตรงๆ มันทำให้สามารถ จิตนาการภาพของเธอพร้อมด้วยคำบรรยายเหมือนกำลังนั่งดูหนังโป๊ไม่มีผิดเลยครับ จอยใช้เวลาในการอาบน้ำนานมาก สักพักใหญ่เธอก็เดินออกมาในชุดนอนที่ดูเบาบางมาก ความบาง ของชุดนอนของเธอทำให้ผมมองได้ผ่านทะลุเข้าไปจนเห็นถึงเนื้อภายในกายของความเป็นสาว สองเต้าของเธอที่ดูแม้จะไม่ค่อยใหญ่นัก แต่หัวนมตั้งชูชันดันเนื้อผ้าออกมาเป็นเม็ดน่าดูดมาก ขณะที่ผม กำลังมองเธออย่างตกตะลึงนั้น ไอ้ชัยเพื่อนของผมมันก็ขอตัวไปอาบน้ำบ้าง แต่ก่อนที่มันจะไปมันก็สั่ง ให้จอยเอาไว้ว่าให้ดูแลผมให้เต็มที่เลยนะเดี๋ยวมันมา และทันทีที่ไอ้เพื่อนผมมันเดินลับตาไปจอยก็ส่ง สายตาหวานเยิ้มให้ผมเลย รอยยิ้มของเธอนั้นบาดหัวใจจริงๆ เพราะว่าดูแล้วเธอเซ็กซี่ไปหมด สายตาของที่มองผมนั้นมันช่างเปิดเผยและเชิญชวนผมไปด้วยในตัวผมเองก็ไม่ยอมปล่อยเวลาให้เปล่า ประโยชน์ ผมจึงลุกไปนั่งข้างๆ เธอทันที จอยเองก็แสดงความไวไฟของเธอออกมาด้วยการกอดผม เป็นการตอบโต้ ผมเองก็เคยผ่านเรื่องนี้มาอย่างโชกโชน แต่เมื่อมาเจอกับสาวน้อยผู้เร่าร้อนอย่าง เมียเพื่อนคนนี้ ผมยอมรับเลยว่าความเร้าใจผสมกับความตื่นเต้นมันเกิดขึ้นกับผมในตอนนี้อย่าง มากมาย เพราะที่ผมเคยเจอมานั้นมันประเภทสาวขายบริการทั้งนั้น เมื่อได้มาพบกับสาววัยรุ่น แถม ยังร้อนแรงและมีความต้องการทางเพศสูงอย่างนี้ รวมทั้งรูปน่างที่ได้สัดส่วนด้วยแล้ว หัวใจของผมมัน ก็ยิ่งพองโตเสียใหญ่เลยครับ เราสองคนต่างก็ประกบปากจูบแลกกันอย่างดูดดื่ม ไม่นานเราสองคนก็ ช่วยกันถอดเสื้อผ้าจนร่างของเราเปลือยเปล่าด้วยกันทั้งคู่ ทำให้ผมได้เห็นเรือนร่างของเธอได้อย่าง เต็มตา สองเต้าอวบของเธอนั้นไม่ใหญ่มากนัก แต่เต่งตึงเชิดงอนสู้มือผม หน้าท้องของเธอแบนราบ เรียบ เนินเนื้อโคกหีมันใหญ่เต็มหว่างของเธอ ยิ่งดูดีและใหญ่มากเลย มันช่างอวบอูมจนใหญ่เกินตัว กลีบแคมสองข้างนั้นเบียดเสียดกันแน่นมิดชิด ปิดร่องเสียวของเธอเสียสนิทผมยิ่งมองมันก็ยิ่งทำให้ผม กระหายอยากมากขึ้นไปอีก อยากจะก้มลงไปเลยเสียตรงนั้นเลย แต่เธอกลับร้องห้ามเอาไว้ “เดี๋ยว จอยดูดควยให้พี่ก่อนดีกว่า เพราะพี่ชัยเขาสั่งให้จอยบริการพี่ให้เต็มที่…” พอเธอพูดจบก็ให้ผมเอนหลัง นอนหงายลง จากนั้นเธอก็ก้มหน้าลงมา อ้าปากอมท่อนควยของผมทันที ลีลาการใช้ปากดูดท่อนควย ของสาวน้อยคนนี้นับว่าเก่งมากเลยทีเดียว เพราะไม่ว่าจะเป็น การดูด การเลีย การอม ของเธอ นั้นทำได้คล่องมาก โดยเฉพาะการดูดที่หัวควยนั้น เธอไม่ได้ดูดเฉยๆ แต่เอาริมฝีปากรูดที่คอหยักของ ผมด้วย มันยิ่งทำให้ผมเสียววูบวาบไปทั่วทั้งตัว จนผมแทบจะกลั้นน้ำเงี่ยนเอาไว้ไม่อยู่เลย “ปล่อย ออกมาได้เลยนะคะ ไม่เป็นไรหรอกค่ะ เดี๋ยวเราค่อยต่อกันอีกรอบก็ได้ คืนนี้จอยเป็นของพี่ได้ทั้งคืน เลยค่ะ…” พอเธอพูดเสร็จ เธอก็เร่งผงกหัวรูดปากดูดท่อนควยของผมเป็นการใหญ่ ตัวของผมเองก็ สุดที่จะทานทนความเสียวเอาไว้ได้ ผมจึงต้องตัดสินใจปล่อยเลยตามเลย ไหนๆ ก็จะทนไม่ไหวแล้ว ผมเลยเอามือกดหัวของเธอไว้ แล้วแอ่นเอวเด้งท่อนควยเสยใส่ปากเธออย่างถี่ยิบ จนน้ำเงี่ยนของ ผมพุ่งกระฉูดใส่ปากของเธออย่างแรง แล้วจอยก็จัดการกลืนกินมันเข้าไปจนหมด จนทำให้หัวควยของ ผมสะอาดเลยครับ มีแต่เพียงน้ำลายของเธอเท่านั้น ผมทั้งตื่นเต้นและเร้าใจเป็นอย่างมากที่ได้เจอกับจอยที่เพิ่งจะแรกรุ่น แต่ร้อนแรงด้วยความสามารถ ทางเรื่องเสียว ผมจำต้องปล่อยน้ำเงี่ยนให้เธอกิน แค่พียงเธอใช้ปากและลิ้นเท่านั้น แต่เธอยังไม่ ยอมหยุดเท่านั้น เธอยังคงใช้ปากลงลิ้นเลียหัวควยผมอย่างบรรจงและตั้งใจ พวงไข่ของผมก็ถูกเธอ เลียและอมจนรู้สึกชา เธอเลียต่ำลงไปจนถึงนิ้วเท้า เธอดูดอมมันอย่างไม่รังเกียจเธอเลียจากปลาย เท้าย้อนขึ้นมาข้างบนอีกครั้ง จนมาถึงใบหน้าของผม ทั้งติ่งหูและรูหูของผมเธอก็ยังฉกลิ้นเลีย จนทำ ให้ผมเกิดอารมณ็เสียววูบวาบไปทั่ว เธอจูบแล้วก็จูบผมไปทั่วทั้งตัว โดยเฉพาะท่อนควยของผมถูก เธออมเลียจนกระทั่งมันแข็งขึ้นมาอีกครั้ง “ควยพี่นี่ช่างใหญ่จริงๆ อย่างนี้แหละที่จอยชอบ… ” แล้ว เธอก็เป็นฝ่ายเริ่มต้นก่อน เธอลุกขึ้นยืนแล้วมานั่งคร่อมกลางลำตัวของผม แล้วจัดการหย่อนสะโพกลง มา แล้วเธอก็ใช้มือนุ่มๆ ของเธอมาจับท่อนควยของผมจ่อให้ตรงร่องหีของเธอที่แบะอ้าออกจนเห็น เม็ดแตดข้างในพอเธอจับมันจ่อตรงปากรูแล้ว เธอก็กดสะโพกของเธอลงมาอย่างช้าๆ แต่เธอก็เต็ม ไปด้วยความมั่นใจ เมื่อร่องหีของเธอสัมผัสกับหัวควยของผมแล้ว เธอก็ค่อยๆ ทิ้งน้ำหนักตัวลงมา ผม เห็นท่อนควยของผมกำลังโดนกลีบแคมสองข้างของเธอดูดกลืนกินเข้าไป มันเป็นภาพที่เร่าร้อนอารมณ์ ของผมเหลือเกินครับ “ซี๊ดดดด…อูยยยย…เสียวรูจังเลยพี่…มันแน่นในรูหีจอยเหลือเกิน…โอยยยยยย…” เธอร้องบอกผมออกมา แต่บั้นท้ายของเธอก็ไม่ได้หยุดยั้งคงกดลงมาเรื่อยๆ จนกระทั่งท่อนควยผม ถูกกลืนหายผลุบเข้าไปในรูหีของเธอจนหมด ภายในรูหีของเธอดูดตอดรัดขมิบท่อนควยของผมตุบๆ อยู่ ตลอดเวลา เสียงของเธอร้องครางออกมาเบาๆ เหมือนกับคนกินอะไรเผ็ดๆ เข้าไปสักคำใหญ่ “โอยยยย…ซี๊ดดดด…ควยพี่มันเข้าไปคับแน่นอื้อตื้อเต็มรูหีดีจัง…อูวววว…จอยเสียวหีจังเลยค่ะพี่…ซี๊ดดดด …อูยยยย…โอวววววว…” เธอยังคงร้องครางออกมา แต่สะโพกของเธอนั้นก็ส่ายร่อนอยู่ไม่ยอมหยุดนิ่ง เลย ผมก็นอนให้เธอเอารูหีรูดกับท่อนควยอย่างสบายใจ มีเพียงแต่อารมณ์เสียวซ่านที่เกิดมาจากการ ที่ท่อนควยของผมครูดกับผนังรูหีของเธอเท่านั้น “พี่ก็เสียวจ้ะ รูหีจอยทั้งฟิตแล้วยังขมิบตอดอย่างนี้จะ ไม่ให้พี่เสียวควยได้ยังไงกัน ขย่มหีลงมาเลยสิจ๊ะ อูยยยย ซี๊ดดดด เสียวดีเหลือเกิน โอวววววว…” เธอไม่รอช้ารีบยกสะโพกขึ้นลง เพื่อตอบสนองผมทันทีที่ได้ยินผมบอก มันเป็นการรูดท่อนควยในรูหีที่ คับแน่นจนครูดไปมา ทำเอาผมแทบจะทนไม่ไหวอยู่เหมือนกัน “อูวววว…อูยยยย…พี่เสียวเหลือเกิน… โอยยยย…เสียวหัวควยเหลือเกิน…โอวววววว…” ท่อนควยของผมทะลวงเข้าไปอย่างสุดกำลัง อัดแน่น เต็มรูหีของเธอเลยทีเดียว ยิ่งตอนนี้เธอขย่มเข้าใสแรงเท่าไหร่ เธอก็ร้องครางเสียงดังมากขึ้นเท่า นั้น เสียงของเธอที่ร้องออกมาเหมือนกับว่าเธอจะขาดใจเสียให้ได้ ผมเห็นน้ำเสียวของเธอไหลออกมามากมาย จนมันเปียกเยิ้มท่อนควยของผม จนทำให้เส้นหมอยของ ผมกับของเธอเปียกน้ำเสียวของเราด้วยกัน จนบริเวณนั้นเปียกชุ่มโชกไปหมด เวลาเธอกระแทกลง มาได้ยินเสียงน้ำดังแจะๆ แล้วเร้าใจดีเหลือเกินเมื่อผมเห็นว่าเธอเหนื่อยมากแล้ว ผมจึงจับเธอให้
