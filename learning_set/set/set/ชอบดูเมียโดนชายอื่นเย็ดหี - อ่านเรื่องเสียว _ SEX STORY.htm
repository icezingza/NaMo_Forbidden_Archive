รีบเข้าไปตีสนิทกับคนกลุ่มนี้ทันที เมื่อคุยกันได้ สองสามคำผมจึงรีบตัดบท บอกถึงสิ่งที่ผม ต้องการ พวกนั้นได้ฟังถึงกับอึ้งไปเลยทีเดียว พอตกปากรับ คำกัน ผมก็บอกแผนการทันที โดยที่แฟนผมไม่มีโอกาสจะรู้เลยว่า จะเกิดอะไรขึ้นกับเธอคืนนี้ หนึ่งในสี่ของแขกรับเชิญของผมในคืนนี้ บอกผมว่าแฟนผมหุ่นน่าเอาที่สุด ไม่รู้สึกเสียดายเหรอ ผม หัวเราะแต่ไม่ได้พูดอะไร ผมแยกตัวออกจากวงทันทีเมื่อมองเห็นแฟนเดินกลับมาลิบๆ ทุกอย่างเป็นไป ตามแผน ผมนั่งดื่มเบียร์กับแฟน 2 ขวด แฟนผมคงเริ่มรู้สึกตึงๆ แล้วกระมัง พอดีกับได้เวลาที่นัด หมายกับพวกชาวประมงไว้ตอน 4 ทุ่ม ผมให้แฟนเข้าไปอาบน้ำเตรียมนอนได้แล้ว ตอนนี้ใจผมเต้นตูม
