แม่เลี้ยง , เรื่องเสียวแนวครอบครัว พ่อมีเมียเด็กเลยต้องจัด เรื่องเสียวเรื่องนี้ถือว่าเป็นความลับของผมเลยก็ว่าได้ครับ เพราะว่ามันเป็นอะไรที่ผมเองก็เปิดเผย กับคนทั่วไปไม่ได้ เลยมาเขียนให้ทุกๆ คนได้อ่านเรื่องเสียวของผมกันในวันนี้ เรื่องก็คือ ผมมีแม่ เลี้ยงอยู่คนหนึ่ง พ่อพาเธอเข้ามาในบ้านหลังจากที่แม่เสียไป 4 ปี ผมว่ามันเป็นเวลาที่นานพอสมควร แล้วเหมือนกันที่พ่อจะต้องเริ่มต้นใหม่ และลืมความเสียใจทั้งหมดทั้งมวลที่ผ่านมา แต่ผมกลับชอบแม่ เลี้ยงของผมเสียอย่างนั้น ทำยังไงได้ละครับ ในเมื่อเธอนั้นก็ยังสาว ยังสวย เป็นรุ่นพี่ของผมไม่กี่ปี ผมจะเรียกเธอว่าแม่ก็กระดากปากนิดหน่อย เลยเรียกเธอว่าพี่แทนนั่นเอง แล้วเพราะว่าความสนิทสนมมันเป็นแบบนี้ผมก็เลยแอบมองเธออยู่บ่อยๆ ตอนที่เธออาบน้ำบ้าง ตอนที่ เธอนั้นทำอะไรต่อมิอะไรบ้าง ก็เธอน่าเย็ดขนาดนั้น ทั้งสวย ทั้งสาว ทั้งหุ่นดี นมใหญ่ มองตรงไหนก็ ชวนเงี่ยน ผมไม่รู้เลยว่าพ่อไปหาเธอมาจากไหนด้วยซ้ำ นั่นเลยทำให้ผมนั้นเกิดความหลงใหลในตัว ของเธอมากขึ้นมาไม่น้อยเลยทีเดียว และเพราะมันเป็นแบบนี้แหละครับ ผมเลยอยากที่จะเย็ดเธอสัก ที แต่ไม่รู้ว่าจะหาวิธียังไงดี จนกระทั่งโอกาสมาถึง วันที่เธอกับพ่อของผมทะเลาะกัน ผมกลับบ้านมาก็เห็นว่าเธอเครียดจนดื่ม เหล้าเมาแล้วหลับไปบนโซฟา ซึ่งข้างๆ กันนั้นมีขวดเหล้าอยู่จำนวนหนึ่ง ซึ่งมันก็มากพอที่จะทำให้นั้นรู้ ได้เลยว่าเธอคงจะเมาแบบไม่ได้สติเลยทีเดียว สุดท้ายแล้วผมเองก็เลยเลือกที่จะเดินเข้าไปมองดู รูปร่างของเธอ เมาขนาดนี้ทำอะไรก็คงไม่รู้สึกหรอก ขนาดแค่มองเธอตอนหลับ…ผมก็ควยแข็งขึ้นมาแล้วครับ ดังนั้นจึงไม่พลาดโอกาสนี้ ผมค่อยๆ เลิกเสื้อ ของเธอขึ้นใบ ชั้นในแบบปีกนกมันทำให้ผมเอาออกได้ง่ายมากๆ แล้วได้เห็นนมใหญ่ๆ ของเธอที่ ปานนมชมพูดูยังไงก็ชวนเงี่ยน ผมกลืนน้ำลายแค่อึกเดียวในระหว่างที่กำลังคิด ก่อนที่จะทรุดตัวลงไป นั่งที่ข้างๆ โซฟา แล้วดูดนมของเธอทันที ปากก็ดูดข้างหนึ่ง มือก็ขยำอีกข้างหนึ่ง จนควยแข็งแทบจะ ทนไม่ไหว ต้องลุกขึ้นมาแล้วถอดกางเกงลง ชักว่าวไปด้วยระหว่างที่กำลังลูบไล้ร่างกายของเธอ แล้วในตอนนั้นผมเองก็เอื้อมมือลงไปลูบที่เนินหีใหญ่ของเธอ เพราะว่ากางเกงของเธอเป็นกางเกง แบบอยู่บ้าน เนื้อบ้าง ขาสั้น ยิ่งแค่เพียงใส่ก็รัดติ้วจนเห็นกลีบหีสวยนูนขึ้นมาแล้ว ผมเลยถอดมันออก อย่างง่ายดาย แล้วแยกขาของเธอออก โอกาสนี้มันมีแค่หนึ่งในไม่กี่ร้อยเท่านั้น เลยทำให้ผมไม่รีรอที่ จะแหวกแคมหีของเธอออกจนต้องร้องโอ้โห เพราะว่ากลีบหีชมพูของเธอตอนนี้มันเยิ้มไปด้วยน้ำเงี่ยน เม็ดแตดแดงแจ๋ ผมก้มลงไปดูดเม็ดแตดของเธอพร้อมๆ กับชักว่าวไปด้วย แล้วเริ่มละเลงลิ้นเลียหีให้ เธอทันที เธอเองก็นอนนิ่งให้ผมเลียหีอยู่พักใหญ่ๆ จนผมเองทนไม่ไหว และตัดสินใจจะไม่ทน ขึ้นไป บนโซฟา แล้วจับขาข้างหนึ่งของเธอขึ้นมาประคงเอาไว้ ลำควยที่แข็งขืนค่อยๆ ถูไถไปตามร่องหีของเธอ แค่นี้ก็เงี่ยนแล้วครับ ยิ่งได้น้ำเงี่ยนแฉะๆ จากรูหี ของเธอที่ปริ่มออกมาปนกับน้ำลายของผม ก็เลยถูซะมันส์เลย จนตัวสั่นระริกด้วยความเงี่ยน เลยจัด การจับควยยัดเข้าไปในรูหีของเธอทันทีด้วยความเสียวซ่าน ผมไม่รีรอหรือว่าปล่อยโอกาสให้มันหลุดมือไปแล้ว ดันควยเข้าไปจนสุดโคนแล้วเริ่มขยับควยเย็ดเธอ ทันที ยิ่งเย็ดก็ยิ่งเสียวควย ตอนนี้ไม่รู้ว่าเธอจะเสียวหีบ้างหรือเปล่า แต่พอเริ่มกระเด้าแรงขึ้นก็เริ่ม เสียวมากขึ้น สุดท้ายสองขาของเธอก็ถูกผมจับยกขึ้นมาพาดบ่า แล้วกระหน่ำลำควยกระแทกรูหีของ เธอเข้าไปเต็มๆ แล้ววันนี้ผมก็ได้เย็ดหีแม่เลี้ยงคนสวยอย่างเต็มคราบ เสียงร่างกายกระทบกระแทกกันดังขึ้นมาอย่างหนักหน่วง ยิ่งขยับยิ่งเสียว ผมใส่ความเงี่ยนลงไปกับ แรงกระแทกจนร้อนผ่าว เนื้อตัวเต็มไปด้วยเหงื่อเม็ดโตที่ผุดพราวขึ้นมาเต็มตัว แต่แบบนั้นมันก็ยิ่งมันส์ เสียวควยฉิบหาย…แม่ครับ…แม่ครับ ผมจะแตกแล้วครับ ซี้ดดด สองขาถูกจับแยกออก ผมใส่แรงเต็มที่มองดูรูหีของเธอที่ถูกควยของผมกระหน่ำจนกระทั่งเสียงคราง ของผมดังขึ้นเต็มที่ น้ำควยทะลักออกมา ผมดันควยเข้าไปมิดด้ามแล้วปล่อยน้ำควยแตกในคารูหีของแม่ เลี้ยงทันที ยังไงซะผมก็เป็นลูกพ่อ ถ้าท้องขึ้นมา…ยังไงก็สายเลือดเดียวกันอยู่ดี เสียวหีไหมครับแม่เลี้ยง ?
