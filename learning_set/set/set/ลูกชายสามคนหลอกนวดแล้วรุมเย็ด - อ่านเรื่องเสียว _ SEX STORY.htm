ไหนจะเกรงว่าเขาจะเข้ามาเพราะรักสมบัติดิฉันบ้าง ที่สำคัญที่สุด ดิฉันห่วงลูกๆ ของดิฉันทั้งสามคนที่จะรับไม่ได้ที่ดิฉันจะมีผู้หญิงคนใหม่หรือเป็นแม่ที่ปฏิบัติตัวไม่ดีที่ไม่ครองตัวให้สมกับ เป็นแม่ของพวกแก เหมือนกับไม่เชื่อฟังดิฉัน ทั้งลูกแดน ลูกดอม และก้อง ทั้งสามต่างก็เป็นเด็กหัวแข็ง ทำตามใจตัวเอง และไม่มีสัมมาคารวะ แต่ยังดีที่ลูกๆ ของดิฉันยังรับผิดชอบเรื่องผลการเรียนได้ดี จึงไม่ทำให้ดิฉัน หนักใจนัก หลุดปากพูดมาว่า “วันนี้แม่แต่งตัวน่าฟัดจังเลย” “หูยยย แม่ ขาวจั๊วะน่าเจี๊ยะ” ซึ่งทุกครั้งที่ดิฉัน ได้ยินก็เอ็ดพวกแกไปตามเรื่อง แต่ยิ่งดูเหมือนยิ่งห้ามก็เหมือนยิ่งยุ ยิ่งพักหลังๆ บางทีพวกแกก็เข้ามาจับก้นดิฉันเอาดื้อๆ ส่วนลูกแดนนี่ยิ่งแล้วใหญ่บางทีก็แกล้งเข้ามา กอดรัดตัวดิฉันเอาเสียเลย ดิฉันก็จนใจไม่รู้จะห้ามปรามอย่างไรค่ะ เรื่องจะดุด่าลูกแรงๆ นั้น ดิฉัน ทำไม่ได้เอาเสียเลย เพราะดิฉันรักพวกแกมาก จนในที่สุด จุดเปลี่ยนของชีวิตดิฉันก็มาถึงเมื่อวันแม่ที่ ผ่านมานี้เอง ปกติลูกๆ ของดิฉันไม่ค่อยสนใจวันพิเศษอะไรตามประสาผู้ชาย แต่วันแม่ที่ผ่านมานี้อยู่ๆ ลูกดิฉันทำตัว เป็นเด็กน่ารักขึ้นมา เช้าขึ้นมาก็ปัดกวาดบ้านอย่างเรียบร้อย ไม่ไปที่ไหน อยู่บ้านรุมเอาอกเอาใจ ดิฉันเป็นพิเศษ ตกเย็นก็พาดิฉันไปทานข้าวนอกบ้าน จนดิฉันลืมความน้อยใจที่ผ่านมาไปจนหมดสิ้น พอทานข้าวเย็นเสร็จกลับถึงบ้าน ลูกก้องน้องคนสุดท้องก็เซอร์ไพรซ์ดิฉันด้วยการมอบช่อดอกมะลิวันแม่ ให้ ซึ่งทำให้ดิฉันปลื้มใจจนน้ำตาซึม โอบกอดลูกทั้ง 3 คนเข้ามาหอมแก้มคนละฟอด แล้วอยู่ๆ ลูกดอม ก็เสนอขึ้นมาว่า “แม่ครับ เดี๋ยววันนี้ผมนวดให้แม่นะครับ” “เอ๊ะ วันนี้ลูกๆ เอาใจแม่เป็นพิเศษจัง” “ก็วันนี้วันแม่นี่ ครับ พวกผมก็อยากทำอะไรดีๆ ให้แม่เป็นพิเศษ” ลูกแดน พี่ชายคนโตเสริม “ครับแม่ เดี๋ยววันนี้พวก ผม 3 คนจะช่วยกันนวดแม่ให้สบายตัวไปเลย” ลูกก้อง น้องคนสุดท้องพูดเอาใจดิฉัน ความที่ดิฉัน กำลังเป็นปลื้มกับลูกชายดิฉันทั้ง 3 คน ทำให้ดิฉันเออ ออ ห่อหมกตามพวกแก โดยหารู้ไม่ว่าตลอดวัน แม่ทั้งวัน ที่พวกแกเอาใจดิฉันนั้นเป็นเพียงแค่แผนที่จะทำให้ดิฉันตายใจ เพื่อนจะล่อให้ดิฉันต้องมาเสีย ท่าลูกชายทั้ง 3 ในท้ายที่สุด ลูกแดนเป็นคนบอกว่า สูตรที่แกจะนวดให้ดิฉันนั้น ต้องใช้น้ำมันสปาที่จะทำให้ดิฉันสบายตัวยิ่งขึ้น เลย ขอให้ดิฉันใส่แค่เสื้อกล้ามกับกางเกงขาสั้นเท่านั้น ซึ่งดิฉันก็ไม่ฉุกคิดอะไรเพราะเห็นว่าเป็นลูกของ ดิฉันเอง จึงทำตามคำลูกแดนอย่างว่าง่าย และให้ลูกๆ ทั้ง 3 ของดิฉันไปนวดตัวดิฉันในห้องนอนดิฉันเอง ดิฉันเปลี่ยนเสื้อผ้า ใส่ชุดสายเดี่ยวสีขาว กางเกงขาสั้นตัวหลวมๆ แล้วล้มตัวลงไปนอนบนเตียง ลูกดอมที่เตรียมน้ำมันไว้พร้อมก็ชโลมน้ำมันเข้ากับฝ่ามือลูบไล้ที่ท่อนแขน ทั้งสองข้างก่อน ส่วนลูกก้องก็ ไปนั่งอยูที่แขนอีกฝั่ง ลูกแดนคนโตนั้นก็ชโลมน้ำมันที่ปลายขาของดิฉัน ตอนนี้ ลูกๆ ทั้ง 3 คนก็รุมนวด ดิฉันเป็นอย่างดี ดิฉันก็นอนหลับตาพริ้มให้ลูกๆ ทั้ง 3 นวดดิฉันอย่างลืมตัว สักพัก ลูกแดนก็ชโลมน้ำมันขึ้นมาที่ขาอ่อนของดิฉัน แล้วกดนิ้วโป้งเข้าด้านใน บีบไล่ขึ้นมาจนเกือบถึง หว่างขา มือผมไปโดนอะไร” “เอ๊ะ ลูกแดนทำไมมายอกย้อนแบบนี้” ดิฉันเอ็ด แต่ลูกแดนไม่ฟังเสียง กลับขยิบตาให้ลูกดอมกับลูกก้องที่ประจำอยู่แขนของดิฉันทั้งสองข้าง ทันใดนั้นลูกแดนคว้าหมับเข้าที่ข้อเท้าดิฉัน ได้แต่สะอึกสะอื้นร้องไห้เสียอกเสียใจที่โดนลูกชายของตัวเองทั้ง 3 คนกระทำ กับดิฉันเช่นนี้ ตอนนี้ลูกแดนเอาหน้าซุกโคกหีของดิฉันที่อยู่ใต้กางเกง เอาจมูกดุนซุกพยายามแทรกเข้า ร่องหีดิฉัน ซักพัก ดอมก็ร้องถาม “พี่แดน หีแม่เป็นไงมั่ง หอมมั้ย” “หอมสิวะ ดอม มาดมมั่งสิ เดี๋ยว พี่จะลองไปเล่นนมแม่บ้าง” แล้วดอมก็สลับตัวลงไปอยู่ที่หว่างหาดิฉัน ดูด ดมที่โคกหีดิฉันเหมือนกับอด อยากมานาน แดนก็สลับมาดูดนมดิฉันบ้าง ส่วนก้อง พอละจากปากดิฉันก็สะกิดดอมพี่คนรอง แล้วเอาหน้าไปซุกหีดิฉัน ซุกไซร้อย่างตะกละ ตะกราม ดอมก็สลับขึ้นมาดูดปากของดิฉัน ดิฉันพยายามเบือนหน้าหนี ดอมก็ เอามือจิกผมดิฉันหันหน้าไปหาแก แล้วดูดปากของดิฉัน ส่วนมือก็บีบบี้หัวนมไม่หยุด ซักพัก แดนก็พูดขึ้น มา “เฮ้ย พี่ว่ามาแก้ผ้าแม่ออกกันเถอะ” แดนออกความเห็น “จะแก้ยังไงล่ะพี่ มัดแม่ไว้แน่นแบบนี้ แก้มัดออกมาเดี๋ยวก็ดิ้นอีกล่ะ” ก้องเถียง “เออ พี่มีวิธีน่า” ซักพักแดนก็ออกจากห้องไป ดิฉันเห็น แกถือมีดคัทเตอร์เข้ามา “แดน จะทำอะไรแม่น่ะ เอามีดมาทำไม!!!” ดิฉันร้องตกใจถาม “โถ แม่ อย่าตกใจไปเลย ผมไม่ได้เอามาเชือดแม่หรอก” ว่าแล้วแดนก็บรรจงหงายมีดเข้ากรีดกับเสื้อและกางเกงของดิฉัน แล้วลูกดอมกับลูกก้อง ก็ช่วยกันดึง เสื้อผ้าที่กลายเป็นเศษผ้าออก แล้วยกทรงกับกางเกงในดิฉันก็โดนจัดการไปด้วย ตอนนี้ดิฉันเปล่า เปลือยอล่างฉ่าง อวดนมอวดหีให้ลูกๆ ดิฉันดู “โหยยยย แม่โคตรขาวเลยว่ะ” ดอมครางฮือ “เออ ว่ะ นมก็ใหญ่หีก็อูม ซี้ดดดด….. ผมไม่ไหวแล้วพี่” ลูกก้อง ร้องขึ้นมา แล้วแกก็ซุกหน้าเข้ามาดูเลียไป ทั่วอกตูมดิฉัน ส่วนแดนนั้นไม่ต้องพูดถึงทันทีที่ตัดกางเกงในดิฉันออกไปก็ซุกหน้าเข้ามาดูด เลียหี ดิฉันเหมือนตายอดตายอยาก ตอนนี้ทั่วทั้งร่างของดิฉันโดนลูกชายของตัวเองดูดซดอย่างตะกละตะกราม ดิฉัน ถึงแม้จะรู้สึกเสียใจที่โดนลูกชายในไส้ของตัวเองรุมปู้ยี่ปู้ยำ แต่ด้วยความที่ดิฉันห่างมือผู้ชายมา นาน ความโหยหาที่เก็บกดในใจตลอด 5 ปีที่ผ่านมาก็คุโชนขึ้นมาจากการโดนลูกปลุกเร้า ความเสียว กระสันต์เพิ่มพูนขึ้นมาทีละน้อยทีละน้อย ตอนนี้ดิฉันเริ่มมีเสียงร้องครางสลับกับเสียงสะอื้น ลูกๆ ดิฉัน ทั้ง 3 คนต่างก็สลับกันเข้ามาดูดดื่มดิฉัน ตอนนี้ทั้งนมทั้งรูหีดิฉันโดนไล้เลียไม่หยุด ซักครู่ดิฉันก็เริ่ม หยุดเสียงสะอื้น กัดฟันทนความเสียว ไม่กล้าแสดงอารมณ์ให้ลูกรับรู้ แต่ทุกจังหวะที่ลูกๆ ของดิฉันดูด เลียก็สร้างความเสียวสะท้านให้ดิฉัน จนดิฉันเริ่มสูดปาก ร้องอุ๊ย ซี้ดดด….ตามความเสียวซ่านที่ได้รับ “เฮ้ย แม่เริ่มเสียวแล้วพี่” ดอมบอกแดน “เออ ว่ะ ดูหีแม่สิ น้ำเยิ้มออกมาเยอะเลยว่ะ” แดนเอา นิ้วเสียบเข้ารูหีดิฉัน ล้วงเอาน้ำเงี่ยนในรูหีชูขึ้นมาแล้วแยกนิ้วออกเผยให้เห็นความเหนียวยืดของน้ำ เงี่ยนดิฉันเอง ดิฉันเบือนหน้าหนีด้วยความอับอายที่ดิฉันเสียวซ่านกับลูกในไส้แท้ๆ ของดิฉันเอง “หุยยย….. รูหีแม่ฟิตชิบหายเลยว่ะ” แดนเอานิ้วชี้เสียบเข้าออกรูหีดิฉันเป็นจังหวะ “ไหนๆ ขอผมดู มั่งดิพี่” ว่าแล้วทั้งดอมและก้อง ก็มานั่งรุมดูรูหีดิฉันที่ตอดรัดนิ้วชี้ของแดน ดิฉันทั้งรู้สึกอายทั้งรู้สึกเงี่ยน ที่โดนลูกๆ รุมเข้ามาดูดรูหีดิฉัน ทันใดนั้นเอง ดอมก็พยายามเอานิ้วชี้ของแกเบียดแทรกเข้ารูหีดิฉัน ทั้งๆ ที่มีนิ้วชี้ของแดนเสียบคาอยู่ “พี่ว่าหีแม่รับนิ้วชี้เราสองคนได้มั้ย” ดอมร้องถาม “ได้สิวะ แค่นิ้วชี้ สองนิ้วเอง หีผู้หญิงน่ะ ควยใหญ่ กว่านี้ เยอะยังรับได้เลย” ว่าแล้วดอมก็เสียบนิ้วเข้ารูหีดิฉัน ดิฉันสะดุ้งขึ้นมาเพราะรู้สึกคับแน่นขึ้น ส่วนลูกก้อง เห็นพี่ชายสองคน ทำก็เอาอย่างบ้าง หงายมือแหย่นิ้วกลางเข้ารูหีของดิฉันเพิ่มขึ้นมาอีก ตอนนี้หีดิฉันก็โดนนิ้วของลูกชาย ทั้ง 3 เย็ดพร้อมๆ กัน ดิฉันหลับตาปี๋ ร้อง “อออออออออี๊” ขึ้นมาดังๆ เพราะนิ้วมันไปกันคนละทิศคน ละทางแยงคว้านในรูหีดิฉันจนรู้สึกเสียวจี้ดขึ้นมา “ดูสิ แม่เสียวใหญ่เลยว่ะ” ดอมพูด “อูยยยย พี่ผม ไม่ไหวแล้วพี่” ก้องร้องบอก “ผมขอเย็ดหี แม่ก่อนนะพี่ ผมเงี่ยน จริงๆ” “เออ ได้สิ เฮ้ยดอม ให้ไอ้ก้องมันเย็ดแม่ก่อนนะ” แดนบอกเก่ง แล้วเก่งก็พยักหน้ารับ ว่าแล้ว ก้องก็ลุกขึ้นไปถอดเสื้อผ้า เหลือแต่ตัวเปล่าเปลือย ดิฉันเห็นควยของก้องดีดผึงออกมาจาก กางเกงใน แข็งปั๋งเต็มที่ มีน้ำเหนียวๆ ไหลซึมที่ปลายหัวควย ส่วนแดนกับดอมก็เข้ามาขนาบกดตัว ดิฉันแน่นเพื่อไม่ให้ดิฉันดิ้นหนีไปที่ไหน “ก้อง…ก้อง…อย่าลูก นี่แม่ของลูกนะ อย่าทำอะไรแม่เลยนะ” กระหน่ำกระเด้ารูหีดิฉันอย่างรุนแรง ก้องกระหน่ำเย็ดรูหีดิฉันอย่างไม่ลดละ เสียงหนอกควยกระทบเนินหีดังปับๆๆๆๆ ลั่นห้อง ดิฉันได้แต่กัด ฟันรองรับแรงเย็ดจากเด็กน้อยอย่างก้อง ก้องเย็ดดิฉันไม่ยั้งปากก็ร้องคราง ออ๊ากกกซ์” แล้วก้องก็กระแทกเข้ามาครั้งสุดท้าย ฉีดน้ำรักของแกแตกใน พ่นใส่รูหีดิฉัน ทันทีนั้นดิฉันก็ถึงจุดสุด ยอดขึ้นมาขึ้นเสียงหลง “ว้ายๆๆๆๆๆๆ ก้อง ก้องจ๋า ก้องลูกรักของแม่ โอ๊ยๆๆๆๆๆๆๆๆๆ” ก้อง ฟุบหน้า
