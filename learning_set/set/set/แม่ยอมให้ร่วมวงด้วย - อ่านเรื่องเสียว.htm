*เรื่องเสียว แม่ยอมให้ร่วมวงด้วย* ชีวิตผมไม่ได้อยู่กับพ่อแม่มาตั้งแต่เล็ก ปู่ย่าและตายายผลัดกันเอาผมมาเลี้ยง ท่านๆรักผมๆเป็นเด็กว่านอนสอนง่าย พ่อแม่มีผมคนเดียว ท่านมีงานธุรกิจที่รัดตัวมาก จะมาเอาผมไปอยู่ด้วยก็วันหยุด จนผมเข้าสิบหกเป็นหนุ่มหล่อ แต่พ่อผมเสียเพราะโรคร้าย จากนั้นแม่ก็เป็นหม้ายเนื้อหอมทั้งยังสาวและสวย ผมสิบเจ็ดหลังพ่อเสียได้ปี แม่มารับผมไปอยู่ด้วย ผู้ใหญ่เห็นว่าผมโตแล้ว และอยู่กับแม่ใกล้ที่เรียน แม่ก็เหงาเราอยู่กันสองคน ผู้ใหญ่จะแวะมาเป็นครั้งคราวดูทุกข์สุขผม ผมเรียนกวดวิชาบางวันกลับบ้านดึก ผมเป็นอิสระมากขึ้นจากผู้ใหญ่ ผมเริ่มเที่ยวเตร่ รู้จักสาวๆและพึ่งรู้ว่าเพศผู้เพศเมียผสมพันธุ์กันมีเพศสัมพันธ์สมสู่ไม่มีลูกก็ได้ ผมนี่โง่จัง ผมดูจากหนังอย่างว่า ศึกษาจากเพื่อน ลุงป้าที่บ้านปู่ไม่เคยพูดสอนเรื่องนี้ บ้านปู่มีแต่ผู้หญิง ผมอยากจะลองของจริงสักทียังไม่กล้า มีแต่เพื่อนชวนดูโชว์ ผมอยู่กับแม่ได้เกือบปี บางทีผมเห็นแม่มีเพื่อนสาวสนิทวัยพอๆกันจะสี่สิบ (แม่ผมสี่สิบ) ผมเรียกเธอว่า”น้า ส้ม” เธอเป็นแม่หม้ายสามีตาย หัวอกเดียวกับแม่ เธอเป็นหุ้นส่วนทำธุรกิจกับแม่ด้วย บ่อยที่เธอมาหาแม่ประจำและนอนค้าง บ้านเราชั้นเดียวมีสองห้องนอน เธอก็นอนกับแม่ น้าส้มเป็นคนสวยพอๆกับแม่ ผมเรียนกวดวิชาบางวันวันนั้นผมกลับดึก ผมเข้าบ้านทางประตูหลังปกติ แต่วันนั้นเดินอ้อมไปอีกด้าน ผ่านห้องแม่ เพราะรถน้าส้มจอดเกะกะ ผมคิดว่าเธอมาค้างที่บ้านอย่างเคย บังเอิญม่านหน้าต่างห้องแม่ที่เปิดแอร์เย็นสบายปิดไม่สนิท มีแสงไฟรอดออกมาผม เลยมองเข้าไป หัวใจผมแทบวาย ที่ได้เห็นน้าส้มนอนหงายยันศอกซ้ายกางขา หันหัวมาทางผม โดยมีแม่ผมซุกหน้าอยู่ในระหว่างขา ใต้ชุดนอน มือขวาเธอกดลูบหัวแม่สลับลูบบีบหน้าอกตัวเอง ผมรู้ว่าสองสาววัยกลางคนทำอะไรกัน นี่หนังสดต่อหน้าต่อตาไม่ใช่หนังแผ่นที่ดูบ่อยๆ ไม่ใช่โชว์ที่เคยดูหลายครั้ง มันตื่นเต้นกว่ามาก สักพักแม่คนสวยของผมเปลี่ยนขึ้นมานั่งคร่อมทับที่หน้าน้าส้ม ถลกชุดนอนขึ้น มือเกาะราวหัวเตียงหลับตาเคลิ้มส่ายเอว ผมไม่เห็นอะไรมาก หัวเตียงที่หันมาทางหน้าต่างบังสายตาผม แต่แล้ว แม่ก็ปลดชุดนอนลงจากไหล่ทำให้ผมได้เห็นเต้านมแม่ ถึงจะไม่ถนัดเต็มตาแต่ก็เห็นว่าเป็นเต้าลูกขาวผ่องไม่ใหญ่นัก แม่บีบลูบไล้นมตัวเอง แล้วลงนอนกอดกับน้าส้ม ผมไม่เห็นอะไรมาก ขอบหน้าต่างและช่องม่านบังมุม เห็นแค่ร่างสองคนตะคุ่มๆกอดฟัดกัน ผมเข้าบ้าน แล้วจัดการกับตัวเอง จากวันนั้นอีกสองวันผมรู้น้าส้มจะมา ผมพยายามกลับผิดเวลา เพื่อแอบดูได้เห็นอีกครั้ง แต่ไม่ชัดม่านห้องแม่ปิดมิดชิด อีกอาทิตย์ผ่านไป จึงได้เห็นอีกชัดเจน ช่องม่านเปิดกว้าง ทั้งคู่นั่งกอดจูบจับเต้านมกันที่เก้าอี้นวมในชุดนอนผ้าชีฟองเบาบาง พอดีน้าส้มหันมาเห็นม่านที่ปิดไม่สนิท ผมรีบเดินหนีคิดว่าเธอคงไม่เห็นผม ผมเข้าบ้านอาบน้ำ บ้านเราเล็กมีห้องน้ำเดียว ผมกำลังจะจิตนาการจัดการกับตัวเอง อยู่ๆน้าส้มก็เปิดประตูห้องน้ำ(ผมลืมล็อกประตู) เธอเห็นผมกำลังยืนชักว่าว เธอแกล้งถาม “ทำอะไรแมน?”(ชื่อเล่นผม) ผมตกใจเขินอายรีบเอามือปิดควยโด่ เธอกลับยิ้มบอก “แอบดูน้ากับคุณแม่ แล้วเก็บกดก็อย่างนี้แหละ” ผมยิ้มแหย(นี่เธอรู้ว่าผมแอบดู) เธอกลับบอก “อย่าชักว่าวเลย ใส่ผ้าแล้วออกมานี่สิ” ผมทำตามเธอ นั่งรออยู่หน้าที่ห้องกลาง เธอบอกให้ผมนั่งข้างๆเธอ “สามครั้ง ผมขอโทษครับ” เธอทำปากจู๋หน้าย่น “ตายหละ แล้วชักว่าวทุกทีสิ” ผมพยักหน้า เธอทำขบคิดแล้วบอก “ชักว่าวไม่ดีเสียสุขภาพหมด” ผมก้มหน้า เธอพึมพำ “น้าจะพูดยังไงดี” ผมมองเธอ “ผมจะไม่แอบดูน้ากับแม่อีก” เธอบอก “ไม่ใช่..น้ากับคุณแม่ไม่ได้ว่าอะไร .. อือ..เอาอย่างนี้ไม่อ้อมค้อม..น้ากับแม่เราเป็นคู่กัน ทำอย่างที่แมนเห็นมาปีแล้ว ตั้งแต่คุณพ่อตาย” ผมถาม “น้าเป็น lesbian เหรอ?” เธอสั่นหน้า “ไม่ใช่ แต่ไม่มีทางออกที่ดีกว่านี้ แมนยังชักว่าวเลย คงเข้าใจเรามีความต้องการเหมือนกัน แต่เราก็เบื่อแบบนี้แล้ว” ผมเลยว่า “ก็หาแฟนใหม่สิ” เธอยิ้มๆ “พูดง่าย แต่น้าไม่อยากมีปัญหา แมนไม่หวงคุณแม่เหรอ?” เธอถามแปลกๆ ผมพยักหน้าบอก “ก็หวงแม่เหมือนกัน แต่ถ้าแม่จะมีใหม่ ผมก็ไม่ว่า แม่ยังไม่แก่ยังดูสาวสวยคงหา ไม่ยาก” เธอบอก “คุณแม่ไม่อยากไปเป็นเมียใครอีก คิดถึงเป็นห่วงแมน” ผมถาม “แล้วน้าจะให้ผมทำไง?” เธอถอนหายใจบอก “แมนเอาแม่กับน้าเป็นเมียสิ” ผมตกใจแทบตกเก้าอี้ “น้าพูดอะไร?” เธอย้ำ “น้าพูดจริงๆ ไม่รู้จะบอกยังไง น้ารักแมน พี่อ้อย(แม่ผม)ก็ด้วย เอาเราเป็นเมียไปพลางๆก่อนสิ จนกว่าแมนจะมีเมียจริงๆ จะได้ไม่ต้องเก็บกดมาชักว่าวให้เสียสุขภาพ” ผมนิ่งอึ้งไปขณะ เธอถามอีก “หรือแมนรังเกียจเราว่าแก่ไป” ผมสั่นหน้า “แม่ก็ยังสาว น้าก็สวย…แต่แม่” เธอเอามือแตะปากผมแล้วบอก “ไม่พูดคำว่าแม่ ถ้าตกลงให้พูดว่าพี่อ้อย พี่อ้อยก็เป็นผู้หญิงคนหนึ่ง คิดแค่นั้นเวลานี้” ผมถาม “แล้วพี่อ้อยว่าไง?” เธอยิ้ม “เรียกพี่อ้อยแสดงว่าตกลงแล้ว พี่อ้อยไม่มีปัญหา เธอเป็นคนพูดเรื่องนี้เอง
