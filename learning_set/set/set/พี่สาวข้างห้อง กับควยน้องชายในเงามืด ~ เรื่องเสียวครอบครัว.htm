เรื่องเสียวแนว ครอบครัว เรื่องเสียวพี่น้อง – พี่สาวข้างห้อง กับควยน้องชายในเงามืด มันเริ่มจากแค่คืนหนึ่ง…คืนที่ห้องนอนบางไปหน่อย เสียง "จ๊วบ…จ๊วบ…" แผ่วเบา ลอดผ่านกำแพง กลิ่นสบู่ กลิ่นน้ำหอมพี่เจน พี่สาวแท้ๆ ของผม…ลอยออกมาพร้อมเสียงครางเบาๆ “อื๊ออ…อือ…ซี๊ดดด…แน่นอีกแล้ว…ควยแน่นมากเลยยย…” เสียงเธอครางเบาหวิว แต่มันทำให้ควยผม แข็งเปรี๊ยะในกางเกงบ็อกเซอร์ พี่สาวผม…กำลังช่วยตัวเอง และเธอก็พูดถึง "ควย" อย่างเสียว ซ่าน ราวกับในจินตนาการนั้น…มันใหญ่ มันลึก…และเธออยากได้มันยิ่งกว่าอะไร ผมแนบหูฟังกับผนัง กำปั้นจิกหมอนตัวเองแน่น ภาพในหัวคือพี่เจน…ผมยาว หุ่นสะบึม นมใหญ่เอวคอด ขาขาวเนียน เธอไม่ใช่แค่พี่สาว…เธอแม่งคือฝันเปียกทั้งชีวิตผม เงามืดในห้องน้ำ – จุดเริ่มต้นของความเงี่ยนที่ห้ามไม่ได้ อีกคืนหนึ่ง ผมกลับบ้านดึก เปิดประตูเบาๆ…เดินผ่านห้องน้ำที่ประตูแง้ม ไอน้ำอุ่นยังคลุ้ง กลิ่นสบู่หอม แสบจมูก แล้วผมก็เห็น…เห็นเธอกำลังยืนเปลือยอยู่หน้ากระจก มือหนึ่งลูบเต้านมที่เด้งตึง มืออีกข้าง สอดเข้าไปลูบหีเบาๆ ผมแทบไม่กล้าหายใจ…ตาแทบหลุดจากเบ้า นิ้วพี่เจนแหวกกลีบหีออก ช้าๆ น้ำใสๆ หยดลงมาตาม ต้นขา เธอเบียดขาเข้าหากัน แล้วกระซิบเสียงคราง "ควยน้อง…ถ้าได้ลองสักที คงแน่น…แน่น เต็มรูแน่เลย…" ผมเกือบชักน้ำแตกตรงนั้น เธอไม่ได้เห็นผม…แต่ผมเห็นเธอทั้งตัว หีที่เกลี้ยงเกลา นมที่เต่งตึง หัวนม สีชมพูชูชัน เสียงนิ้วแหย่หีดัง “แจ๊ะๆๆ…” ห้องนอนกลางดึก – พี่สาวเปิดทางให้น้องชาย ผมทนไม่ไหว… กลางดึก ผมแง้มประตูห้องเธอเบาๆ ไฟในห้องมืด มีแค่แสงจันทร์ลอดม่าน พี่เจนนอน หงาย ผ้าห่มหลุดไปครึ่งตัว เสื้อกล้ามสีขาวบางจนนมโผล่ หัวนมแข็งปูดใต้ผ้า กางเกงในลูกไม้สีดำ แนบแน่นกลางหว่างขา ควยผมแข็งจนปวด…ผมเดินเข้าไปช้าๆ นั่งข้างเตียง แล้วค่อยๆ เอื้อมมือจับขาพี่สาว เธอขยับเบาๆ แต่ไม่ตื่น ผมค่อยๆ ลูบไปจนถึงหว่างขา แล้ววางมือทับเนินหีที่ร้อนผ่าว เธอครางเบาๆ “…อื๊อ…” ขยับตัวเบาๆ แต่ไม่ห้าม ผมรู้เลยว่าเธอไม่ได้หลับสนิท…และเธอก็ไม่ขัดขืน ผมเลื่อนกางเกงในเธอลง เห็นหีเนียนสวยที่ชุ่มแฉะ แล้วก้มลงไปเลีย… เลียหีพี่สาว – หีรสชาติพี่สาวแท้ๆ ที่ไม่มีวันลืม ลิ้นผมแตะที่ติ่งเสียวของพี่เจน “อ๊ะ…อ๊ะ…อื้อออ…” เสียงเธอดังขึ้น มือเธอจิกหัวผมแน่น ผมดูดเม็ดแตดเธอแรงๆ ดูดจนเธอเกร็ง ขาเกร็ง หน้าท้องสั่น น้ำหีเธอหวานแปลกๆ กลิ่นสบู่อ่อนๆ ผสมกลิ่นคาวเพศ "เย็ดเถอะ…น้อง…พี่ไม่ไหวแล้ว" คำพูดนั้นดังจากปากเธอ เสียงจริง…เต็มไปด้วยความหื่น ผมถอดกางเกง จับควยตัวเองจ่อที่ร่องหี หัวควยถูไปตามรอยแยก พี่สาวสั่นเบาๆ "ใส่มาเลย…พี่ อยากโดนเย็ดจากน้อง…" แล้วผมก็กดควยเข้าไปช้าๆ หีพี่เจนร้อนจัด…แน่น…ตอด เสียง “ซวบบบบ…” ดังในความเงียบ ควยน้องชาย – ความเงี่ยนที่ฝังแน่นในครอบครัว ผมเริ่มซอยเบาๆ พี่เจนครางเสียงแหลม “อ๊ะ! อ๊ะ! ควยแน่น! แม่งแน่นเต็มรูเลย!!” เสียงเนื้อกระแทกกันดัง “พั่บ! พั่บ! พั่บ!” เต้านมเธอกระเพื่อมขึ้นลง จุกนมแข็งจนผมต้องก้มลงดูด "พี่เสียวหี…หีตอดควยน้อง…โอ๊ยยยย…พี่แตกแล้วววว!!" น้ำหีเธอทะลักออกมาเต็มลำ แต่ผมยังไม่พอ ผมจับเธอพลิกคว่ำ ยกสะโพกขึ้น แล้วเสียบควยเข้า ท่าหมาแบบไม่รอ เสียงเนื้อกระแทกตูดดังลั่นห้อง เธอคราง "เย็ดหีพี่แรงๆ เลย…ทำให้พี่ท้องควยน้อง!" แตกใน – คำขอของพี่สาวที่เงี่ยนจนควบคุมตัวเองไม่ได้ “แตกในเลยนะ…น้อง…พี่อยากรู้ว่ารู้สึกยังไงเวลาน้ำเงี่ยนไหลเข้าหี” ผมซอยแรงขึ้น ควยกระแทกจนพี่สาวสั่นไปทั้งตัว มือจิกที่นอน เสียงครางสั่นสะท้าน “อ๊าาาา!! อื้ออออออ!! แตกในเลย!! แตกใน!!” ผมคำรามในลำคอ แล้วกระแทกสุดลำ น้ำเงี่ยนพุ่งเข้ารูหีเธอแบบไม่ยั้ง อุ่น เหนียว ล้นไหลย้อนออกมา เราทั้งคู่หอบหายใจ เสียงเงียบไปนอกจากเสียงหัวใจเต้นแรง ผมกอดเธอจากด้านหลัง กระซิบ “พี่ …หีพี่แม่งโคตรดีเลย” พี่เจนยิ้มทั้งน้ำตา แล้วตอบว่า “แล้วคืนนี้…อย่ากลับห้องนะ…มาเย็ดพี่อีกรอบตอนตีสองนะจ๊ะ…” Share: // // //
