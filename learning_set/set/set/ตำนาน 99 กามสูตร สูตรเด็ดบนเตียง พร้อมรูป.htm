โดยแยกขาออกจากกัน ผู้ชายเข้าใกล้ระหว่างขาของเขาและเกิดการปฏิสนธิของทั้ง คู่ ผู้หญิงโอบขารอบผู้ชายคล้ายกับขากบ และเริ่มบรรเลงได้เลย ท่ากบ (FROG) ท่าแขนซ้าย (RIGHT ARM) ผู้หญิงนอนหงายและหันแขนไปด้านข้าง ชายคนนั้นคุกเข่าและเข้ามาจากด้านหลัง เขาเหยียดขาข้าง หนึ่งในขณะที่หักอีกข้างหนึ่ง นี่คือวิธีการผสานเกิดขึ้น ท่าแขนซ้าย (RIGHT ARM) ท่าทราเวิร์ส (TRAVERSE) ผู้หญิงคนนั้นต้องนอนตะแคง โดยกางมือออก ผู้ชายนอนตะแคงโดยให้ร่างกายตั้งฉากกับผู้หญิง และผู้ หญิงจะยกขาส่วนบนขึ้น ส่วนตัวผู้ชายจะเข้าไปอยู่ระหว่างขาในลักษณะนี้ ท่าทราเวิร์ส (TRAVERSE) ท่าน้ำตก (WATERFALL) ผู้ชายนั่งอยู่บนเก้าอี้
