ทุกหนทุกแห่งบนเรือนร่างของแม่ไม่มีที่ใดรอดจากการถูกสัมผัสเล็มเลียด้วยลิ้นของผมไปได้ แม้แต่จุดที่ผู้ชายบางคนรังเกียจ ผมก็ไม่สนใจ ใช้นิ้วแหวกแคมอันแดงระเรื่อชุ่มด้วยน้ำสวาทที่หลั่งออกมาล้นเยิ้มออกมาจนไหลเลอะร่องก้นไปด้วย พร้อมใช้ปากและลิ้นดูดเลีย ร่องแคมเหมือนคนหิวกระหาย ดื่มกินไม่รู้จักอิ่ม สะโพกผายของแม่ร่อนแนบชิดกับริมฝีปากผมเหมือนไม่อยากจะจากไปไหน มือทั้งสองเกร็งจิกกับผนังโซฟาเหนือศรีษะจนเป็นร่องลึก ดวงตาหลับพริ้มเหมือนกับ ไม่อยากรับรู้กับสิ่งเลวๆที่เกิดขึ้นกับตัวเอง แม้กระทั้งความร่านอยากในใจตนซึ่งไม่เคยโดนทำรักด้วยปากมาก่อนแม้แต่ กับสามีของตนเอง ยังไม่เคยทำเลย ทั้งๆที่ตนเองปรารถนาสิ่งนั้นมานานก็ตาม แต่ไม่ กล้าบอกสามี พอมาเจอสิ่งที่ใคร่อยากจะสัมผัส อารมณ์อัเร่าร้อนก็ เลยเตลิดแม้ว่าผู้กระทำสิ่งนั้นให้ จะเป็น ลูกชายที่เธอรักใคร่ถนุถนอมมาตลอดเวลา จนกระทั้งร่างของแม่กระแดะแอ่นขึ้นสุดๆนั่นแหละ ผมจึงรู้ว่าเธอถึงจุดสุดยอดแล้ว เมื่ออารมณ์ใคร่ของแม่สงบลง ความรู้ผิดชอบชั่วดี ก็ เกิดขึ้น เสียงร้องไห้โฮก็เกิดขึ้น จากความอดสูใจของเธอ แม่ยกมือปิดหน้าร้องไห้ พาร่างเปลือยของตนวิ่งเข้าห้องน้ำ ทิ้งไว้เพียงคราบความใคร่ ที่เธอหลั่งออกมาเลอะโซฟา ช่วงนั้นผมไม่รู้จะทำยังไงทั้งๆที่ยังไม่ได้ สอดใส่ ท่อนที่ผมคิดว่าใหญ่โตกว่าของพ่อตนเองมากนัก เลยตัดสินใจเดินโทงๆ ตามแม่ไปที่ห้องน้ำ ซึ้งตอนนี้มีเสียงฝักบัวดังขึ้น เธอคงชำระล้างคราบไคลของตนเอง คงเพราะความรีบร้อนของแม่เลยลืมล็อคประตูห้องน้ำ ผมเปิดประตูห้องน้ำเข้าไปกอดแม่ ซึ่งยืนให้น้ำจากฝักบัวราดรดตัวเองอยู่ ผมหอมแก้มแม่แล้วสวมกอดร่างของแม่ แล้วกระซิบข้างหูว่า ผมต้องการแม่มากที่สุด ปรารถนาใจตัวเธอมาตลอด ตั้งแต่แอบเห็นเธอกับพ่อร่วมรักกัน แม้แต่ตอนเปลี่ยนเสื้อผ้า จนกระทั้งเห็นแม่ช่วยตัวเองในห้องน้ำตอนที่พ่อไม่อยู่ หรือแม้แต่ตอนที่เลิกกันแล้ว ทุกวันเลย พอผมพูดถึงตอนนี้แม่นิ่งอึ้ง ก้มหน้าไม่ยอมสบตาผม เนื่องจากผมยังไม่เสร็จก็เลยซุกไซร้ซอกคอขาวผ่องของแม่ เปลี่ยนมือที่โอบกอดเอวแม่มาเป็นใช้นิ้วชี้กระแซะร่องแคมของเธอแทน จากท่อนขาที่เบียดชิดติดกันในตอนแรก เมื่ออารมณ์เริ่มเคลิดอีกครั้งท่อนขาอันอวบอัดก็เริ่มถ่างออกอ้ารับนิ้วกลางของผมที่กระแซะร่องลึกเข้าไปอีก ซ้ำยังลูบไล้สัมผัสติ่งแห่งความเปียกจนแม่ต้องสะดุ้งกระตุกสะโพกเป็นระยะๆ คงด้วยสำนึกของความเป็นแม่ทำให้เธอไม่ยอมง่ายๆนัก ผมต้องใช้ปากประกบปากแม่ดูดดุนจนแม่หายใจแทบไม่ทัน มืออีกข้างก็ตะโบมจับเต้านมที่ชูชันทั้งสองข้างอย่างไม่ให้เธอตั้งตัวได้ ส่วนช่วงล่างก็พยายามสอดขาเข้าไปจนได้ จนแม่เริ่มรู้ว่ามือที่สอดใส่ในร่องเสียวของตนไม่ใช่นิ้ว แต่เป็นส่วนหัวอันบานใหญ่ของลูกชาย ที่ค่อยๆสอดผ่านปากร่องแคมของตัวเองเข้ามาด้วยความคับแน่น เพราะผมดันแม่ไปติดผนังห้องน้ำทันที ลำตัวส่วนกลางของผมซึ่งแทรกหว่างขาแม่เข้าไปได้ ผมก็ เริ่มใช้หัวบานอันใหญ่ของผมขยี้ปากร่องเสียวและเสียดสีกับติ่งกระสัน จนแม่เริ่มเผลอตัวแบะขาออก เพราะอารมณ์ความใคร่
