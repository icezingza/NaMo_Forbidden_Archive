ยังไม่รู้ประสีประสา แต่มาถึงตอนนี้พอเรียบเรียงเหตุการณ์ได้แล้วก็รู้สึกสยิวมากๆ ครอบครัวของดิฉันดูเหมือนจะเป็นครอบครัวปกติทั่วไป อยู่กันพ่อแม่ลูก นอนด้วยกัน พ่อกับแม่ก็จะเย็ด กันข้างๆ ฉันอยู่ประจำ ด้วยความเป็นเด็ก ทุกครั้งที่เสียงดังทำให้ฉันตื่น แม่กับพ่อก็จะบอกว่า เขาเล่นมวยปล้ำกันอยู่พร้อม หัวเราะในความไร้เดียงสาของเรา แต่เรื่องไม่ได้มีแค่นั้น วันนึงเราตื่นจากนอนกลางวัน เดินเข้า ไปในครัว เห็นแม่กำลังนั่งยองๆ อมควย ผู้ชายคนนึงอยู่ ผู้ชายคนนั้นคือ อาบ อย เพื่อนร่วมงานพ่อ แกไปๆ มาๆ บ้านของเราจนสนิทกัน (ตอนนี้ดิฉันเข้าใจแล้วว่าทำไมอาบอยมา เล่นบ้านของเราบ่อยๆ มาเล่นชู้กับแม่นี่เอง) อาบอยสะกิดแม่ที่กำลังดูดควย อย่างได้อารมณ์อยู่ ให้ หันมามองที่ดิฉัน แม่ตกใจเล็กน้อยแล้วก็หยุดทำรักให้อาบอย แล้วก็เดินมาอุ้มดิฉันพร้อมถามว่าตื่นแล้ว เหรอลูก ฉันเลยถามไปว่าแม่ทำอะไรกับอา แม่ตอบว่ากำลังทำกับข้าวกับอา ..แล้วไอ้แท่งยาวๆ ที่ แม่กำลังกินคืออะไร แม่ตอบกลับมาว่ามะเขือหน่ะลูก แม่กำลังกินมะเขือ ฉันถามต่อว่าอร่อยมั้ย แม่ ตอบกลับมาว่าก็อร่อยดี (แม่ตอบพร้อมหัวเราะ) หลังจากนั้นแม่ก็พาฉันมาที่โซฟา แล้วก็เปิดการ์ตูนให้ดู แล้วเธอก็บอกว่าหิวยัง เดี๋ยวแม่ไปทำอะไรให้ กินนะดูการ์ตูนอยู่นี่ เดี๋ยวแม่ไปในครัวต่อ (แม่คงกลับไปสนุกกับอาบอยต่อ) และหลายๆครั้งดิฉันเห็น แม่กับอาอยู่ด้วยกันบ่อยมากๆ ทุกครั้งที่พ่อไม่อยู่ มีอยู่ครั้งนึง ฉันนั่งดูการ์ตูนอยู่โซฟา เขาทั้งสองเย็ดหี กันอยู่ข้างๆ โดยที่ อาบอยนั่งดูอยู่ถัดมาข้างๆ แล้วแม่ก็นั่งอยู่บนตักอาขยับไปขยับมาเบาๆ แท่งควยของอาคงสอดใส่เข้า ไปในร่องถ้ำแม่อยู่ ซักพักทั้งสองก็ซุบซิบๆ แล้วอาก็อุ้มแม่ออกไปทั้งอย่างนั้น คือพอทั้งสองเอากันให้ฉัน เห็นบ่อยเข้าๆ เลยกลายเป็นเรื่องปกติเลย (ในตอนนั้นคงเพิ่มอารมณ์ให้ทั้งสองเป็นอย่างมาก) แต่ที่ ทำให้อึ้งมากคือ บางวันแม่เอากับอาเสร็จแล้ว ตกดึกก็เย็ดกันกับพ่อต่อ (พลังเงี่ยนของแม่มีเยอะมาก) และมีอีกครั้งนึงที่พอคิดย้อนกลับไปกี่ทีก็ติดตามาก ตอนนั้นแม่กำลังอาบน้ำให้เรา แล้วจู่ๆ ซักพักอาบอย ก็เข้ามาอาบด้วย อาบอยทักทายและลูบหัวดิฉันว่าขออาบด้วย พร้อมถือเรือของเล่นมาให้ แม่ก็บอกว่า ให้อาบด้วยนะ ดิฉันด้วยความเป็นเด็กก็ไม่ได้คิดอะไรฉันก็เล่นน้ำอยู่ในอ่างกับของเล่น โดยที่แม่กับอา อาบฝักบัวอยู่ข้างๆ ก่อนทั้งสองจะนัวกันอยู่ข้างๆ อาบอยก็คิดทะลึ่งขอให้ฉันช่วยถูสบู่ให้แม่ ด้วยความ ยังเด็กฉันก็มาเล่นถูสบู่ด้วยด้วยความสนุกสนาน เราทั้งสองก็ได้ร่วมกันถูสบู่ทั่วร่างกายของแม่ โดยที่แม่บิดตัวไปบิดตัวมาด้วนความเสียวจากมือของ เราทั้งสองโดยมืออาก็รู้งานเล่นหีเล่นนมของแม่ จนครางออกมาเบาๆ
