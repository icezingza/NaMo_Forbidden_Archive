ผมแอบชอบน้าสาวตัวเองอยากลองสักครั้งว่าคนรุ่นนั้นจะมีอารมณ์ เซ็กส์แค่ไหน ยิ่งกับน้าสาวผมเองที่เป็นคนเรียบร้อยเงียบๆ ออกจะระเบียบจัดมั้งครับ น้าสาวผมชื่อ แต๋วอายุตอนนั้นประมาณ 39 ปี แกชอบเชื่อเรื่องไสยศาสตร์มาก รูปร่างหน้าตาน้าสาวผมถือว่าสวยมาก ร่างบางสมส่วนสูงราว 165 สามีแกต้องทำงานต่างจังหวัดบ่อยๆ ยายเลยให้ผมไปอยู่เป็นเพื่อนแกคอยช่วยแกขายข้าวเก็บร้าน ประมาณนี้ครับ วันนั้นวันเสาร์ผมจำได้ดีมาก น้าสาวชวนผมไปบ้านที่เค้าทรงเจ้า แล้วเจ้าก็ทักว่าระวังตัวหน่อยดวง ไม่ดีถึงขั้นพิการก็ว่าได้ แกตกใจและออกจะวิตก เจ้าที่ทรงเลยบอกน้าสาวผมว่า อย่ากลัว คนที่จะ ช่วยได้คือเด็กผู้ชายที่เกิดวันเสาร์หรืออาทิตย์ ถ้ามีพามาหาแกแล้วจะบอกวิธีสะเดาะเคราะห์ให้ น้าสาวผมบอกว่าพอดีเลยพามาด้วยพอดี เจ้าเลยเรียกผมเข้าไปแล้วให้น้าสาวผมรอข้างนอก แล้ว เจ้าที่ทรงก็บอกว่าช่วยน้าสาวเอ็งหน่อยจะทำไงก็แล้วแต่เอ็งจะคิดแค่นี้แหละ แล้วเจ้าก็เรียกน้าสาว ผมเข้าไปบอกว่าข้าบอกวิธีไปแล้วที่เหลืออยู่ที่เอ็งว่าจะทำได้มั้ย จำไว้ปล่อยไปตามพิธีห้ามฝืนหรือ ล้มเลิกเด็ดขาด พอเรากลับถึงบ้าน น้าสาวถามผมว่าต้องทำไง ผมบอกว่า เอาผ้ามาปิดตาผมปิดตาน้าแล้วนอนไกล้กัน ที่เหลือก็ปล่อยไปเพราะจะมีสิ่งที่มองไม่เห็นควบคุมเอง แล้วผมกับน้าก็นอนไกล้กันตรงลานหน้าทีวี ผม ลุกขึ้นเอาผ้าปิดตาออก แล้วจับน้าสาวให้กางแขนกางขาแกก็ทำตามแล้วผมก็เอาปากคาบเสื้อดึงขึ้นจน เลยอกแกสะดุ้งแต่นิ่ง แล้วผมก็เอาปากคาบกางเกงแกดึงลงจนหลุดใช้เวลานานนิดนึงแล้วผมก็ ดมหน้าแกออกแรงสูดลมเข้าให้แกได้ยิน ผมดมไล่ลงมาถึงนมเอาจมูกดุนชั้นในหอมมากจนนมแกโผล่แล้วก็ดมที่หัวนม แกบิดตัวเล็กน้อยแล้วผม ก็ดมลงไปถึงหรอก น้าสาวผมสะดุ้งเด้งตัวเล็กน้อย ผมเอาจมูกดุนที่หีแกจนแกอ้าขาเขย่งปลายเท้าขึ้น ผรู้สึกว่าหอมมาก ควยผมชี้โด่แล้วผมก็เอาปากคาบกางเกงในกัดดึงจนขาดแล้วผมก็เลียหี เบาๆ แกสะดุ้งร้องอุ๊ยเบาๆ แล้วผมก็ลองดูดที่รูหีไล่ขบเม็ดเเตดแก
