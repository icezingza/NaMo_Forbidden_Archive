อีกมือก็ปลิ้นนมออกมา มันสะใจจริงๆ ค่ะที่ได้ทำในที่แปลกๆ ที่ที่เคยมีคนอยู่เยอะๆ แล้วบางครั้งจินตนาการว่าโดนลูกศิษย์ เข้ามาข่มขืน แต่ความตื่นเต้นในจินตนาการก็ยังสู้ ความจริงที่ฉันเพิ่งเจอมาไม่ได้ ฉันต้องการแอบดูอย่างที่สุด ก็มีช่องหน้าต่างเล็กๆ นี่แหละที่ทำให้มองเห็นว่าทั้งสองคนนั้น ต่างเป็นลูกศิษย์ของฉันทั้งคู่ เกิดมายัง ไม่เคยเห็นคนเย็ดกันต่อหน้าอย่างนี้มาก่อนเลย ยัยเปิ้ลนิสิตหญิง ลูกศิษย์ของฉันเขาเย็ดกันหลายท่า เปลี่ยนท่าแล้วท่าเล่า เอาบนโต๊ะอาจารย์บ้าง เอาที่พื้นบ้าง เดินอุ้มไปกระเด้าไปบ้าง โก้งโค้งบ้าง ลีลาทั้งคู่ดูมันมากอย่างนี้แหละที่ฉันอยากโดน พอพวกเขาเย็ดกัน เสร็จ ตอนฉันเสร็จรูหี ของฉันบีบรัดแน่นกว่าทุกครั้ง วันรุ่งขึ้น จิตใจฉันยังคงหมกมุ่นถึงแต่เรื่องแอบดู ในใจลุ้นอยู่ตลอดว่าวันนี้จะมีอีกไหม แต่ก็ออกไปสำรวจที่ทางไว้ก่อน เพื่อจะได้แอบดูแบบเต็มตาหน่อย ตกเย็นฉันก็แอบไปซ่อนตัวข้างๆ ห้องนั้น มันออกจะสกปรกหน่อย ไม่นานนักฉัน ก็ได้ยินเสียงคนเข้ามาแล้ว ใจฉันสั่นเต้น โครมคราม ระทึกมาก ตาโป้งกับยายเปิ้ลคู่ เดิม ทำไมทั้งคู่ถึงได้เงี่ยน นักนะ ไม่ไปโรงแรมสบายๆ เย็นๆ ฉันได้ยินเขาพูดกันว่า เดี๋ยวจะมาอีกคู่หนึ่ง ใครกันนี่ แต่ภาพที่ฉันเห็นนี่สิ มันร้อนแรงมาก เขาไม่ทันแก้ผ้าเลย โป้งระดม จูบเปิ้ลอย่างหื่นกระหาย มือก็ถลกกระโปรงนิสิตขึ้น โป้งแข็งเต็มที่แล้ว เส้นเลือดปูดนูนเห็นได้ชัด หัวถอก บานเป็นเงี่ยงใหญ่ ไม่ทันไรมันก็เข้าไปอยู่ในปากของเปิ้ล โอ้ย.. ทำไมเขาทำกันมันอย่างนี้นะ ฉันอยากเอาบ้างจัง ฉันเริ่มถลกกระโปรงตัวเองขึ้นมาบ้าง
