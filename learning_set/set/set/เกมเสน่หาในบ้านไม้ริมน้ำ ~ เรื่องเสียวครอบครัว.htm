เรื่องเสียวแนวครอบครัว , ลุง , หลาน เกมเสน่หาในบ้านไม้ริมน้ำ ความอบอุ่นที่เริ่มเปลี่ยนเป็นไฟเมื่อหลานสาววัยใสย้ายมาอยู่กับลุง ฉันชื่อแก้ว อายุ 18 ปี เพิ่งย้ายมาอยู่กับลุงชัชที่บ้านไม้ริมน้ำหลังเก่าหลังเรียนจบ ลุงชัชเป็นน้องชาย แท้ๆ ของแม่ฉัน เขาอายุราวๆ 45 ปี ตัวสูงใหญ่ ผิวคล้ำแดด มีหนวดเคราครึ้ม แต่มันกลับดูดิบเถื่อน และเร้าใจอย่างประหลาด ทุกครั้งที่ลุงมอง ฉันรู้สึกเหมือนมีอะไรบางอย่างแล่นไปทั่วร่าง ลุงมักจะ ใส่เสื้อกล้ามตัวเดียว เผยให้เห็นกล้ามเนื้อแข็งแกร่ง ผมสลวยที่ยาวระต้นคอของแกทำให้แกดูเป็น ศิลปิน เป็นคนที่ไม่เหมือนใคร และก็เป็นคนที่ทำให้หัวใจฉันเต้นระรัว คืนนั้นอากาศร้อนอบอ้าวมาก ฉันกำลังนั่งอ่านหนังสืออยู่ริมหน้าต่าง ลมพัดเอื่อยๆ แทบไม่ช่วยอะไร เลย กางเกงขาสั้นของฉันร่นขึ้นไปจนเห็นโคนขาอ่อนๆ ที่ยังไม่เคยมีใครสัมผัส /ซู้ดดด/ เสียงเปิด ประตูห้องดังขึ้น ลุงชัชเดินเข้ามาในชุดกางเกงบอลขาสั้นตัวเดียวกับเสื้อกล้ามที่เปียกชุ่มไปด้วยเหงื่อ จากการออกกำลังกาย กลิ่นเหงื่อผู้ชายปนกลิ่นดินที่แกชอบปลูกต้นไม้ลอยเข้ามาแตะจมูกฉัน มันเป็น กลิ่นที่ดิบเถื่อนและปลุกเร้าอารมณ์แปลกๆ “ร้อนนักเหรอแก้ว... หรือว่ากำลังคิดอะไรอยู่นะ” ลุง ชัชพูดเสียงทุ้มต่ำ ดวงตาคมกริบของแกจ้องมองมาที่ต้นขาฉันอย่างเปิดเผย คำท้าทายจากสายตาที่ร้อนแรงของลุงทำให้ฉันแทบจะยอมจำนน ฉันสะดุ้งสุดตัว มือสั่นจนหนังสือหล่นจากมือ *ตุ้บ!* พยายามจะพูดแก้ตัวแต่คำพูดมันติดอยู่ในลำคอ “ปะ...เปล่าค่ะลุง” ใบหน้าฉันคงขึ้นสีแดงก่ำจนลุงเห็นได้ชัด ลุงชัชเดินเข้ามาใกล้ ยืนค้ำหัวฉันที่ กำลังนั่งอยู่ตรงขอบหน้าต่าง แสงจันทร์สาดส่องเข้ามาในห้องกระทบแผ่นอกเปลือยเปล่าของแก เห็น กล้ามเนื้อเป็นมัดๆ ชัดเจน /กลึก/ ฉันกลืนน้ำลายลงคออย่างยากลำบาก กลิ่นเหงื่อของแกรุนแรงขึ้น จนฉันมึนหัวไปหมด “เปล่าเหรอ... แต่ทำไมหน้าแดงแบบนั้นล่ะ” ลุงชัชพูดพลางก้มตัวลงมาใกล้ ริมฝีปากหยักหนาเกือบ จะชนกับหูของฉัน “หรือว่า... อยากให้ลุงช่วยให้หายร้อน?” เสียงของแกรื่นหูอย่างประหลาด มัน ไม่ใช่คำพูดปกติที่ลุงใช้ มันเหมือนคำเชื้อเชิญที่อันตราย นิ้วหยาบกร้านของลุงชัชค่อยๆ แตะลงที่ต้นขา อ่อนๆ ของฉัน ลากขึ้นช้าๆ จนถึงร่องขา /จึ๊ก!/ ความร้อนจากปลายนิ้วของแกลามเลียไปทั่วร่าง ฉันตัวสั่นสะท้านไปหมด /อ๊าาา/ เสียงครางในลำคอดังออกมาโดยไม่รู้ตัว สัมผัสแรกที่ปลุกเร้าสัญชาตญาณดิบในตัวฉันให้ตื่นขึ้น “ขาอ่อนจังนะแก้ว... แถมยังสั่นแบบนี้อีก” ลุงชัชกระซิบข้างหู น้ำเสียงของแกร้อนผ่าวไปหมด เขา ดันตัวฉันให้เอนราบไปกับพื้นไม้เย็นๆ แล้วขึ้นคร่อมฉันทันที แผ่นอกของแกกดทับลงบนอกฉัน แรงจนฉัน หายใจไม่สะดวก /ฮือออ/ กางเกงขาสั้นของฉันถูกร่นขึ้นไปสูงกว่าเดิมจนเห็นกางเกงในตัวจิ๋วสีชมพู มือนั้นก็ไม่ได้หยุดอยู่แค่นั้น นิ้วโป้งของลุงค่อยๆ กดลงไปที่ร่องกางเกงใน ตรงเนินน้องสาวของฉัน / จึ๊ก!/ ความชื้นแฉะที่เริ่มไหลซึมออกมาจากหีของฉันถูกกดขยี้เบาๆ “แฉะขนาดนี้แล้ว... นี่มันอยาก หรือกลัวกันแน่หืม?” ลุงถามเสียงแหบพร่า สายตาคมกริบของแกจ้องลึกเข้ามาในดวงตาของฉัน เหมือนจะฉีกฉันออกเป็นชิ้นๆ ลุงชัชเลื่อนมือไปจับคางฉันบังคับให้แหงนหน้าขึ้น แล้วก้มลงมาจูบฉันอย่างรุนแรงและเร่าร้อน ลิ้นของ แกสอดเข้ามาในปากฉัน ตวัดเกี่ยวลิ้นฉันอย่างบ้าคลั่ง /ชลับ ชลับ/ รสชาติแปลกใหม่ที่ดิบเถื่อนทำให้ ฉันแทบจะสำลักแต่กลับหยุดไม่ได้ มือหยาบกร้านของลุงค่อยๆ ลากไปตามขอบกางเกงใน ดึงรั้งลงไป ช้าๆ เผยให้เห็นหีของฉันที่ปูดนูนและเปียกชุ่มน้ำเงี่ยน ลุงชัชจ้องมองมันด้วยแววตาหิวกระหาย “ขาว จริงๆ ... น่าเอาควยถูเสียเหลือเกิน” เขาพูดก่อนจะใช้ปลายคางและหนวดเคราครูดย้อนขึ้นลงบน เนินหีฉันเบาๆ /ซี้ดดด/ ฉันเสียวจนตัวบิดไปมา อ้าขาออกกว้างขึ้นโดยไม่รู้ตัว เกมอำนาจและการยอมจำนนที่ไม่อาจต้านทานต่อความปรารถนาของลุง ลุงชัชไม่รอให้ฉันตั้งตัว เขากระชากกางเกงบอลของตัวเองลง เผยให้เห็นควยใหญ่ที่แข็งโด่ชี้หน้าฉัน อยู่ /ผงาด!/ หัวควยสีคล้ำบวมเป่ง ปลายหัวมีน้ำใสๆ เยิ้มออกมา ฉันมองมันตาค้าง มันใหญ่กว่าที่ ฉันจินตนาการไว้มาก ลุงชัชจับควยของแกให้ปลายหัวจ่ออยู่ตรงปากหีของฉันที่กำลังเต้นตุบๆ ด้วย ความปรารถนา เขาออกแรงกดเบาๆ *ชลับ!* ปลายควยของแกดันเข้ามานิดหนึ่ง “อยากได้ควยลุง ขนาดนี้เลยเหรอแก้ว...” เขาพูดเสียงแหบพร่า แล้วกระแทกควยเข้ามาอย่างแรงในคราวเดียว *ปึก!* “อ๊าาาาา!!” ฉันกรีดร้องสุดเสียง ความเจ็บปวดผสมความคับแน่นจนแทบจะขาดใจ หีของฉันเหมือน จะฉีกออกเป็นสองส่วน ลุงชัชไม่ได้หยุด เขากระแทกเข้ามาเรื่อยๆ ไม่สนใจเสียงร้องของฉันเลย *พั่บ! พั่บ! พั่บ!* เสียงเนื้อกระทบกันดังก้องไปทั่วห้องนอนไม้ ลุงชัชจับสะโพกฉันแน่น แล้วยกก้นฉัน ขึ้นให้กระแทกควยเข้ามาได้ลึกและแรงยิ่งขึ้น “แน่นชิบหาย... รัดควยลุงจนปวดไปหมดแล้ว” ลุง ชัชสบถ มือก็ฟาดลงบนสะโพกฉันดัง **เพียะ!** ความเจ็บปวดและแสบร้อนทำให้ฉันครางออกมาไม่ หยุด /อ๊าาาาาาาา/ แต่ยิ่งเจ็บฉันก็ยิ่งรู้สึกเสียวจนสติแทบหลุด จุดสุดยอดที่รุนแรงและป่าเถื่อนจนฉันไม่อาจทานทนได้อีกต่อไป ลุงชัชก้มลงดูดที่คอฉัน ขบเม้มจนเป็นรอยแดงช้ำ มือของแกก็ยังคงกระแทกควยเข้ามาในหีของฉัน อย่างไม่ปราณี *ตั่บ! ตั่บ! ตั่บ!* หีของฉันเริ่มตอดรัดควยลุงอย่างรุนแรง น้ำเงี่ยนไหลออกมาผสม กับน้ำควยของลุงจนเปียกแฉะไปทั่วหว่างขา เสียงครางของฉันปนกับเสียงหอบหายใจของลุงชัชดัง ระงมไปทั่วห้อง “ลุง... ลุงขา... หนู... หนูไม่ไหวแล้ว... อ๊าาาาา!!” ฉันร้องขอ แต่ลุงชัชกลับกระแทกเข้ามาหนักขึ้นและเร็วขึ้น ราวกับต้องการลงโทษฉันให้จมอยู่ใต้ควยของแก “ก็ แตกให้ลุงดูสิ... รัดควยลุงให้แตกคาหีแก้วเลย” ลุงชัชกระแทกเข้ามาอีกไม่กี่ที แรงจนตัวฉันกระเด็นตามแรงกระแทก **ปึก! ปึก!** แล้วร่างของ แกก็เกร็งกระตุก ควยของแกสั่นรัว ฉีดน้ำควยร้อนๆ เข้ามาเต็มหีของฉัน /อ๊าาาาาาาาาาาาา!!!/ ฉันกรีดร้องสุดเสียง สติหลุดลอย ร่างกายกระตุกเกร็ง น้ำรักของฉันก็ฉีดพุ่งตามออกมาเปื้อนหน้าท้อง ของลุงชัชจนเปียกปอนไปหมด ฉันรู้สึกโล่งจนแทบจะหมดแรง หายใจหอบถี่ ตัวลอยไปหมด บทส่งท้ายแห่งความหลงและผูกมัดที่ทำให้ฉันไม่อาจหันหลังกลับ ลุงชัชถอนควยออกช้าๆ เสียงดึงดูดของเนื้อที่แยกออกจากกันดัง **จุ๊บ!** ฉันยังนอนหอบอยู่บนพื้นไม้ กลิ่นน้ำคาวของควยลุงและน้ำเงี่ยนของฉันคลุ้งไปทั่วห้อง ลุงชัชนอนตะแคงข้าง กอดฉันแน่น ดวงตา ของแกยังคงฉายแววหิวกระหาย “แก้ว... นี่มันเพิ่งเริ่มต้นนะรู้ไหม” เขาพูดเสียงแหบพร่า แล้วก้ม ลงจูบที่หน้าผากฉันเบาๆ ฉันรู้สึกผิดในใจนิดๆ แต่ความเสียวที่ยังหลงเหลือทำให้ผมรู้ว่า ผมติดใจซะแล้วสิ ผมอยากให้คืนนี้เกิด ขึ้นอีก อยากให้ความลับนี้ดำเนินต่อไปในคฤหาสน์เงียบแห่งนี้ หัวใจฉันเต้นระรัว
