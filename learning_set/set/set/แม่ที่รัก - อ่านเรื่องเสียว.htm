*เรื่องเสียว แม่ที่รัก* ในบ้านผมก็มีพ่อ แม่กับผมและน้องสาวผมเล็กๆอีก 2 คนพ่อเป็นนายทหารสัญญาบัตรส่วนแม่อายุ 32 เป็นครูประชาบาลขณะนั้นผมเป็นเด็กหนุ่มอายุ 15-16 เพื่อนๆเอามาดูกันแล้วแอบสำเร็จความใคร่ด้วยตัวเองบ่อยๆ แล้วตอนเช้าวันหนึ่งผมเดินผ่านแม่ของผมกำลังจัดเสื้อกระโปรงให้น้องอยู่ เผอิญแม่นั่งยองๆไม่ทันระวังชายกระโปรงชุดครูด้านหลังก็ตกห้อยอยู่กับพื้นทำให้ผมมองเห็นของดีแม่ที่ อยู่หว่างกลางโคนขาขาวอวบโดยไม่คาดฝัน สิ่งที่ผมอยากเห็นในตอนนี้กำลังอวบอิ่มซ่อนตัวอยู่ในบิกินีสีชมพูจนตรงเป้าอูมนูนออกมามากเลย ผมแกล้งเดินไปมาและชำเลืองดูโหนกเนื้อที่นูนดันเนื้อผ้าออกมาไม่ให้แม่รู้ตัวจนกระทั่งแม่ลุกขึ้นทำให้ ผมเสียดายอยากเห็นเนื้อในของแม่มาก ผมจึงคิดได้ว่าวิธีง่ายที่สุดที่จะได้เห็นของจริงก็คือดูจากแม่ของผมนี่เอง ผมหาโอกาสแอบดูของแม่ผมเองแต่ก็ยังไม่เคยเห็นแม่โป๊แบบนี้อีกเลย หลังจากนั้นประมาณ10วันผมเข้าไปเก็บของในห้องใต้บันไดติดกับห้องน้ำผมก็คิดออก ผมลองเจาะรูๆหนึ่งขนาดเท่ารูตะปูเห็นจะได้ในห้องเก็บของแล้วแนบหน้ามองผ่านไปก็สามารถเห็นใน ห้องน้ำที่อยู่ติดกัน พอถึงเวลา19 ขณะที่ไม่มีใครสังเกตผมก็รีบแอบเข้าไปในห้องเก็บของทันที ขณะนั้นมืดมากแล้วเห็นแสงไฟที่ห้องน้ำออกจากรูนั้น ผมจึงแนบใบหน้าเข้าไปแล้วมองผ่านเข้าไปในห้องน้ำด้วยหัวใจที่เต้นไม่เป็นจังหวะภาพที่ผมเห็นนั้นแม่ กำลังหันหลังถอดชุดครูประชาบาลออกแล้วทั้งเนื้อทั้งตัวแม่ก็เหลือแต่ยกทรงกับกางเกงในตัวบางๆ ผมกวาดสายตาขึ้นลงตั้งแต่หัวจรดเท้าของแม่ทั้งเอวคอดสะโพกผายก้นขาวกลมกลึง แม่ของผมมีเชื้อจีนแต่ผิวขาวอมชมพูเนียนขาวไปทั้งตัวไม่ขาวซีดเหมือนคนจีนทั่วไปแม่สวยงามเหลือเกิน ตอนนั้นผมก็ยังไม่ได้คิดอะไรกับแม่ของตัวเองหรอกครับนอกจากความอยากรู้อยากเห็นอวัยวะเพศของ ผู้หญิงเท่านั้น จากนั้นแม่ก็ถอดยกทรงออกโดยหันด้านขวามาทางผมด้วยแสงจากหลอดไฟชนิดกลมขนาด 100 วัตต์ส่องลงอกที่เปล่าเปลือยไม่มีอะไรปิดบัง ระยะห่างจากสายตาของผมไม่ถึง 1 เมตรด้วยซ้ำไป แม้นจะเห็นเพียงด้านข้างก็น่าดูไม่ใช่น้อยทำเอาผมใจเต้น นมเป็นกระเปาะสั่นกระเพื่อมห่างจากสายตาของผมไม่มากนักช่างขาวนวล พอคิดแค่นั้นอวัยวะเพศผมก็เริ่มแข็งตัวผมยังไม่แน่ใจว่าเป็นอารมณ์ปรารถนาทางเพศกับแม่หรือเป็น ธรรมชาติของผู้ชายที่เห็นนมผู้หญิง และขณะที่แม่ก้มตัวยกขาถอดกางเกงในออกจากปลายเท้านั้นก้นกลมขาวก็ลอยโด่งยักขึ้นยักลงผมก็มอง ลอดง่ามก้นที่ขาวกลมเห็นนูนเนื้อที่ย้อยลงมีปุยฝอยดำเป็นเงาๆอยู่รำไร พอเห็นแม่ในท่านี้ผมใจผมเต้นตึกๆ มังกรแข็งปั๋งทันที ผมอยากเอาดุ้นเอ็นยัดใส่เครื่องเพศของแม่จริงๆ พอนึกได้ผมก็ตกใจหน้าร้อนวูบวาบนึกละอายใจที่มีอารมณ์อยากสังวาสกับแม่ของตัวเอง ผมรีบระงับใจไม่ให้คิดลามกอย่างนั้น ผมภาวนาให้แม่หันมาขอผมเห็นด้านหน้าตรงนั้นของแม่ว่าเป็นยังไงแล้วผมก็จะออกไปทันที แล้วฝันก็เป็นจริงพอแม่หันมาตักน้ำอาบผมใจเต้นระริกผมรีบมองต่ำลงและให้ตายดิ้นสิครับสิ่งที่ผมไม่ เคยเห็นก็ได้เห็นก็ตรงระหว่างง่ามขาเนินสามเหลี่ยมที่ผมอยากเห็นนั้นขาวเนียนนูนเป็นโหนกออกมา จากใต้ท้องน้อยจนเห็นได้ชัดฝั่งแคมทั้งสองข้างที่ขาวอูมเบียดกันอย่างสนิทมีปุยขนที่เปียกน้ำดำมันราว
