เรื่องเล่าจากทางบ้าน , เรื่องเสียวน้า , เรื่องเสียวแนวครอบครัว , หลาน เล่า เรื่อง ประสบการณ์เล่นเสียวกับน้าสาวอารมณ์เปลี่ยว เรื่องมันมีอยู่ว่าพ่อแม่ผมและน้าเขยได้ไปทำงานที่ต่างประเทศ ทั้งสามคน ประมาณ 2 ปี กว่าจะกลับ บ้านมาครั้งหนึ่ง จึงได้บอกให้น้าสาวของผมมาอยู่อยู่ด้วยเป็นเพื่อน ผมเองอายุ 16 ปีอยู่ตอนนั้น เนื่องจากพ่อแม่กลัวผมทำตัวไม่ดีเหลวไหล จึงให้น้ามาควบคุมดูแลความประพฤติของผมครับ น้าสาว ถึงแม้ว่าอายุ 42 ปี แล้วแต่ดูยังสาวสวยอยู่ครับ ชื่อน้าแพท ผมเองเรียนอยู่อาชีวะแห่งหนึ่ง สาขา ช่างอิเลกทรอโจ ส่วนน้าก็อยู่บ้านรับตัดเย็บเสื้อผ้า ทำงานาอยู่กับบ้าน ทุกวันเวลาตอนเย็นผมมักจะ แอบดูน้าสาวอาบน้ำเป็นประจำครับ ของน้าสาวใหญ่มากครับ ทำให้ผมทนไม่ไหวต้องช่วยตัวเองตามทุกครั้ง มาวันนี้ก็เช่นเดียวกันผมแอบดู น้าสาวอาบน้ำแต่วันนี้น้าสาวตกเบ็ดครับ ผมเห็นน้าเอามือถือมาเปิดดูหนังโป๊แล้วอีกมือก็เขี่ยเม็ดเสียว ไปด้วย ผมเห็นแกทำอยู่สัก 5 นาที แกเร่งมือเร็วขึ้นบิดตัวเกร็ง ส่วนผมก็ไม่ต้องพูดถึงชักว่าวเสร็จ ตามน้าไปติดๆครับ หลังจากเสร็จแล้วผมไม่ได้ระวังตัวเอาเท้าไปเตะเข้าของที่อยู่ข้างห้องน้ำครับ ทำให้น้าสาวผมรู้ตัวว่ามันคนแอบดูขึ้นมาทันที จึงรีบประตูออกมาเจอผมเข้า ทีแรกผมก็กลัวน้าด่าครับ แต่ไม่เป็นอย่างที่คิด น้าพูดว่า “โจน้ารู้นะว่าแอบดูน้าอาบน้ำทุกเลย ทำแบบนี้ทำไมล่ะ” ผมไม่ตอบครับกลังก็กลัวอีกอย่างอายด้วย น้าพูดต่อไปว่า “ไหนๆก็เห็นของน้าหมดแล้วงั้นมาช่วยน้าดีไหมคืนนี้” ผมได้ยินดังนั้นรีบพยักหน้าครับ พออาบน้ำทานข้าวเสร็จ ผมก็ไปหาน้าแพทที่ห้องครับ คืนนี้น้าแพทใส่ชุดนอนบางๆกางเกงในไมใส่อีก ต่างหากครับแสดงว่าน้าแพทคงเงี่ยนมากๆ ผัวไม่อยู่ไปนอก จึงเตรียมความพร้อมให้ผมไปเย็ด ผมจึง อยากจะลองเหมือนกันว่าเย็ดน้าแพทจะมันและเสียวขนาดไหน พอไปถึงห้องนอนผมไม่รอละครับ ต่าง คนต่างรู้กันแล้ว ผมนุ่งแค่ผ้าขนหนูตัวเดียว ปลดออกดุ้นผมแข็งจี้โด่ไปที่น้าแพท น้าตกตะลึงกับดุ้นผมที่ ใหญ่ยาว น้าแพทรีบเข้ามาจับรูดล่นและอมเข้าไปในปาก ผมเสียวครางออกเบาๆ น้าแพทผมเสียว ๆครับน้า ผมขอเย็ดน้าแพทดีกว่านะ จากนั้นผมรีบถอดดุ้นออกจากปากน้าแพท แล้วจับขาถ่างออกยัดดุ้น เข้าร่องเสียวน้าแพท ส่วนน้าก็เด้งรับ ดุ้นผมเข้าจนมิดเลยครับ ผมกระแทกอย่างเร็วและแรงมากๆ ให้สมกับความอยาก น้าแพทครางลั่นห้อง เลย “ โจน้าเสียวที่สุดเลย เอาแรงๆน้ามีความสุขที่สุด ทำแบบนี้กับน้าทุกวันเลยนะ สักพักน้าแพทตัวเกร็งกระตุกๆ ตอรัดดุ้นผม เสียวจนทนไม่ไหว น้ำดุ้นแตก ใส่ร่องน้าแพทอย่างเนืองนองเลยครับ ทุกคืนๆผมเล่นเสียวกับน้าแพทบางคืน 5 ครั้งครับ ยอมรับว่า น้าแพทเซ็กส์จัดจริงๆ Share: // // //
