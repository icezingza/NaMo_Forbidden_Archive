ก่อนที่พ่อจะเลิกกับแม่ไปเสียอีก… โดยส่วนตัว ลุงแกเป็นคนนิสัยดี เรียบร้อย ขยันมากแต่เมียแก (พี่สาวพ่อ/ป้าของผม) กลับติดเล่นไพ่อย่างอมแงม แกเลยแยกจากกัน… มาอาศัยช่วยแม่ผมขายของบ้านผม ในช่วงที่ขายของเสร็จ กลับมาบ้านกินข้าวกินปลาแล้ว ทุกๆ ครั้งก่อนนอน ลุงแกใจดี แกจะมาหยิบ นวดจับเส้นให้แม่ผมทุกวัน เพราะแกเคยเป็นหมอนวดแผนไทยมาก่อน ส่วนแม่ผมเป็นคนชอบนวดด้วย แม่ผมเลยจะมานอนให้ลุงเค้านวดที่ห้องของแม่เล็งทุกวันเป็นประจำ… จนมีอยู่คืนหนึ่ง ผมนึกสงสัย ก็ เลยอยากลองแอบดู…. ว่าจะมีอะไรไหม ?!? ก็เห็นแม่ผมใส่ชุดนอนเหมือนปกติ กำลังนอนคว่ำอยู่ โดยที่ลุงแกกำลังบีบนวดที่ขาแม่ ไล่ขึ้นไปที่สะโพก ใต้ชุดนอนแม่.. มันก็คุ้มแค่บริเวณเนื้อหัวเข่าขึ้นไป จึงมองเห็นท่อนขาล่างขาวอวบ ผมที่เป็นลูกชายแท้ๆ เห็นแล้วยังได้อารมณ์มาก ลุงแกบีบขึ้นลงถอนขาเปื่อยๆ บริเวณน่องสักพัก แล้วอยู่ๆ นิ้วแกก็เกี่ยวเอาชายชุดนอนแม่ขึ้นไปเรื่อยๆ จนแม่โป๊มาก ขอบชุดนอนแม่เกือบจะถึงแก้มก้นอยู่แล้ว แต่แม่ก็ยังคงนอนเฉยอยู่ ผมคิดในใจว่า… แม่ ผมวันนี้ คงรอดยากแล้ว หรือว่าแม่ผมคงอยากด้วยละมั้ง ?!? แล้วลุงแกก็ค่อยๆ จับขาแม่ผมทางออก แล้วแล้วก็แอบก้มลงไปชมของรับภายใต้กางเกงในของแม่… ก่อนที่ลุงแกจะกลับมาเริ่มนวดอีกครั้ง โดยไล่นวดจากท่อนขาเนื้อหัวเข่าขึ้นไปเรื่อยๆ แต่เพียงคู่เดียว… ทีนี้แกก็ใช้สองมือล้วงเข้าไปใน ชุดนอน แล้วก็ขยำแก้มก้นใหญ่ของแม่อย่างเมามันส์เลย โดยลุงแกก็ใช้นิ้วโป้งขยี้คลึงแคมทั้งสองข้าง ไปด้วย ถึงแม้มันจะยังมีกางเกงในของแม่สวมทับอยู่
