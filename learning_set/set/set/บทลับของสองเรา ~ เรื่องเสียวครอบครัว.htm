ใกล้ชิดกันมากมาตั้งแต่เด็กๆ พลอยมักจะเข้ามานอนกอดฉันในตอนกลางคืนเวลาที่เธอรู้สึกไม่สบาย หรือบางครั้งก็แค่อยากจะอ้อน ฉันเองก็ไม่เคยปฏิเสธสัมผัสเหล่านั้น เพราะมันทำให้ฉันรู้สึกอบอุ่นและ ไม่โดดเดี่ยวจนเกินไป เมื่อเวลาล่วงเลยไปจนดึก ฉันยังคงนั่งจิบไวน์อยู่คนเดียวในห้องนั่งเล่น ความรู้สึกเหงาถาโถมเข้า มาอีกครั้ง ทันใดนั้น ประตูห้องนอนของพลอยก็เปิดออก เธอยืนอยู่ตรงนั้นในชุดนอนผ้าซาตินบางเบาที่ เผยให้เห็นเรือนร่างอันเย้ายวน “แม่คะ ยังไม่นอนอีกเหรอคะ” พลอยถามเสียงแผ่ว “แม่ยังไม่ค่อย ง่วงเลยจ้ะ” ฉันตอบพลางยิ้มให้ “พลอยก็ยังนอนไม่หลับค่ะแม่ ขอมานั่งเป็นเพื่อนแม่ได้ไหมคะ” เธอ พูดพลางเดินตรงเข้ามาหาฉัน แววตาของเธอเต็มไปด้วยความต้องการบางอย่างที่ฉันเองก็สัมผัสได้ มือของพลอยเลื่อนมาแตะที่แขนฉันเบาๆ สัมผัสที่นุ่มนวลและอ่อนโยนของเธอนั้นแตกต่างจากสามีของ ฉันอย่างสิ้นเชิง “ได้สิจ้ะลูก” ฉันตอบ พลอยทรุดตัวลงนั่งข้างๆ ฉันบนโซฟา พลอยโน้มตัวเข้ามาใกล้ ใบหน้าของเธอห่างจากฉันเพียงคืบ ลมหายใจอุ่นร้อนของเธอเป่ารดใบหน้า ของฉัน กลิ่นหอมอ่อนๆ จากร่างกายของเธอยิ่งทำให้ฉันรู้สึกปั่นป่วน “แม่คะ...พลอยคิดถึงแม่” เธอ พูดเสียงแผ่ว แล้วซบหน้าลงบนไหล่ของฉัน สัมผัสที่อ่อนโยนของเธอทำให้ฉันรู้สึกอบอุ่น แต่ก็แฝงไป ด้วยความรู้สึกแปลกประหลาดที่ยากจะอธิบาย “แม่ก็คิดถึงลูกจ้ะ” ฉันตอบ พลางยกมือขึ้นลูบผมลูกสาว เบาๆ มือของพลอยเลื่อนลงมาวางบนหน้าขาของฉัน สัมผัสที่นุ่มนวลและอ่อนโยนของเธอทำให้ฉันรู้สึก เหมือนมีกระแสไฟฟ้าแล่นพล่านไปทั่วร่าง /ซี้ดดด/ ฉันสะดุ้งเล็กน้อย พยายามรวบรวมสติที่ กระเจิดกระเจิง “พลอย...ลูกกำลังทำอะไร” ฉันถามเสียงตะกุกตะกัก จุดเริ่มต้นแห่งความเร่าร้อน พลอยไม่ยอมปล่อยมือ เธอค่อยๆ บีบมือฉันเบาๆ แล้วลูบไล้ไปมาอย่างช้าๆ แผ่วเบา แววตาของเธอ ที่มองมายังฉันนั้นเต็มไปด้วยความปรารถนาที่ฉันไม่เคยเห็นมาก่อน “แม่ก็รู้ไม่ใช่เหรอคะ...ว่าพลอย รู้สึกยังไงกับแม่” เธอพูดเสียงพร่า แล้วโน้มตัวเข้ามาใกล้ ริมฝีปากของเธอสัมผัสเบาๆ ที่ริมฝีปาก ของฉัน “พลอย...นี่มันไม่ถูกนะลูก” ฉันพยายามพูด แต่เธอกลับใช้มืออีกข้างเชยคางฉันให้หันกลับมา สบตากับเธอ “ไม่มีใครรู้หรอกค่ะแม่...มีแค่เราสองคน” เธอพูดพลางหัวเราะในลำคอเบาๆ เสียง หัวเราะของเธอแหบพร่าและเร้าอารมณ์อย่างประหลาด จู่ๆ พลอยก็ก้มลงจูบฉันอย่างร้อนแรงและรุนแรง ริมฝีปากของเธอบดขยี้ลงบนริมฝีปากของฉันอย่าง บ้าคลั่ง ลิ้นของเธอก็สอดเข้ามาในปากฉัน ตวัดเกี่ยวลิ้นฉันอย่างหื่นกระหาย /ชลับ! ชลับ!/ รสจูบที่ ดิบเถื่อนและเผ็ดร้อนทำให้ฉันแทบจะสำลักแต่กลับหยุดไม่ได้ มันเป็นจูบที่ทั้งเอาแต่ใจและน่ากลัว แต่ก็ เร้าอารมณ์อย่างที่ไม่เคยเจอมาก่อน มือเรียวเล็กของพลอยลูบไล้ลงมาตามแผ่นหลังของฉัน แล้วรั้ง ชายชุดนอนผ้าซาตินของฉันขึ้นอย่างช้าๆ เผยให้เห็นเนินสะโพกกลมกลึงของฉันที่กำลังสั่นระริก พลอย ใช้ปลายคางของเธอครูดลงไปที่เนินอกของฉันเบาๆ /ซี้ดดด/ ฉันเสียวจนตัวบิดไปมา แอ่นอกรับ สัมผัสจากเธอโดยไม่รู้ตัว พลอยถอนจูบออกช้าๆ ดวงตาของเธอฉายแววเจ้าเล่ห์และเร่าร้อนอย่างไม่ปิดบัง “แม่สวยที่สุดเลย ค่ะ” เธอพูดเสียงแหบพร่า ไม่รอให้ฉันตอบ เธอกระชากชุดนอนผ้าซาตินของฉันออกอย่างรวดเร็ว และรุนแรงจนขาดวิ่น *ฉีก!* เสียงผ้าขาดดังลั่นในความเงียบของห้องนั่งเล่น มันเป็นเสียงที่ทำให้ ฉันรู้สึกเหมือนตัวเองกำลังถูกปลดปล่อย และก็ถูกกระตุ้นไปในเวลาเดียวกัน เธอก้มลงดูดเม้มที่ยอ ดอกของฉันอย่างหิวกระหาย /จ๊วบ! จ๊วบ!/ มืออีกข้างก็ปลดกางเกงของตัวเองลง เผยให้เห็นหี ของเธอที่ปูดนูนและเปียกชุ่มไปด้วยน้ำเงี่ยนที่เริ่มไหลซึมออกมาอย่างควบคุมไม่ได้ ฉันมองมันตาค้าง ด้วยความตกใจและหวาดหวั่นปนกับความรู้สึกอยากรู้ พลอยไม่พูดอะไร เธอถอดกางเกงในของฉัน ออก เผยให้เห็นหีของฉันที่ปูดนูนและเปียกชุ่มไปด้วยน้ำเงี่ยนที่เริ่มไหลซึมออกมาอย่างควบคุมไม่ได้ เธอก้มตัวลง เลียที่ปากหีของฉันเบาๆ /แผล่บ!/ สัมผัสแรกนั้นทำให้ฉันสะทุ้งสุดตัว ไฟพิศวาสที่ไม่อาจต้านทาน “อื้อออออ” ฉันครางออกมาอย่างควบคุมไม่ได้ พลอยใช้ลิ้นตวัดเลียไปทั่วปากหีของฉันอย่างช้าๆ และ แผ่วเบา ก่อนจะค่อยๆ สอดปลายลิ้นเข้ามาในร่องหีของฉันอย่างช้าๆ /จ๊วบ! จ๊วบ!/ ฉันเสียวจนตัว บิดไปมา สะโพกของฉันแอ่นขึ้นรับลิ้นของเธอโดยไม่รู้ตัว เธอใช้ลิ้นตวัดวนไปมาที่เม็ดแตดของฉัน อย่างจงใจและยั่วยวน /ดูด! ดูด!/ ฉันเสียวจนขาอ่อน สองมือจิกเกร็งไปที่โซฟาหนังเย็นเฉียบ “พลอย... อ๊าาาาาาาาาาาาา” ฉันร้องเรียกชื่อลูกสาวออกมาอย่างแผ่วเบา ร่างกายสั่นสะท้านไป ทั้งตัว พลอยเงยหน้าขึ้นมามองฉัน ใบหน้าของเธอเปื้อนไปด้วยน้ำเงี่ยนของฉัน ดวงตาคมกริบของ เธอยังคงจ้องมองฉันด้วยความหิวกระหาย “ยังไม่พอใช่ไหมคะแม่... อยากได้อะไรมากกว่านี้” เธอพูดเสียงพร่า แล้วใช้ปลายลิ้นของเธอสัมผัสเบาๆ ที่เม็ดแตดของฉันอีกครั้งอย่างยั่วยวน พลอยโน้มตัวเข้ามาใกล้ แล้วใช้ริมฝีปากของเธอครอบลงบนน้องสาวของฉันอย่างนุ่มนวลแต่หนักแน่น /ดูด! ดูด!/ เธอเริ่มดูดเม็ดแตดของฉันอย่างบ้าคลั่ง สลับกับการใช้ลิ้นตวัดเลียและกดลงไปอย่าง จงใจ /แผล่บ! จ๊วบ!/ ฉันรู้สึกเหมือนมีกระแสไฟฟ้าแล่นพล่านไปทั่วร่าง ความเสียวซ่านพุ่งตรงไปที่ จุดศูนย์กลางของร่างกายอย่างรุนแรง “อ๊าาาาาาาาาาาาา!!” ฉันกรีดร้องสุดเสียง ขาโก่งตัวขึ้น ด้วยความเสียวจนตัวสั่นสะท้านไปทั้งตัว หีของฉันบีบตัวเข้าหากันอย่างรุนแรง พยายามจะบีบลิ้นของ พลอยไว้แน่น เธอใช้ลิ้นดูดเม็ดแตดของฉันอย่างไม่หยุดหย่อน *ดูด! ดูด! ดูด!* แรงดูดของเธอทำ ให้ฉันรู้สึกเหมือนจะหลุดลอยไปจากโลกนี้ ฉันจิกเล็บลงบนโซฟาแน่นจนเจ็บ ผมของฉันกระจัดกระจาย ไปทั่ว ดวงตาปิดแน่นด้วยความเสียวซ่าน พลางแอ่นสะโพกขึ้นรับแรงดูดของเธออย่างลืมตัว พลอยยังคงดูดเม็ดแตดของฉันอย่างต่อเนื่องและรุนแรง เสียงดูดดังจ๊วบจ๊าบไปทั่วห้องนั่งเล่น เสียงครางของฉันปนกับเสียงหอบหายใจของพลอยที่เริ่มถี่ขึ้น ดังระงมไปทั่วห้องที่ควรจะเงียบสงบแต่กลับกลายเป็นสนามรบแห่งความปรารถนาอันเร่าร้อน “พลอย ... อ๊าาาาาาาาาาาาาาาาา!!” ฉันร้องขออย่างบ้าคลั่ง ความรู้สึกเหมือนจะแตกกระจายไปแล้ว แต่พลอยกลับดูดเข้ามาหนักขึ้นและเร็วขึ้นอีก ราวกับต้องการให้ฉันจมดิ่งลงสู่ห้วงแห่งความสุข “แตก ให้พลอยดูสิคะแม่... แตกคาปากพลอยเลยนะคะ” เธอพูดเสียงแหบพร่า สลับกับการดูดเม็ดแตดของ ฉันอย่างรุนแรงและรวดเร็ว ไม่ยอมให้ฉันได้พักหายใจ พลอยดูดเม็ดแตดของฉันอีกไม่กี่ที แรงจนตัวฉันกระเด็นตามแรงดูด **จ๊วบ! จ๊วบ!** แล้วร่างของ ฉันก็เกร็งกระตุกอย่างรุนแรง น้ำรักของฉันฉีดพุ่งออกมาอย่างไม่หยุดยั้ง /อ๊าาาาาาาาาาาาา!!!/ ฉันกรีดร้องสุดเสียง สติหลุดลอย ร่างกายกระตุกเกร็งอย่างบ้าคลั่ง หีของฉันตอดรัดลิ้นของพลอย อย่างรุนแรง น้ำรักของฉันไหลออกมาเปื้อนใบหน้าของพลอยและโซฟาจนเปียกปอนไปหมด ฉันรู้สึก โล่งจนแทบจะหมดแรง หายใจหอบถี่ ตัวลอยไปหมด ความรู้สึกเหมือนร่างกายกำลังละลายไปกับ ความเร่าร้อนนั้น ภาพทุกอย่างพร่าเลือนไปหมด เหลือเพียงสัมผัสของลิ้นเธอที่ยังคงดูดเม็ดแตดของ ฉันจนฉันต้องแอ่นกายรับอย่างบ้าคลั่ง บทส่งท้ายแห่งความลับที่ไม่อาจเปิดเผย พลอยเงยหน้าขึ้นมามองฉัน ใบหน้าของเธอเปื้อนไปด้วยน้ำรักของฉัน
