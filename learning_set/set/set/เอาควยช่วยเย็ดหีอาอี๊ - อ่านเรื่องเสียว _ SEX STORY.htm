ความตื่นเต้นทำให้ท่อนควยแข็งขึ้นมาแนบกับร่องก้นอาอี๊ จะขยับหนีไปขยับไม่ออก เพราะต้องขยับเดิน กันเข้าไป แต่อาอี๊รู้สึกตัวหันมามองเหมือนตกใจแต่เมื่อรู้ว่าเป็นผม ก็ไม่ได้พูดไร หน้าแดง และทำท่า ถอนหายใจ เรียนกลับมาตอนเย็น อาอี๊กำลังทานข้าวเย็นกับเอกและอ้อ เรียกผมทานด้วย เสร็จแล้วบอกเอกกับ อ้อว่ารีบทำการบ้านแล้วไปนอนซะ เพราะพรุ่งนี้จะให้คนขับรถมารับตอนตี 5 ไปเที่ยวสวนจตุจักรกัน แต่อาอี๊มาคุยกับผม 2 ถามว่าทำไมมองแบบนั้น ไม่สวยเหรอจ๊ะ ผมบอกอี๊สวยและเซ็กซี่ด้วยคับ อี๊ยิ้มอย่างพึงพอใจ แล้วผมก็ขับรถออกมา ถามอี๊ว่าจะไปไหน.. อี๊บอกไปเที่ยวสิ ที่ไหนก็ได้แล้วแต่ผม ผมพาไปนั่งฟัง เพลงที่ผับแห่งนึง.. ไปนั่งโต๊ะหลบมุม ไม่ค่อยมีคนสั่งไวน์ให้ อี๊ ดื่ม เรานั่งติดกัน เสียงเพลง ค่อนข้างดัง เวลาคุยต้องกระซิบข้างหู อี๊ดื่มไวน์จนหน้าเริ่มแดง ผมบอกอี๊ว่า อี๊หน้าแดงดูเซ็กซี่จัง อี๊ยิ้มหวาน ผมยังบอกอีกว่า เนี่ยถ้าผมมีแฟนน่ารักแบบอี๊ก็ดีสิ… สวยก็สวย น่ารักๆ นิสัยก็ดี แบบนี้รัก ตายเลย อี๊ยิ้มรับแบบเขินเล็กน้อยที่ผมชมต่อหน้า อี๊คุยเรื่องไปเที่ยวดูสินค้าที่เมืองทองบอกมีสินค้าน่าดู หลายอย่าง ที่ยังไม่ได้ดู..เพราะคนเยอะมาก เบียดกันจนแทบเข้างานไม่ได้ พอพูดถึงตรงนี้อี๊ก็ เหมือนนึกถึงเหตุการณ์นั้นได้ หน้าแดงแอบมองที่ผม ผมจ้องหน้าอี๊พลางกระซิบข้างหู ผมชอบแบบนั้น มากเลยอี๊ ผมอยากทำแบบนั้นอีก ท่อนควยก็แข็งเป็นลำเมื่ออี๊นั่งลง มา สัมผัสกับก้นอี๊ อี๊หายใจแรงจับมือของผมทั้งสองข้าง เป็นงัยอี๊ ชอบมั้ย ผมเลื่อนมือข้างหนึ่งปลด ตะขอกางเกงอี๊ออกแซะเข้าไปล้วงผ่านกางเกงในจับไปที่โคกเนื้ออวบของอี๊
