ผมเป็นลูกคนเดียว ฐานะทางบ้านก็ปานกลาง แม่ผมคลอดผมตอนอายุ 17 ปี และไม่เคยบอกว่าพ่ออยู่ที่ไหนทำอะไรให้ผมรู้เลย ผมจึงอาจเป็นเด็กเก็บกดตั้งแต่เล็กๆ ก็ได้ ส่วนมากคนที่เลี้ยงผมคือตากับยาย แม่จะไม่ค่อยอยู่บ้านทำงานขายของอยู่ในห้างสรรพสินค้า แห่งหนึ่ง แม่ผมเป็นคนสวยและเจ้าชู้ซะด้วย ผมเห็นจนชินตาตั้งแต่เด็กๆ แล้วแม่พาหนุ่มๆ มาที่บ้านกลางดึกตั้งหลายครั้ง ตั้งแต่ผมอายุ 10 ขวบกว่าๆ บางคืนผมอยากไปนอนกับแม่ แอบเดินไปห้องแม่ ( ผมนอนห้องเดียวกับยาย ) ก็เห็นแม่อยู่กับผู้ชายบ่อยๆ ภาพที่เห็นคือแม่กำลังดูดควยให้หรือกำลังขึ้นขย่มให้เค้าดุ้นแทบหัก จนผมมีความคิดไม่ดีเกี่ยวกับแม่มาตั้งแต่เด๊ก คืนนึงตอนนั้น หลังจากวันเกิดอายุ 16 ปีได้ 2 วัน แม่สัญญาว่าจะซื้อของขวัญให้ผมวันนี้ แต่ตอนนี้ตี 1 กว่าแล้วแม่ยังไม่กลับ สงสัยไปดื่มและอาจจะพาใครมาบ้านเหมือนเคย ผมนอนเงียบอยู่ซักพัก จึงได้ยินเสียงแม่กลับมา ผมจึงย่องไปดูจริงดังคาดแม่เดินเข้ามาพร้อม ลุงชัยคนที่แม่พามาด้วยบ่อยๆ รู้สึกแม่จะเมามากในมือแม่ไม่ได้ถือของขวัญอะไรมาเลย เพราะเดินมาตัวเปล่าเซไปเซมา ลุงชัยเดินจูงแม่เข้าห้องนอน แล้วก็ปิดประตูโดยที่ผมแอบดูอยู่ แอบมองเข้าไปในช่องเล็กๆข้างประตูที่ประจำที่ผมแอบมองแม่อยู่บ่อยๆ ผมเห็นลุงชัยแกเอาถลกกระโปรงแม่ ขึ้นไป เห็นเรียวขาอันขาวเนียนของแม่ ทั้งเนินนูนใต้กางเกงในของแม่ชัดเจนเพราะไม่ได้ปิดไฟ ทันใดนั้นเสียงเพจดังขึ้น ของลุงชัยนั่นเองจับใจความที่แกบ่นได้ว่าเป็นใครไม่รู้เกิดป่วยขึ้นมา ซักพักเหมือนแกจะออกจากห้อง เพราะดูท่าทางตกใจ ผมจึงต้องแอบไปหลบอยู่หลังบ้าน ก็ได้ยินเสียงแกออกมาโทรศัพท์ตรงห้องรับแขก และออกจากบ้านไป ผมกลับไปที่ห้องแม่ประตูไม่ได้ล็อก ผมย่องเข้าไปนึกจะเข้าไปดูกางเกงในของแม่ซัดๆ เพราะไม่ค่อยมีโอกาศดีๆได้ดู แต่กลับกลายเป็นแม่นอนอ้าขากางเกงในถูกดึงออกมาแล้ว ภาพที่เห็นทำให้ผมใจเต้น แม่ผมนอนอ้าหีโหนกนูนเห็นรูเต็มๆ น้ำแฉะแบบเห็นได้ชัด ( สงสัยลุงแกเลียก่อนไป ) หุ่นเหมือน สาว หมวย อายุ 20 กว่าๆ ( ตอนนั้นแม่ 33 ) ผมตื่นเต้นมากแอบย่องเข้าไปดูใกล้ๆเพราะพึ่งเคยเห็นเต็มๆก็วันนี้ ผมสังเกตุแม่เหมือนกับหลับสนิทไปแล้ว ผมจึงปิดไฟ ค่อยๆ ปิดประตู แล้วย่องมาข้างเตียง พอปิดไปผมมองอะไรไม่เห็นเพราะมันมืดมาก ผมคลำไปเจอเตียง และคิดอยู่ว่าจะกลับไปเปิดไฟดีมั้ย เพราะมองไม่เห็น มือข้างขวาผมเกิดไปโดนขาอ่อนของแม่ ผมตกใจกลัวแม่ตื่นแต่แม่ก็นิ่ง ผมจึงค่อยๆเคลื่อนมือไปโดนขาแม่อีกและค่อยๆลูบขาแม่เบาๆ ตอนนั้นใจเต้นมากกลัวแม่จะตื่นบรรลัยแน่ แต่ความเงี่ยนมันหยุดไม่อยู่แล้ว มือผมค่อยๆ เลื่อนไปจนถึงหีแม่ ( ไม่เคยจับมาก่อนเลย ) ควยผมแข็งเต็มที่ตั้งแต่แอบดูแล้ว หีแม่แฉะและนิ่มมาก ควยผมแทบระเบิด ผมตัดสินใจเป็นไงเป็นกัน ผมลูบหีแม่ขึ้นลงเบาๆ เห็นแม่นิ่งไม่มีทีท่าว่าจะตื่น ผมจึงหนักมือขึ้น ตอนนั้นควยแทบระเบิดแล้ว ลูบหี เสียวที่สุดในชีวิต ผมลูบหนักมือเข้า อีกมือนึงเริ่มจับไปที่ควยของผม แม่ครางออกมาเบาๆ ผมหยุดมือนิ่งไว้ทันที ใจสั่นมาก แต่ซักพักแม่ก็เด้งก้นสู้มือผม เหมือนคนละเมอ ผมทนไม่ไหวแล้วจึงเอานิ้วคลำหารูแม่แล้วสอดนิ้วเข้าไป ตอนนั้นคิดว่าแม่ตื่น ก็ช่างหัวมันแล้ว ผมสอดนิ้วเข้าไปชักเข้าชักออก พร้อมๆกับแม่เด้งก้นรับมือผมค่อยๆ อีกมือนึงผมรูดควยไปด้วย น้ำจะแตกแล้ว แต่กลั้นไว้อยู่ ไม่นานผมกลั้นไม่ไหว น้ำผมแตกเต็มมือผมเต็มไปหมดยังกะเปิดก๊อก แต่ผมยังแข็งอยู่ ความเงี่ยนค่อยๆหายไป ผมเอามือเช้ดผ้าผ่ม เตรียมจะย่องออกไป ระหว่างที่เช็ดมือผมก็โดนจับมือ ( ตกใจสุดขีด ) แม่จับมือผมไปที่หว่างขาแม่ ได้ยินเสียงแม่พูดว่าทำอะไรอยู่ เร็วๆ สิ ซี้ด ผมปล่อยแม่ให้จับมือผมไปที่หีของแม่ ( สงสัยนึกว่าลุงชัย ) ลูบหีแม่อยู่ซักพัก แม่ก็พูดว่า ” เอาควยมาดูดหน่อย ” ผมได้ยิน กลับมีอารมณ์เต็มที่อีก อยากจะเอาให้ดูดจริงๆ เท่าที่รู้มาแม่ชอบดูดมาก ผมเฉยอยู่ แม่จึงเขยิบเข้ามาควานหาควยผมจนเจอ ต่างคนต่างมองไม่เห็น ผมสะดุ้งสุดตัว แม่จับควยผมรูดๆเบา แล้วซักพักรู้สึกได้ว่าแม่อ้าปาก อมควยผมเข้าไปเต็มๆ ตอนนี้เสียวที่สุดในชีวิตเลยครับนึกภาพแม่กำลังดูดควยลูกชายแท้ๆอย่างเอร็ด อร่อย แม่ดูดอยู่ซักพัก แม่ก็ถอนปากออก แล้วพูดว่า ” ควยใหญ่จังนะวันนี้ ” ผมเห็นแม่พูดแบบนี้ ก็เกิดกลัวขึ้นมาสงสัยจะสร่างขึ้นมาแล้ว แต่ตอนนั้นทำอะไรไม่ได้ ต้องเลยตามเลย แม่ดูดมันส์มาก ดูดรูดขึ้นรูดลงจนสุด ผมเสียวจนทนไม่ไหวจับหัวแม่กด แล้วกระเด้าตามปากแม่ เผลอครางออกมา ” อาว์ ~~ ” แม่ถอนปากออกทันที แต่มือยังกำรอบควยอยู่ ถามว่า ” เฮ้ยใครน่ะ พี่ชัย ? ” ผมตกใจมาก ไม่กล้าตอบ แม่หยุดไปซักพัก ก็ดูดของผมอีกรอบ คราวนี้แม่ดูรุนแรงกว่าครั้งก่อนมาก แถมมือก็รูดไปด้วย ปากก็ดูดหัวถอกสลับกับลิ้นเลีย ผมเสียวมากเพราะแม่ชักให้มันส์มาก ซักพักแม่เอามือออกแล้วดูดควยผมเต็มลำ ผมเสียวทนไม่ไหวเด้งก้นเอาควยเข้าปากแม่เป็นจังหวะ แต่มันไม่ยักเสร็จเหมือนผมชักว่าวเสร็จเร็วมาก ผ่านไปนานพอสมควร แม่ถอนปากออก แล้วพูดว่า ” เงี่ยนมากมั้ย ” ผมไม่รู้จะตอบว่าอะไรเพราะมันตอบไม่ได้ แม่พูดขึ้นอีก ” ไม่ต้องอายหรอก ต้อง แม่ถามว่าเสียวมากมั้ย ” คราวนี้เหมือนฟ้าผ่าเลยครับ ผมรีบดึงควยออกจากมือแม่ แล้วรีบบอกว่า ” ขอโทษครับแม่ ประตูมัน ” พูดได้แค่นั้น แม่ก็จับควยผมดูดต่อ ผมงงมาก แต่พอรู้ว่าแม่ไม่โกรธเลยยอมให้แม่ดูดต่อ ” อืม.. ควยใหญ่ดีจริง ” แม่พูดพร้อมควยผมเต็มปาก ผมได้ใจจับหัวแม่เอาควยเด้งใส่ปากแม่อีก คราวนี้ครางออกมาได้ถนัดหน่อย ซักพักแม่เอาลิ้นเลียไข่ กับรูก้นให้ผม ท่าทางหน้าตาของแม่ดูเงี่ยนสุดๆเหมือนผมไม่ใช่ลูกแม่แต่เป็นผัวแม่เลย ผมครางออกมาเต็มที่ ” เสียวครับแม่ อูย เสียวมากเลย ” มือแม่ก็ชักให้ผมไปด้วย แปลกมาก ถ้าเป็นมือละก็ผมจะแตกอีกแล้ว ซักพักผมไม่ไหวก็ปล่อยออกมาอีก คราวนี้เสียวกว่าตอนแรก แม่ถามผมว่าเสร็จแล้วหรอ แล้วแม่ก็ลุกไปเปิดไฟ ผมนั่งตัวเกร็งเลย แม่บอกว่ารู้ตั้งแต่เอามือมาจับหีแม่แล้ว แต่แม่แกล้งหลับ แม่บอกว่าเป็นหนุ่มแล้วคงเงี่ยนเป็นเหมือนกันนะ แม่นั่งคุยกับผมทำให้ผมเห็นหุ่นแม่ชัดๆเต็มตา หุ่นแม่ยังดีมากไม่มีพุงเลยแถมนมก็ยังสวยอยู่แต่หัวนมจะใหญ่หน่อย หีแม่นี่สวยสุดๆ ผิวขาวสวย ต่างกับผมผิวออกสีแทนๆ แม่บอกว่าเคยเอาผู้หญิงรึยัง ผมก็ตอบตามความจริงว่าไม่เคยครับ ถ้าอยากก็มาบอกแม่ เดี๋ยวแม่ทำให้ ผมถามว่า ” แม่ไม่โกรธหรอครับ ” แม่บอกแม่รู้นานแล้วว่า ต้องมาแอบดูอยู่เห็นรูอยู่ข้างประตู คราวนี้ต้องช่วยแม่บ้างนะ แม่กางขาออกโชว์ความอวบของหีแม่ให้ผมดู ” ก้มลงไปหอมมันสิ ” แม่สั่ง ผมรีบทำตามทันทีทันที ก้มลงไปหอมมันและใช้ลิ้นเลียมัน กลิ่นมันออกคาวๆแต่หอมมาก ควยผมแข็งเต็มที่อีกแล้ว ผมเลียจนแม่ครางออกมาเสียงกระเส่า ” อาว์ .. อูย ” ผมได้ใจเอาหน้าละเลง หีแม่เต็มที่น้ำเงี่ยนแม่เลอะเต็มหน้าผมเลยท่าทางแม่เสียวมาก แม่บอกว่าไม่ไหวแล้ว แม่ให้ผมนอนหงาย แม่ยกตัวขึ้นเอาหีมาจ่อที่ควยผมแล้วกดลงไป ผมเจ็บมากร้องโอ๊ยเลย แม่บอกว่า ” เสียวหรอ ต้องเป็นผัวแม่แล้วนะ ” แต่ผมเจ็บเหมือนหนังมันฉีก แต่ตอนนั้นควยแข็งมากอย่างที่ไม่เคยแข็งขนาดนี้มาก่อน แม่เริ่มขย่มผมอย่างค่อยๆ หีรูดควยขึ้นลง หีแม่ฟิตและลื่นมาก ตอดควยดังตุบๆเหมือนเอามือบีบเลย จากเจ็บเริ่มเสียวนิดๆ
