เรื่องเสียวรุมโทรม , เล่าเรื่องเสียว เมื่อวันศุกร์ที่ผ่านมานั่งทำงานอยู่บนห้องรู้สึกเงี่ยน อยากโดนควยเย็ดหี จึง เอามือลูบที่หว่างขาตัวเองเล่นยิ่งลูบยิ่งเงี่ยน จึงหยิบโทรศัพท์โทรหาเพื่อน รุ่นน้องที่ เคยให้เย็ดเมื่อเวลาเงี่ยนแต่ปรากฏว่าไม่สามารถติดต่อได้ เลยรูดซิบกางเกงตัวเองเอามือลูบหี และเอานิ้วแหย่หี ยิ่งเงี่ยนมากขึ้นจึงเอา โทรศัพท์โทรหาเด็กนักเรียนที่เคยให้เย็ด แต่ก็ติดต่อใครไม่ได้เลยสักคนเดียว เงี่ยนมากจึงถอดกางเกงและกางเกงในออกเพื่อที่จะได้เล่นหี ตัวเองให้ถนัดๆ เอา นิ้วมือแหย่หีตัวเองจนเสียว จึงเอานิ้วสองนิ้ว แหย่ทำให้เสียวมากขึ้นพอดีมองเห็นขวดลิโพจึงหยิบเอมมาเช็ดจนสะอาดแล้วก็เอา ขวดลิโพเย็ดหี ตัวเองแทนนิ้วดันขวดลิโพเย็ดหีตัวเองเข้าไป ครึ่งขวดแล้วซอยขวดลิโพเย็ดหีเร็วขึ้นจนทั้งเสียวทั้งเงี่ยนจนต้องหลับตาเอาขวดลิโพเย็ดหีด้วย ความมันจนสักพักใหญ่น้ำเงี่ยน แตกจนเยิ้มขวดลิโพก็ลืมตาขึ้น เพื่อดูผลงานของ ตัวเองแต่ก็ต้องตกใจเมื่อเห็นเด็กนักเรียนสองคนกำลังยืนแก้ผ้ามองอยู่โดยมือ กำลังสาวควยที่ลุกแข็งโด่มีขนาดทั้งยาวทั้งใหญ่ฉันตกใจถามเด็กทั้งสองคนโดย ที่ขวดลิโพยังคาหีอยู่ อุ้ยอนุชากับวิชัยเธอขึ้นมาเมื่อไรนี่และนั่นเธอทำอะไรนะ ผมขึ้นมาตั้งแต่อาจารย์ภาศรีหลับตาเอา ขวดลิโพเย็ดหี อยู่นะ ครับเห็นแล้ว เงี่ยนอยากเย็ด อาจารย์จนควยแข็ง ก็เลยเอามือสาวควย เล่นรอเย็ดอาจารย์นะครับ ฉันนึกได้ว่าขวดลิโพยังคาหี อยู่รีบดึงขวดลิโพออกจากหีแล้วเอา มือปิดหีตัวเอง ไว้ส่วนปากก็พูดว่า เธอสองคนจะบ้าเหรอเห็นครูเป็นอะไรถึงบอกว่าสาวควยรอเย็ดครู ก็ผมสองคนเห็นอาจารย์กำลังเงี่ยนผมก็จะช่วยเย็ดหี อาจารย์แก้เงี่ยนให้ไง ครับแล้วอาจารย์ไม่ต้องเอามือปิดหรอกผมเห็นจนหมดแล้ว เธอรู้ได้ยังไงว่าฉันเงี่ยนอย่าพูดบ้าๆนะ ไม่เงี่ยนแล้วทำไมอาจารย์เอาขวด ลิโพเย็ดหีจนน้ำเงี่ยนแตกแฉะหีอย่างนั้น ละมาให้ผมเอาควยเย็ด เถอะรับรองมันกว่าขวดลิโพเยอะเลย พร้อมกับพูดทั้งสองคนก็เดินสาวควยเข้ามาหาฉันที่เก้าอี้ฉัน เองมองเห็นควยขนาดยาวใหญ่ของทั้งสองคนแล้วก็อยากให้เอาเย็ดหีแก้เงี่ยน เหมือนกันทั้งสองคน พอเข้ามาถึงก็เข้ามานั่งข้างๆเก้าอี้แล้วจับขาฉันให้ถ่าง ออกอนุชาก็ก้มลงมา เอาปากจูบที่ร่องหี แล้วเอาลิ้นเลียร่องหีที่อ้าอยู่แล้วก็เลียที่ติ่งแตด ฉัน เสียวจนต้องแอ่นหีตัวเองรีบลิ้นที่เลียลงมาส่วนวิชัยก็เข้ามาถอดเสื้อ และ เสื้อชั้นในฉันออกแล้วก็เอาปากมาดูดหัวนมส่วนมืออีกข้างหนึ่งก็บีบขยำนม วิชัยทั้งดูดทั้งกัดหัวนมจนฉันเสียวทั้งนมและหี โอ้ยซี๊ดหีหีนมนมอนุชาวิชัยครูเสียวหี เสียวนมซี๊ดหีหีชาจ๋าหีครูชัยจ๋านม ครูโอ้วจะแตกแล้วน้ำหี ครูน้ำเงี่ยนครูจะแตกแล้วซี๊ดแตกแล้วชาจ๋าน้ำเงี่ยน ครูแตกแล้วชาเอาควยเย็ดหีครูเถอะครู เงี่ยนอยากให้ชาเอาควยเย็ดหี ฉันบอกให้อนุชาเอาควยเย็ดหีฉันด้วยความเงี่ยนและความร่าน อนุชากับวิชัยก็เลยช่วยกันประคองฉัน ไปที่โต๊ะแล้วจับฉันนอนหงายบนโต๊ะอนุชาขึ้นไปนั่งคร่อมตรงหว่างขาฉันส่วนวิชัยขึ้นไปนั่งคุกเข่าอยู่ตรง หน้าฉันฉันจับควยที่ยาวใหญ่ ของอนุชาเอาหัวควยจ่อ ที่หีอนุชาพอควยจ่อ ที่หี เขาก็ดันควยเย็ดหี ฉันอย่างแรง แต่ควยของเขาทั้งคับทั้งแน่นเพราะความใหญ่ควยอนุชาเย็ดหีฉันเข้าไปได้ไม่ถึงครึ่งควย ฉันเจ็บหีจนต้องให้เขาหยุดเย็ด โอ้ยอนุ ชาครูเจ็บหีหยุดเย็ดก่อนควยเธอทั้งคับทั้งแน่นหีครูจนเจ็บไปหมดแล้ว โอ้ยหีหี อนุชาเขาหยุดเย็ดวิชัยเขาก้มลงมาจูบปากเอาลิ้นเข้าไปตะหวัดเกี่ยวกับลิ้นฉัน ส่วนมือก็บีบขยำบี้หัวนมจนฉันเสียวและเงี่ยนเพราะรสจูบทำให้น้ำเงี่ยนออกมา เยื้มหีอนุชาพอเห็นหีฉันเยิ้มด้วยน้ำเงี่ยนก็ดันควยเย็ดอย่างแรงจนควยเขา ทะลวง เข้าไปในรูหีมิดลำควย จนหัวควยชนกับมดลูกของฉัน โอ้ยแหกหีแหกแล้วซี๊ดอนุชาหัวควยชาเข้าไปดันมดลูกครูจนเสียวไปหมดแล้วชาจ๋า ควยชาทั้งยาวทั้ง ใหญ่หี ครูแหกหมดแล้ว อนุชาพอดันควยเย็ดหีฉันจนมิดแล้วเขาก็ลงมือสาวควยกระเด้าเย็ดหี ฉันโดยไม่ฟัง เสียงร้องของฉันเขาสาวควยเย็ดอย่างรุนแรงด้วย ความเงี่ยนและเย็ดแรงขึ้นเร็ว ขึ้นฉันเองตอนนี้ความเจ็บไม่รู้หายไปไหนมีแต่ความเสียวและความร่านเด้งหีรับควยอนุชาที่เย็ดลงมาด้วยความเงี่ยนและร่าน ในขณะเดียวกันวิชัยก็เอาควยมาจ่อที่ปากฉันให้ฉันอมและดูดฉันเองก็อ้าปากดูดอมควยวิชัยด้วยความร่าน ตอนนี้เลยมีสองควยที่เย็ดฉันควยนึงเย็ดหี อีกควยเย็ดที่ปาก ฉันทั้งเสียว ทั้งเงี่ยนแต่ ก็ร้องไม่ออกเพราะว่าควยวิชัยเย็ดคาปากอยู่อนุชาเย็ดฉันจนน้ำเงี่ยนฉันแตกถึงสามครั้ง เขาจึงดันควยอัดเข้าไปสุดๆ จนหัวควยมุดเข้าไป ในมดลูกฉันแล้วเขาก็ ฉีดพ่นน้ำอสุจิใส่เข้าไปในมดลูกฉันอย่างแรงจนฉันร้อนวาบไปทั้งมดลูกส่วน วิชัยก็ฉีดน้ำกาม ใส่ปากฉันแล้วให้ฉันดูดกินน้ำกามของเขาจนหมด พออนุชาเอาควยออกจากหีฉันวิชัยที่ควยยังแข็งอยู่ถึงน้ำกามจะแตกแล้วก็เข้ามาเอาควยเย็ดหี ฉันต่อทันที ส่วนอนุชาเอาควยที่ยังลุกแข็งอยู่เช่นเดียวกันมาให้ ฉันเอาปากอมและ ดูดต่อวิชัยเย็ดฉันอยู่นานมากเพราะน้ำกามแตกไปแล้วครั้งนึงวิชัยเย็ดฉันอยู่ เกือบสี่สิบห้านาทีทำให้ฉันน้ำเงี่ยนแตกไปห้าหกครั้งวิชัยจึงน้ำ กามแตกใส่หี ฉันส่วนอนุชาก็น้ำกามแตกใส่ปากให้ฉันดูดกินจนหมดเหมือนกันหลังจากนั้นเด็ก ทั้งสองคนก็พักอยู่เกือบครึ่งชั่วโมงอนุชาก็ควยแข็งโด่เข้ามาหาฉัน แล้วบอก ให้ฉันนอนคว่ำเอาหมอนมารองตรงท้องน้อยจนก้นกระดกเห็นหีชัดอนุชาก็เข้ามานอน ประกบด้านหลังเอาควยจ่อที่หีแล้วทะลวงควยเย็ดหีฉันทางด้าน หลังอย่างแรงจนควย ทะลวงเย็ดเข้าไปในหีฉันทีเดียวมิดลำควยเลยแล้วอนุชาก็ซอยควยกระเด้าเย็ดหี ฉันอย่างแรงและเร็วจนฉันต้องร้องครางด้วยความเสียว และความเงี่ยนน้ำหีแตกอีก หลายครั้งพออนุชาพ่นน้ำกามใส่หีฉันเสร็จวิชัยก็เข้ามาบอกให้ฉันนั่งคุกเข่า โก้งโค้งแล้ววิชัยก็นั่งคุกเข่าทางด้านหลังเอาควยทะลวง เย็ดหีฉันในท่าคุกเข่าโก้งโด้ง วิชัยเย็ดฉันรุนแรงมากส่วนมือก็เอื้อมมาบีบขยำนมอย่างแรงวิชัย เย็ดแรงจนหนอกควยเขากระแทกง่ามก้นฉัน ดังปั๊บปั๊บหัวควยเข้า ไปชนมดลูกตลอด เวลาฉันยิ่งโดนวิชัยเย็ดรุนแรงก็ยิ่งทั้งเงี่ยนทั้งร่านบอกให้วิชัยเย็ดแรงๆ อีก ซี๊ดชัยจ๋าเย็ดหีครู แรงๆอีกซี๊ดมีนหีดีจังผัวขาเย็ดหีเมียแรงๆเลย เย็ดให้หี แหกไป เลยผัวขา ฉันเงี่ยนจนต้องเรียกวิชัย เป็นผัวพร้อมกับโยกหีสู้กับควยของวิชัยที่เย็ด เข้ามาจนน้ำเงียนแตกแล้วแตกอีกในที่สุดวิชัยก็น้ำกาม แตก ใส่หีฉันพอวิชัยดึง ควยออกจากหีฉันอนุชาก็เข้ามาจับให้ฉันยืนโก้งโค้งเอามือท้าวเก้าอี้ แล้ว อนุชาก็มายืนเย็ดฉันทางด้านหลังต่อทันทีหลังจากอนุชาเย็ดฉันใน ท่ายืน เสร็จวิชัยก็ให้ฉันเย็ดกับเขา ต่อในท่าที่วิชัยนั่งบนเก้าอี้แล้วให้ฉันนั่ง คร่อมเอาหีขย่มเย็ดควยของเขาโดยวิชัยช่วยจับ เอวแล้วแทง ควยสวนเข้ามาแล้วน้ำ กามวิชัยก็แตกใส่หีฉันอีกครั้งถึงตอนนี้ฉันโดน อนุชาและวิชัยเย็ดหีคนละสามที รวมเป็นหกทีฉันบอกกับเด็กทั้งสองคนว่าวันนี้พอ แค่นี้แต่เด็กทั้งสองคนบอกว่ายัง ไม่ถึงจุดที่อยากจะทำ ให้ฉันเลยขอพักเดี๋ยว ก่อนแล้วจะเย็ดต่อรับรองว่าฉันจะต้องติดใจแน่พอหลังจากพักประมาณครึ่ง ชั่วโมงอนุชาก็ขึ้นไปนอนหงายบนโต๊ะควย ลุกตั้งโด่แล้วบอกให้ฉันขึ้นไปนั่ง คร่อมเอาหีเย็ดควยเขาพอ ควยเย็ดเข้าหีมิดอนุชาก็บอกให้ฉันขย่มหีเย็ดควยเขา สองสามทีอนุชาก็ดึงตัวฉันลงไปเพื่อเอาปากดูด กัดหัวนมฉันทำให้ก้นฉันโด่งลอย จนมองเห็นรูตูดแล้วฉันก็รู้สึกว่าวิชัยเอาอะไรมาทาที่รูตูดฉันเย็นๆแล้ วิชัย ก็เอานิ้วมือแหย่เข้ามาในรูตูดฉันที่แรกนิ้วเดียวทำให้ ฉันรู้สึกเสียวแปลกๆ สักพักก็เอาสองนิ้วแหย่ฉันเองตอนนี้ทั้งเสียวหีเสียวตูดจนพักใหญ่วิชัยก็เอา นิ้วออกฉันรู้สึกมีอะไรมาทา มากขึ้นแล้ววิชัยก็เอาควยมาจ่อที่รูตูด ฉันแล้ว ดันควยเย็ดตูดฉันจนเข้าไปมิดหัวควยฉันตอนนี้เจ็บจน ต้องร้องพยายามจะเบียงตูด หนีแต่ก็ทำไม่ได้เพราะอนุชากอดไว้แน่น โอ้ยเจ็บนี่เราสองคนจะทำ อะไรครู ผมสองคนจะทำให้อาจารย์ภาศรีมีความสุขอีกแบบนึงโดยเย็ดหี และตูดอาจารย์ พร้อมๆกัน โอ้ยไม่เอานะครูเจ็บอย่าทำอย่างนั้น ทนอีกนิดนะ อาจารย์ภาศรีเดี๋ยวพอควยไอ้ชัยมันเข้ามิดแล้วผมสองคนเย็ดอาจารย์ พร้อมๆ
