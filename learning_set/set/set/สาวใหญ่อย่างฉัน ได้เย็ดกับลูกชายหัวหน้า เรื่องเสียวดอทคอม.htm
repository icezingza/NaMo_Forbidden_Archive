เพราะคำสัญญาที่ให้ไว้กับแม่ของเขา ทำให้ฉันได้รับประสบการณ์ที่เสียวซ่านที่สุดในชีวิต ฉันเป็นข้า ราชการวัย 50 กว่าๆ มีสามีแล้วแต่แยกทางกันไปนาน มีลูกสองคน แต่ยังรักษารูปร่างไว้อย่างดี เพราะเป็นคนผิวขาวสวย วันหนึ่งในช่วงหน้าร้อนปีที่แล้ว ลูกชายของหัวหน้าฉันเกิดอุบัติเหตุ ขาหัก และแขนซ้ายหัก และเนื่องจากหัวหน้าและภรรยาต้องรีบไปต่างจังหวัด ฉันจึงถูกขอให้ช่วยดูแลลูกชาย ของเขา เนื่องจากครอบครัวนี้อยู่กันเพียงแค่สามคน ทำให้ฉันต้องเข้ามาอยู่ในสถานการณ์นี้ ลูกชาย หัวหน้าคนนี้อายุประมาณ 25 ปี หลังจากที่ฉันเลิกงานประมาณทุ่มครึ่ง ฉันก็รีบอาบน้ำเปลี่ยนชุดแล้วไปบ้านหัวหน้า ลูกชายของเขาชื่อ ว่า นัท ส่วนฉันชื่อว่า มิน เมื่อฉันเข้ามาในห้อง… “นัท พี่ต้องทำอะไรบ้าง?” นัทตอบว่า “ช่วยเช็ดตัวกับเปลี่ยนเสื้อผ้าให้ผมหน่อยครับพี่มิน” เพียงแค่นั้นฉันก็รู้สึกเสียววาบที่ท้องน้อย ตั้งแต่เลิกกับสามีมา 9 ปี ฉันยังไม่เคยเห็นผู้ชายโป๊จริงๆ เลยนอกจากในซีดีที่ดูคนเดียวในห้องนอน “เอาวะ” ฉันคิดในใจ เริ่มจากถอดเสื้อนัทก่อนแล้วค่อยๆ เช็ดตัวให้เขาที่ท่อนบน มือฉันสั่นไปหมด โดยเฉพาะ ตอนเช็ดโดนหัวนมของเขา มันตั้งชันทำให้ฉันแทบอยากจะดูดเลียให้สะใจ นัทดูเหมือนจะรู้ เพราะ เขาเริ่มหายใจแรงขึ้น แต่คงกลัวฉันจะอายเลยพยายามกลั้นไว้ แต่เมื่อฉันเช็ดตัวใกล้ถึงท้องน้อย เขาหายใจแรงขึ้นพอๆ กับความรู้สึกในใจของฉัน ฉันเห็นควยในกางเกงแพรเริ่มขยายตัว หีของฉันก็ยิ่งแฉะขึ้นเรื่อยๆ จนความต้องการชนะความอาย ฉันจึงเอ่ยขึ้นว่า “อากาศในห้องนอนนัทอบอ้าวจังเลยเนาะ” พร้อมกับปลดกระดุมคอเสื้อออกสองเม็ด เผยให้เห็นเนินอกคัพ C ของฉัน พร้อมกับก้มลงทำเป็นปัดฝุ่น ที่ข้อเท้าให้เขาเห็นนมชัดๆ (ฉันไม่ได้ใส่เสื้อชั้นในเพราะคิดว่ามาแป๊บเดียวก็กลับแล้ว) นัทคงจะรู้ แล้วจึงบอก “พี่มินครับ ช่วยเช็ดท่อนล่างให้ผมด้วยนะครับ เพราะผมยังอาบน้ำไม่ได้” พร้อมกับส่งสายตาหื่นกระหายมาให้ ฉันซึ่งเป็นม่ายสาวก็รู้ทันทีว่ามันคือสัญญาณของความต้องการ ฉัน ทำท่าทีเฉยแล้วตอบว่า “งั้นเดี๋ยวพี่ไปเปลี่ยนน้ำเช็ดตัวก่อนนะ” แต่ที่จริงแล้วฉันรีบออกไปล็อกประตูบ้าน แล้วจึงเปลี่ยนน้ำเช็ดตัวเข้าไปใหม่ เมื่อฉันกลับไป ก็เริ่ม ปลดปมกางเกงแพรของเขาด้วยมือสั่นระริก หัวใจเต้นโครมคราม เสียววูบไปหมด เมื่อกางเกงแพร หลุดพ้น ฉันก็พบกับควยขนาดใกล้เคียงข้อมือเด็ก หัวแดงเหมือนในซีดีโป๊ นัทเห็นฉันนิ่งอยู่ จึงกระซิบบอก “พี่มินครับ เช็ดตัวให้ผมต่อเถอะครับ อย่าหยุดเลยนะ” ตอนนั้นฉันไม่รู้ว่าเป็นเพราะความเงี่ยนหรืออะไรก็ตาม ฉันขยับขึ้นไปนั่งชันเข่าข้างนัทด้านที่แขนไม่หัก ถ่างขาออกเล็กน้อย เพื่อให้เขาเห็นเนินหีอวบอูมของฉัน (ฉันแอบถอดกางเกงในออกตั้งแต่ไปล็อก ประตูบ้านแล้ว) พร้อมกับดึงมือเขามาวางที่โคนขาอ่อนด้านใน “นัท ลูบดูสิ พี่รู้สึกว่าตัวพี่เหนียวไปหมดแล้ว” แค่นั้นเอง นัทก็หมดความอดทน พุ่งมือเข้ามาที่โคกหีของฉันทันที พร้อมๆ กับที่ฉันคว้าท่อนควยขนาด เหมาะมือของเขาแล้วเริ่มรูดขึ้นลง “โอ๊ว…อาห์.. บี้แตดพี่ด้วยสิ อ๊าห์ ตรงนั้นแหละ โอ๊ย…นัท โอ๊ สุดยอดเลยผัวขา” “ซี๊ด..พี่มิน อ๊า…เสียวไหมพี่ ชอบไหม?” ฉันตอบด้วยเสียงที่สั่นสะท้านว่า “ชอบมากเลยนัทขา แหย่ เข้าไปลึกๆ อีก ซี๊ด…ลึกๆ แรงๆ เลย” เมื่อความเสียวซ่านเข้าครอบงำ ฉันก้มลงเลียรอบๆ หัวควยของเขา ใจนึกถึงซีดีที่เคยดู แล้วเริ่มดูด ควยทันที “โอ๊ว…ซี๊ด พี่มินทำไมดูดเก่งแบบนี้ เสียวไปทั้งท่อนควยแล้ว” ฉันทั้งดูดทั้งเลียด้วยความเงี่ยนอย่างเต็มที่ เสียวรูหีสุดๆ เพราะนัทใช้สองนิ้วทะลวงเข้ามาอย่างไม่ ยั้ง แต่แทนที่จะเจ็บ ฉันกลับเด้งรูหีใส่นิ้วอย่างแรง “อ๊า…ซี๊ด พี่มินอย่าเพิ่งเร่งครับ เดี๋ยวจะเกมส์ซะก่อน” ฉันจึงถอนปากออกจากควย แล้วหันมาถอดเสื้อกับกางเกงนอนขาบานออก แล้วเริ่มขึ้นคร่อมป้อนนมใส่ ปากนัทอย่างสุดกระสันต์ “ผัวขาดูดนมแรงๆ เลย เมียเงี่ยนจะตายอยู่แล้ว…ซี๊ด…อู๊ย…” นัทไขว่คว้าดูดนมของฉันอย่างหิวกระหาย พร้อมกับแอ่นท่อนควยบดเบียดใส่ร่องหีฉันไปพร้อมๆ กัน “ซู๊ด…โอ๊ว” ฉันครางออกมาอย่างลืมอาย “พี่มินครับ เขยิบหีขึ้นมาหาปากผมสิครับ แล้วพี่จะรู้ว่าความสุขเป็นแบบไหน” “แหม๋ อายุแค่นี้เก่งจริงนะ” ฉันเอ่ยขึ้นแบบเสียงกระเส่า พร้อมเลื่อนสะโพกขึ้นไปหาปากนัท เพียงแค่ลิ้นแรกที่สัมผัส ฉันแทบจะบด รูหีและเม็ดแตดใส่ปากกับลิ้นของเขาอย่างลืมตาย สามีเก่ายังไม่เคยเลียหีให้ฉันเลย มาเจอชั้นเชิง เด็กอายุ 20 กว่าๆ ฉันแทบจะคลั่ง “ซี๊ด…ซี๊ด…โอย…อ๊า…โอ๊ว…นัทขา…ผัวขา สุดยอดเลยยยย…เสียวรูหี…เสียวแตด…ใจจะขาดแล้ว” ฉันร้อง ออกมาอย่างสุด กลั้น พร้อมกับบดหีใส่หน้านัทอย่างเต็มที่ “โอ๊ววววว…ซี๊ด…..ไม่ไหวแล้ว พี่ขอเย็ดเถอะ” ฉันเลื่อนตัวลงไปพร้อมกำท่อนควยของเขา แล้วเอาหัวควยมาถูร่องหีเพื่อสร้างความคุ้นเคย ก็เพราะ ไม่ได้เจอของจริงมาตั้งแปดเก้าปี ต้องสร้างความคุ้นเคยกันหน่อย ก่อนจะค่อยๆ กดหีลงไปเรื่อยๆ “ซู๊ด…พี่มินครับ ทำไมรูหีพี่ถึงฟิตดีจริงๆ เหมือนเด็กสาวๆ เลย โอ๊ว…” ก็แน่ละ ฉันคิดในใจ ตั้งแต่สามีตาย ฉันก็มีแต่หมอนข้างกับน้ำจากฝักบัวเป็นผัวชั่วคราวนี่นา พอเข้าไป ได้จนสุด ฉันก็แทบขาดใจกับความเสียวซ่านที่ได้รับจากควยเด็กหนุ่ม เมื่อเริ่มชิน ฉันสวมวิญญาณเป็น จ็อกกี้ ควบขย่มควยนัทอย่างสุดแรง ทั้งขย่ม ทั้งร่อน ทั้งโยก ตามที่เคยเห็นจากหนัง นัทก็ไม่ยอมแพ้ เด้งควยสู้ฉันอย่างไม่ถอย “โอ๊…โอ๊…โอ๊ ขย่มแรงๆ เลยพี่มิน เอาให้สะใจพี่เลย” “ได้เลยผัวขา…ซู๊ดดด…..ควยแข็งๆ แบบนี้เมียสู้ตายเลย” “มันส์ไหมพี่ โอ๊ว…ชอบไหม ผมเย็ดมันส์ไหม” “สุดยอดเลยนัทจ๋าาาา…ซี๊ดดดด…ทำไมเย็ดเก่งแบบนี้ อ๊าาาาา…พี่จะมาให้นัทเย็ดบ่อยๆ เลย” “โอ๊วววว…ผมก็ชอบหีฟิตๆ แบบนี้ อ๊าาา…พี่มินจ๋าาา…..เร่งเร็วๆ น้ำจะแตกแล้ว จะออกแล้วพี่” “พี่ก็เหมือนกัน โอ๊ววววว…แตกข้างในเลยยยย…พี่ทำหมันแล้ว เอาเลยๆๆๆๆๆ ซี๊ดดดดดดด ….อ๊าววววววว….ผัวขาาาา…เมียเสร็จแล้ว” “อ๊าาาา….พี่มิน ซี๊ดดดดดด…โอ๊วววววว..ออกแล้วพี่..ออกแล้ว!!!!!!!!!!” ฉันแทบสลบไปกับความมันส์ที่เด็กหนุ่ม อายุห่างกัน 20 กว่าปี ป้อนให้ ตั้งแต่นั้นมาเราก็แอบมีความ สัมพันธ์กันมาเรื่อยๆ จนถึงทุกวันนี้ (เมื่อคืนหัวค่ำเราก็แอบมีอะไรกันในห้องน้ำที่ทำงานฉันอีก ยกหนึ่งค่ะ)
