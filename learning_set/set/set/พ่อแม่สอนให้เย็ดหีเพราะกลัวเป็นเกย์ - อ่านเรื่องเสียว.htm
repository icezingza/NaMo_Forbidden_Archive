แม่กระซิบบอกผมว่าน้ำของหนูเยอะจัง ขนาดน้ำออก 3 ครั้งแล้ว ดูซิมันไหลเลอะง่า มขาของแม่แล้ว ผมพลิกตัวลงจากแม่ แล้วก้มดูน้ำควยที่ขาวข้นที่ไหลย้อยออกมาจากรูหีของแม่อย่างชัด เจน แม่เอาชายผ้าถุงเช็ดน้ำเมือกเงี่ยนของผม แล้วนอนหลับตาอย่างมีความสุข ผมนอนกอดแม่ไว้สักพักหนึ่ง ผมก็ลุกออกมาอาบน้ำ หลังจากนั้นแม่ก็บอกให้ผมเดินไปซื้อกับข้าวที่ร้านค้า มากินกัน เวลานั่งกินข้าวด้วยกัน ผมยังรู้สึกอายๆ แม่อยู่เหมือนกัน แต่แม่ผมทำตัวปกติพูดคุยกันตาม ธรรมดา ไม่ได้ท่าทีอะไรหรือพูดอะไรให้ผมรู้สึกเขินอายเลย ตอนกลางคืนเวลาที่พ่อออกไปธุระข้าง นอกหรือออกไปส่องปลาตามคลองใกล้ๆ บ้าน ผมกับแม่ก็จะเย็ดกันทุกครั้ง กว่าพ่อจะกลับเข้าบ้านผมก็ เอาน้ำเข้ารูหีของแม่ไป 2 ครั้งแล้ว หลังจากพ่อกลับเข้าบ้าน พ่อก็จะเอากับแม่ต่อทันที ท่าทางพ่อกับ แม่ผมมีอารมณ์รุนแรงมากๆ ครางอู้วไม่หยุดปากเวลาที่เอากัน แม่ผมยังเอามือจับกุมท่อนเอ็นของผมไว้ตลอดเวลาเหมือนที่เคยทำ จนพ่อปล่อยน้ำควยพุ่งใส่ใน รูหีอารณ์เงี่ยนจัดของพ่อกับแม่ก็จะสงบลงและนอนกอดก่ายกันอย่างมีความสุข คืนหนึ่งตอนที่ผมกับแม่ กำลังเอากันอยู่ในห้อง 2 คน แม่ก็พูดเรื่องพ่อให้ผมฟังว่า พ่อจะมีอารมณ์มากถ้ามีคนมานอนดูอยู่ใกล้ๆ เวลาที่เอากันกับแม่แบบนี้ พ่อเขาอ่านเจอเรื่องแบบนี้ในหนังสือโป๊
