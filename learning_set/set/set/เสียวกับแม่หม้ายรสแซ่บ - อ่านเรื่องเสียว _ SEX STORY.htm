เล่าเรื่องเสียว ผมชื่อ “เดช” เป็นคนต่างจังหวัด แต่ผมเข้ามาทำงานในกรุงเทพฯ หลายปีแล้ว ผมทำงานก่อสร้าง เป็นช่างทาสี ได้ค่าแรงวันละสองร้อยกว่าบาท ก็นับว่าดีแล้ว ดีกว่าทำงานที่บ้านนอกมาก ผมมาทำ งานที่นี่ทำให้ผมรู้จักกับแม่ม่ายเสน่ห์แรงคนหนึ่ง เธอชื่อ “พี่แอม” อายุมากกว่าผม 9 ปี ทำงานเป็น กรรมกรอยู่ที่เดียวกับผม พี่แอมอยู่กับน้องสาวชื่อ “อ้อม” อายุอ่อนกว่าผม 2 ปี หน้าตาสวยดีทั้งพี่ ทั้งน้องเลยทั้งสองเป็นคนต่างจังหวัดเหมือนกัน มาทำงานในกรุงเทพฯ นานหลายปีแล้วเหมือนกัน ทั้ง สองคนพี่น้องสนิทสนมกับผมมาก เพราะเธอทำงานที่เดียวกับผมคอยช่วยงานให้ผม เรียกว่าเป็น ลูกน้องผมนั่นเอง เวลาทำงานเราจึงได้มีโอกาสอยู่ใกล้กันทุกวันเลย สถานที่ก่อสร้างแห่งนี้มีที่พักให้คนงานทุกคนด้วย ปลูกเป็นเรือนสังกะสีเก่าๆ ติดกันหลายห้อง ผมเป็น คนโสดตัวคนเดียวก็ได้ห้องพักเหมือนกัน เมื่อก่อนผมพักอยู่กับเพื่อน แต่ต่อมาเพื่อนได้ลาออกจากที่นี่ไป ผมจึงได้อยู่คนเดียว ส่วนห้องของพี่แอมก็อยู่ติดกับผมนี่แหละ พี่แอมอยู่รวมกับอ้อมห้องเดียวกัน ห้อง ของเราทั้งสองนี้อยู่ไกลจากคนอื่นนิดหน่อย เพราะถัดไปจากห้องของผมกับห้องของพี่แอม ก็จะเป็น ห้องว่างอีกสองห้อง เลิกจากงานมาก็อาศัยห้องดังกล่าวนี้แหละเป็นที่หลับนอน ซุกกายพักผ่อนตาม ประสาคนจน ยิ่งนับวันผมกับพี่แอมก็สนิทสนมกันมากขึ้น ถึงพี่แอมจะเป็นแม่ม่ายแต่ผมก็รักเข้าแล้ว เพราะพี่แอมสวยมาก หน้าอก หน้าใจเต่งตั้งเต้า ร่องรอยของความเป็นแม่ม่ายที่เคยผ่านการมีผัวมาแล้วไม่ปรากฏให้เห็นเลย เรียกว่ายังสดใสเปล่งปลั่งอยู่นั่นแหละ สำหรับน้องอ้อมนั้นไม่ใช่ว่าผมจะไม่สนใจหรอกนะ เพราะน้องอ้อมก็สวยเหมือนกัน แต่อย่างว่าผมรู้จักกับพี่แอมมาก่อนน้องอ้อม และท่าทีของพี่แอมก็ดูจะชอบผมด้วยเหมือนกัน เวลาที่ผมยิ้มให้ พี่แอมก็จะยิ้มตอบเสมอ ไม่มีท่าทีว่าจะเล่นตัวกับผมเลย จนเรื่องราวของผมกับพี่แอมกลับกลายเป็นความรักเหมือนหนุ่มสาวทั่วไป ทางน้องอ้อมก็เข้าใจในเรื่องของผมกับพี่แอมดีครับ แล้วเปิดทางให้ผมอย่างดี ตอนเลิกจากงานผมกับพี่แอมจะไปหามุมสงบนั่งคุยกันเสมอเกือบทุกวันตามประสาคนรัก ผมเคยคิดจะเผด็จศึกพี่แอมตั้งหลายครั้ง แต่โอกาสก็ไม่ให้ผมสักที จนกระทั่งคืนวันหนึ่ง ผมนัดกับพี่แอมเพื่อจะไปดูหนังรอบค่ำด้วยกัน ส่วนน้องอ้อมนั้นนอนพักผ่อนอยู่ที่ห้องคนเดียว ผมกับพี่แอมไปดูหนังกันตามลำพังสองคนเท่านั้น ในคืนนั้นหนังที่ฉายสนุกมากเพราะเป็นหนังเรทอาร์เสียด้วย เป็นหนังญี่ปุ่น ผมกับพี่แอมนั่งใกล้ชิดติดกัน เหมือนประสาคนรักทั่วไป พอถึงตอนที่เป็นฉากเลิฟซีน พระเอกกับนางเอกนอนแก้ผ้าบนเตียงเล่นรัก กันเต็มที่ นางเอกกำลังหมอบโก้งโค้งบนเตียง โดยมีพระเอกตามเข้าประกบทางด้านหลัง แล้วขยับเอวเย่อ ยิกๆ ผมไม่เห็นท่อนเอ็น ของคนแสดงหรอกครับ แต่ภาพแค่นี้ก็ทำให้ผมมีอารมณ์หงี่ ขึ้นมามากเสียแล้ว ผมนั่งตัวเกร็งเชียวหละ ท่อนเอ็น ของผมมันแข็งปั๋งปวดหนึบตุงเป้ากางเกงของผมแทบปริเลย ผมหันมองทางพี่แอมก็นั่งเงียบดูตาไม่กระพริบเลย ผมแกล้งกระซิบถามพี่แอมว่าดูหนังสนุกดีมั้ย พี่แอมตอบว่าไม่สนุกเลยอยากกลับบ้านมากกว่า ผมนั้นตามใจอยู่แล้ว เลยพาพี่แอมกลับบ้านทันทีในตอนนั้นเลย พอกลับมาใกล้จะถึงห้องพักของเรา ผมก็ชวนพี่แอมเข้ามาในห้องของผมก่อน เพราะเห็นว่าน้องอ้อมนั้นปิดไฟหลับไปแล้ว พี่แอมก็ยอมเข้ามาในห้องนอนของผม พอเข้าห้องแล้วผมก็จัดการปิดประตูลงกลอนแน่น พร้อมกับเข้าหาพี่แอมแล้วกระซิบว่า “ดูหนังเมื่อกี้สนุกดีมั้ย…” “หนังอะไรก็ไม่รู้ทะลึ่งเป็นบ้า…” ผมบอกกับพี่แอมว่าผมอยากทำแบบในหนังบ้าง พี่แอมถามว่าจะทำกับใคร ผมก็บอกว่าพี่แอมนี่แหละ พี่แอมยิ้มแล้วบอกว่าจะบ้าเหรอ ไม่เอาด้วยหรอก แต่ผมรู้ว่าพี่แอมนั้นดูหนังโป๊ มาแบบนี้ ต้องเกิดอารมณ์แล้วด้วยเหมือนกัน เพราะลมหายใจของพี่แอมในตอนนี้มันร้อนผ่าวมากเหลือเกิน ผมจึงแกล้งพูดอีกว่า ไม่รู้ล่ะ ผมรักพี่ ผมต้องทำให้พี่แบบในหนังให้ได้ แล้วกระซิบเสียงแผ่วเบาอีกว่า “พี่แอมครับ ผมรู้ว่าพี่แอมก็ต้องการใช่ไหม ผมรักพี่มาก ขอให้ผมเถอะนะ…” พี่แอมไม่ตอบคำอะไรอีกเลย ผมได้โอกาสรีบกอดจูบหอมแก้มพี่แอมฟอดใหญ่ พี่แอมไม่ได้ขัดขืนผมเลย ยอมให้ผมสนุกอย่างว่าง่าย ลมหายใจร้อนผ่าวของพี่แอมสาดลดใส่ผมอย่างจัง เร้าอารมณ์ให้มากยิ่งขึ้น ผมกอดพี่แอมเอาไว้ใน อ้อมแขน พี่แอมพูดเสียงกระเส่าบอกผมว่า “เดชต้องรักพี่จริงๆ นะ…อย่าทิ้งให้พี่เหงา…” “ผมรักพี่ มากครับ…ผมอยากได้พี่ทั้งตัวตั้งนานแล้ว…ผมไม่ทิ้งพี่หรอกครับ…” “เดชทำกับพี่อย่างนี้เดชรู้มั้ยว่า อ้อมน้องสาวพี่ถ้ามารู้เรื่องนี้เขาต้องเสียใจอย่างแน่นอนเลย…” “ทำไมเหรอครับ…” “เดชไม่รู้หรอก ว่าอ้อมเขาหลงรักเดชด้วยนะไม่ใช่พี่คนเดียวหรอก อ้อมเขาแอบรักเดชมาตั้งนานแล้ว แต่นี่เดชมารัก พี่ ไว้ก่อนแล้วค่อยคิดกันทีหลัง…” “ครับพี่…ผมจะรีบทำให้พี่มีความสุขเดี๋ยวนี้แหละครับ…” ผมรีบ ประกบปากกับพี่แอมอีกครั้ง คราวนี้พี่แอมเริ่มกอดจูบกับผมบ้างแล้ว ผมซุกไซ้พี่แอมไปทั้งตัว ตั้งแต่ใบหู ติ่งหู และมาที่ซอกคอ ก้มหน้าต่ำลงมาที่หน้าอกของพี่แอมหอมฟัดอย่างหิวกระหาย จากนั้นเราก็ช่วยกัน ถอดเสื้อผ้าให้กันอย่างรวดเร็ว เมื่อใจเราสองปรารถนาตรงกัน เรื่องอับอายกันนั้นก็ไม่ต้องพูดถึงกัน อีกต่อไป ท่อนควย ผมมันแข็งปั๋งผงาดง้ำส่ายหัวดิกๆ ไปมา พี่แอมเห็นของผมเข้าถึงกับตาโตเลย “เดชจ๋า…ไอ้นั่นมันของเธอหรือของม้ากันเนี่ยะ…ทำไมมันใหญ่ยาวอะไรอย่างนี้…หัวถอก บานเหลือเกิน…” “ของผมสิครับ…พ่อให้มาตั้งแต่เกิดแล้วครับ…” “อย่าทรมานพี่เลย รีบทำให้พี่มีความสุขเร็วๆ เถอะจ้ะ…” ผมตะลึงลานกับสองเต้านม คู่งามของพี่แอมมากเหลือเกิน เพราะงอนงามมากยิ่งกว่าเต้านม ของสาวรุ่นเสียอีก
