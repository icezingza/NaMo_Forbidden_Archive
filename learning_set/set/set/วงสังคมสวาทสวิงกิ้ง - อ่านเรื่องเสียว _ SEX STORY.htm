ไม่น่าเชื่อเลยว่าสิ่งเหล่านี้มันได้เกิดขึ้นในกรุงเทพฯที่กำลังโชติช่วงชัชวาลย์นี่เอง แต่บางท่านก็บอก ว่าไม่ใช่ของแปลกใหม่อะไรเลย มันมีกันมาตั้งนานแล้วเพียงแต่ไม่เปิดเผยกันมากนัก และเมื่อก่อนยัง ไม่กล้าพอที่จะจัดกันอย่างเป็นพิธีรีตองเช่นทุกวันนี้ นั่นก็คือชมรมของผู้ที่ชอบแลกผัวแลกเมียกันหลับนอน ทุกวันนี้กระทำกันอย่างเป็นล่ำเป็นสัน โดยส่วนมากแล้วก็จะเป็นผู้ที่มีการศึกษาสูงทั้งสิ้น หรือไม่ก็สูงพอ ที่จะมองเห็นเรื่องร่วมเพศเป็นสิ่งผ่อนคลายและบำรุงบำเรอบำบัดบางอย่าง และอย่าเพิ่งมองว่าเขาเหล่านี้มีจิตใจที่ต่ำทราม เพราะส่วนมากที่นิยมการสังวาสแบบนี้มักจะเป็นคู่ สมรสที่มีปัญหาเรื่องบนเตียงทั้งสิ้น แต่แทบที่จะปล่อยทิ้งเอาไว้และรอให้มันเป็นต้นตอของการเลิกร้าง หย่ากันไป พวกเขากลับหันหน้าเข้าหากันและช่วยกันหาทางออกกับเรื่องนี้ ปัญหาก็มีอยู่หลายประเภท ด้วยกัน พื้นฐานที่สุดได้แก่คู่ที่เกิดความเบื่อหน่ายจำเจต่อหีเดิมควยเก่าของกันและกัน ถ้ายิ่งฝ่ายใด ฝ่ายหนึ่งเป็นโรคมักมากในเชิงกามาด้วยแล้ว ไม่นานการแอบเล่นชู้ก็มักจะเกิดตามมา ซึ่งผลร้ายมันก็ จะเกิดขึ้นตามมาทีหลัง บางคู่ก็รักกันอย่างแน่นแฟ้นแต่อารมณ์ทางเพศหรือความเงี่ยนมันไม่แน่นด้วย อาการไม่สู้ก็มักจะเกิดขึ้นเป็นจุดเริ่มของกามตายด้าน ส่วนที่มีปัญหาแปลกแหวกแนวไปกว่านี้ ก็ยังมี เช่นว่ามีเมียสวยเกินไปพาไปโชว์ยังไงๆ ก็ไม่จุใจ อยากที่จะให้คนอื่นๆ มารู้เห็นด้วยว่าเมียตัวเอง นั้นงามขนาดไหนเวลาโป๊เปลือยแก้ผ้า หรือไม่ก็อยากที่จะเห็นเมียของตัวเองถูกคนอื่นเย็ดเอา หรือ ผัวไปเย็ดกับผู้หญิงอื่นต่อหน้าต่อตา อย่างนี้ก็มีด้วยเหมือนกัน และเชื่อหรือไม่ว่าการแลกผัวแลกเมียนี้ เคยทำให้ชีวิตครอบครัวที่กำลังแตกแยกกัน กลับยืนยาวได้ต่อไปอีก มามากแล้ว เพราะเรื่องที่ท่าน กำลังจะได้รับรู้นี้เป็นเรื่องจริงทั้งสิ้น ก่อนอื่นมาดูว่าเขารวมกลุ่มกันได้อย่างไร วิธีการสมัครเข้าเป็นสมาชิกกลุ่มกันนั้นเราบอกไม่ได้ ถ้า สนใจจริงๆ ก็เสาะหากันเอาเอง เมื่อพบแล้วเขียนจดหมายพร้อมทั้งส่งรูปของท่านพร้อมคู่ทั้งเล่า ประวัติย่อๆ เพียงการศึกษาและความเป็นอยู่ สำหนับหน้าที่การงานนั้นเขาไม่สนใจ เมื่อทางกลุ่ม สนใจท่านก็จะมีจดหมายตอบมานัดหมายการพบปะ ซึ่งทีแรกๆมักจะเป็นตามร้านอาหาร และผู้ที่มาพบ ท่านมักจะเป็นชาย แต่บางครั้งอาจจะเป็นผู้หญิงก็ได้ เมื่อทำความรู้จักคุ้นเคยกันบ้างแล้วก็ยังจะไม่มี อะไรเกิดขึ้น จนกว่าจะมีจดหมายมานัดเป็นครั้งที่สอง แต่ทุกครั้งที่นัดพบกันท่านจะต้องไปกันทั้งคู่ จน ครั้งที่สามนั่นแหละ ถึงจะมีการนัดแนะให้ไปพบที่บ้านแห่งหนึ่ง เมื่อเข้าไปในบ้านก็จะถูกแยกคู่ออกทันที ผู้ชายไปคุยกับกลุ่มผู้ชาย ผู้หญิงจะเข้ากลุ่มเพศเดียวกัน ทั้งสองจะถูกซักถามด้วยคำถามที่คล้ายๆ กัน ถึงปัญหาและชีวิตประจำวันอันเกี่ยวเนื่องกับเรื่องส่วนตัวทั้งสิ้น การที่ต้องทำอย่างนี้ก็เพราะป้องกัน การสวมรอย โดยไปจ้างอีตัวมาแสดงเป็นภรรยาหรือคู่ขาทรี่อยู่ด้วยกัน ถ้าทั้งสองคนตอบออกมาตรง กันทุกข้อ พวกเขาจึงจะรับเข้าเป็นสมาชิกของกลุ่ม โดยบอกข้อกำหนดบังคับต่างๆให้รู้ ข้อที่สำคัญเห็น จะได้แก่ห้ามถามถึงเรื่องราวส่วนตัวของกันและกัน และห้ามแสดงการหึงหวงกันเด็ดขาด จากนั้น เซ็กซ์หมู่ก็จะค่อยๆเริ่มขึ้น สมาชิกใหม่อาจจะยังเขินๆอยู่ ก็ยังไม่จำเป็นต้องเปลี่ยนสลับคู่ก็ได้ ทุกคน จะอยู่ในอยู่ในชุดเสื้อคลุมเพียงตัวเดียว ถ้าใจยังไม่กล้าที่จะเปลี่ยนคู่ก็ต้องเอากันเองหรือดูคู่อื่นเขา ซึ่งพวกเขาก็จะเอากันแบบไม่เลือกที่ไม่เลือกว่าเป็นใคร จะมีผู้คอยจัดให้ว่าใครควรจะเปลี่ยนสลับคู่ ได้แล้วบ้าง ในบ้านนั้นจะพบผู้หญิงที่มีอายุตั้งแต่ ๑๘ ปีขึ้นไปจนถึง ๓๕ ส่วนผู้ชายอาจจะมีถึงวัย ๔๐กว่า ทุกคนยอม รับว่ามันน่าตื่นเต้นสุดขีดทีเดียว เมื่อได้เห็นเมียตัวเองกำลังเปลือยกายรับดุ้นควยชายอื่นอย่าง เร่าร้อน และยิ่งตื่นเต้นจนร้อนหน้าวาบในบางครั้งซึ่งเกิดมาจากความหึงหวงเมื่อฟังเสียงเมียตนร้อง ครวญครางดังรอดมาจากห้องนอน หรือแอบดูแอบได้ยิน ซึ่งในห้วงเวลานั้นเองที่จะรู้สึกตัวว่าเมียตน นั้นมีค่าควรหวงแหนยิ่งนัก ความหึงของผู้ชายนี่แหละทำให้ความรักและการเอาอกเอาใจกลับคืนมา เหมือนกับตอนได้กันใหม่ๆ บางคนแทบจะคลั่งตายเมื่อเมียต้องไปดูดควยให้ชายอื่นจนน้ำออก หรือไม่ก็ เห็นภาพที่เมียถูกผู้ชายสองคนเย็ดพร้อมกัน โดยคนหนึ่งเย็ดทางรูหีอีกคนเย็ดทางปาก ซึ่งบางคนอดใจ ไม่ไหวถึงกับต้องไปต่อคิวเพื่อจะเย็ดเมียตัวเองทันที ตลอดเวลาหัวหน้าชมรมจะคอยกำกับดูแลไม่ให้คู่ ใดอยู่กันตามลำพังนานเกินไป เพราะอาจจะทำให้เกิดความสัมพันธ์ทางใจขึ้น ซึ่งไม่ใช่จุดมุ่งหมาย ของชมรมแลกคู่ การชุมนุนแลกคู่กันเช่นนี้มักจะจัดกันขึ้นเดือนละครั้ง คราวๆ หนึ่งจะมีคนมาเข้าร่วม ตั้งแต่สิบคนขึ้นไป ผู้ที่มาเข้าร่วมก็จะมีตั้งแต่นักศึกษา, อาจารย์, ทนายความ, ข้าราชการ, นัก ธุรกิจ, แม้แต่พวกดารา-นักร้องก็มี ผู้หญิงแต่ละคนนั้นต่างก็พยายามทำตัวอย่างสุดสวยราวกับจะไป ออกงานสังคม เธอเหล่านั้นพร้อมที่จะตอบสนองความต้องการของชายคนใดก็ได้ที่อยู่ในงานชุมนุนนั้น ทุกเมื่อทุกที่ที่เขาต้องการ ไม่ว่าจะเป็นในห้อง, บนพื้นต่อหน้าคนอื่นๆ, นอกระเบียง, หรือแม้แต่ใน ครัวก็ยังมี คือใครมีจินตนาการบางอย่างก็นัดแนะกันแสดงออกมาเอง จะเป็นหมู่-เดี่ยว-สองต่อหนึ่ง หรืออะไรก็สุดแท้แต่จะนึกกันขึ้นมาได้
