เรื่องเสียวโดนข่มขืน ดิฉันไม่เคยคิดเลยว่าชีวิตจะต้องประสบกับเรื่องเช่นนี้ แม้ว่ามันจะผ่านมาเป็นเวลาหลายปีแล้วแต่ดิฉัน ก็ไม่สามารถลืมได้ เหตุการณ์ครั้งนั้นมีผลกระทบกับชีวิตของดิฉันตลอดมา ดิฉันแต่งงานแล้วเมื่อหลายปี ก่อน สามีและดิฉันต่างก็เป็นพนักงานบริษัทแต่ไม่ได้ทำงานที่เดียวกันชีวิตก็ราบรื่นดี เมื่อแต่งงานกัน ใหม่ๆ ก็ร่วมรักกันบ่อยๆ แต่ผ่านไปสองสามปีก็ห่างไปบ้างเป็นธรรมดาแต่ก็ไม่มีปัญหาอะไรกัน วันหนึ่งเป็นวันหยุดดิฉันและสามีไม่ได้ออกไปไหนเราอยู่บ้านดูทีวีเหมือนอย่างเคยแม้ว่าบ้านเราจะเป็น ทาวน์เฮาส์แต่อยู่กันสองคนก็ได้สบายๆ มีโทรศัพท์เข้ามาที่บ้าน สามีเป็นคนรับสายดิฉันเห็นสามีพูด โทรศัพท์แล้วก็มีสีหน้าเครียดๆ พูดแต่ครับๆ แล้วก็วางสายไปเห็นเขานั่งนิ่งคิดอะไรเงียบๆ “ใคร โทรมาหรือคะ” “ไม่ ไม่มีอะไร เอ่อ เดี๋ยวพี่จะออกไปข้างนอกหน่อย” สามีก้มหน้าตอบ ดิฉันได้ยิน สามีตอบอย่างนั้นก็แปลกใจเหมือนกัน แต่ดิฉันก็ไม่ได้ว่าอะไรสักพักหนึ่งเขาก็ไปแต่งตัวแล้วก็ผลุนผลัน ออกไปข้างนอก ดิฉันเลยอยู่บ้านคนเดียว ประมาณครึ่งชั่วโมงก็มีคนมากดกริ่ง ดิฉันชะโงกหน้าดูก็เห็นผู้ชายยืนอยู่ที่หน้าบ้าน “มาหาใครคะ” ดิฉันเดินออกไปถามที่ประตูรั้ว “เปิดประตูก่อนเถอะคุณ” เขาตอบ ดิฉันรู้สึกฉุนกึกที่เขามาออกคำสั่ง ชายคนนี้สวมแว่นกันแดดหน้าตาดูคมเข้ม แต่ก็ไม่น่าไว้ใจเลย “เอ่อ คุณมาหาใครล่ะ” “สุพจน์สามีคุณ น่ะกำลังไม่ปลอดภัย เปิดประตูเถอะ” เขาเน้นเสียง ได้ยินอย่างนี้ดิฉันตกใจและไม่ได้คิดอะไรอื่น รีบเดินไปเปิดประตูรั้วโดยไม่ได้คิดเลยว่าภัยร้ายกำลังจะเกิดขึ้นกับตัวเอง ดิฉันเดินนำหน้าเขาเข้า มาในบ้าน เขาปิดประตูบ้านทันทีดิฉันรู้สึกสังหรณ์ใจว่าจะเกิดอะไรไม่ดีขึ้นกับตัวเองแต่ก็แข็งใจถามไป ว่าสามีดิฉันเป็นอะไรเกิดอะไรขึ้น “ยังไม่เป็นอะไรหรอก แต่คุณรู้หรือเปล่าว่าเขาติดหนี้พนันบอล” ดิฉันตกใจและงงไปหมด สามีไปเล่น พนันบอลตั้งแต่เมื่อไหร่กันไม่รู้เรื่องเลย “จริงหรือ เขา เขาเป็นหนี้เท่าไหร่คะ” ดิฉันพยายาม บังคับเสียงไม่ให้สั่น “ห้าแสน” เขาตอบสั้นๆ “ว่าไงนะ…” ดิฉันรู้สึกตกใจมาก รู้สึกว่าตัวเองนั่งลง กับโซฟาเมื่อไหร่ไม่รู้“คุณจะไม่เชื่อก็ตามใจ เดี๋ยวเขากลับมาแล้วถามเขาดูเอาเอง แต่ตอนนี้ผม สนใจคุณ” “คุณจะทำอะไร ..” ดิฉันใจไม่ดี แทนคำตอบเขามองดิฉันยิ้มๆ ตอนนี้เขาถอดแว่นออก แล้ว นัยน์ตาเขาดูจริงจังเขาจ้องมองจนดิฉันรู้สึกเย็นเยียบและเริ่มรู้ตัวว่ากำลังจะเกิดอะไรขึ้น เขา ถอดเสื้อแจ๊กเก็ตออกเหมือนอย่างกับว่าคุ้นเคยกับดิฉันมานาน เขาเป็นคนรูปร่างแข็งแกร่งเขาเดิน เข้ามาหาดิฉัน ดิฉันผงะถอย ตั้งท่าจะร้อง “อย่านะ จะทำอะไร” “คุณจะขัดขืนผมก็ตามใจ แต่พูดกับ สามีคุณก่อนสิ” ชายแปลกหน้ากดโทรศัพท์แล้วยื่นให้ดิฉันรับโทรศัพท์ไปฟัง “แพรว แพรว เขาจะฆ่าพี่ .. แพรว ..” ดิฉันได้ยินเสียงสามีละล่ำละลักแล้วโทรศัพท์ก็ตัดไปโดยที่ ดิฉันไม่ทันจะได้อ้าปากพูดอะไรดิฉันตกใจกลัวไปหมด น้ำตาเริ่มไหลทำอะไรไม่ถูก ชายคนนั้นไม่พูด อะไร เขารับโทรศัพท์ไปแล้วเดินเข้ามาจับไหล่ดิฉัน “คุณสวยดีนะ หุ่นดีจริงๆ สูงๆ อย่างนี้ผมชอบ” “อย่านะ อย่าทำอะไรหนูเลย ขอร้องเถอะ” ดิฉันยกมือไหว้เขาวิงวอนน้ำตาไหล เขาเชยคางดิฉัน ขึ้นแล้วก็เช็ดน้ำตาให้อย่างนุ่มนวล “ถ้าคุณขัดขืนผมก็ไม่ทำอะไรคุณหรอกแต่เมื่อผมกลับไปสามีคุณก็ตาย ผมช่วยอะไรไม่ได้นี่เป็นระบบ คุณต้องเข้าใจสามีคุณน่ะผลัดหนี้มาหลายครั้งแล้ว คราวนี้ยอมไม่ได้” เขาพูดพร้อมกับเริ่มแกะกระดุมเสื้อดิฉัน “อย่า..” ดิฉันพยายามจะจับมือเขาไว้ ชายหน้าเข้มหยุดมือ ทันทีและมองดิฉันเขม็ง ไม่พูดอะไรดิฉันสะอื้นออกมาเพราะกลัวว่าถ้าขัดขืนเขาแล้วจะเกิดอะไรขึ้นกับ สามี เขาประคองไหล่ดิฉันไปที่ห้องนอน ดิฉันเดินตามเขาไปอย่างตัวสั่นงันงกเหมือนคนไม่มีสติเขาให้ ดิฉันนอนลงน้ำตายังคงไหลไม่หยุด ดิฉันรู้สึกกลัวมาก “ฮือ พี่ อย่า .. อย่าทำหนูเลย ..” “ไม่ต้องกลัว ผมไม่ทำคุณเจ็บหรอกน่า” เขาพูดปลอบใจพร้อมกับปลดกระดุมเสื้อดิฉันดิฉันพยายามขัดขืน แต่เขาก็ถอดเสื้อดิฉันออกอย่าง ง่ายดายดิฉันอายมากรีบเอามือจะกอดอกแต่เขากั้นแขนดิฉันไว้เบาๆ โน้มตัวลงหอมแก้มดิฉัน มือเขา เริ่มลูบไล้ต้นแขนเขาหอมแก้มดิฉันหนักๆ ทั้งสองข้างแล้วก็ประกบจูบทันที ดิฉันพยายามเบี่ยงหน้าหลบ ไปมาเขาเอามือมาแตะที่แก้มลูบเบาๆ ดิฉันกลัวว่าเขาจะทำร้ายเลยได้แต่ตะแคงหน้า ดิฉันหลับตาไม่ กล้ามองใจเต้นแรง ในที่สุดเขาก็จูบปากดิฉัน เขาบดเน้นจูบไปทั่วริมฝีปากของดิฉัน มีเสียงจูบจุ๊บ ๆและพยายามจะเผยอปากดิฉันออกแต่ดิฉันไม่ยอมเปิดปากขึ้น ตอนนี้เขากอดดิฉันไว้ดิฉันพยายามเอา แขนกั้นหน้าอกตัวเองแต่เขาก็คว้าแขนดิฉันลงข้างกายหน้าอกของเขาบดเบียดกับเนื้อนมของดิฉัน เขา หอมแก้มและไซร้ไปที่ข้างหู ลมหายใจของเขารดอยู่ข้างซอกหูดิฉันรู้สึกขนลุกเกรียว เขาจูบไซร้ไปทั่วใบหู ดิฉันหันหน้าตะแคงเพื่อนอนทับใบหูของตนให้พ้นจากการรุกเร้าทำให้แก้มของ ดิฉันไปสัมผัสกับข้างแก้มของเขา เขาจูบปากดิฉันทันที ดิฉันไม่ทันระวังจึงถูกประกบจูบ ลิ้นของเขาพุง วาบเข้ามากระดิกสะกิดลิ้นของดิฉัน รู้สึกเสียววูบจนต้องรีบเบือนหน้าหนี พอหลบพ้นการจูบเขาก็จูบลง ที่ใบหูอย่างหนักพร้อมทั้งฉกลิ้นชอนไชเข้ามาในรูหู เขาขบเม้มใบหูของดิฉันแล้วอมดูดติ่งหู ทันใดนั้น เขาก็เป่าลมพรูเข้ามาเบาๆ ดิฉันรู้สึกจั๊กกะจี้ เขาจู่โจมลิ้นลงมาในช่องหูของดิฉันอีกครั้งและอย่างไม่ ทันตั้งตัวเขาก็จูบไซร้ที่ซอกคอ “อือ .. ตัวคุณหอมจริงๆ ..” เสียงเขางึมงำที่ซอกคอ เขา ไซร้หนักเบาสลับกับงับใบหูของดิฉันถึงตอนนี้ดิฉันรู้สึกสยิวแสยงไปหมดแล้ว กลัวจนหยุดร้องไห้ไปเลย แต่ดิฉันก็ยังไม่กล้าลืมตา เขาคลุกหน้ากับซอกคอดิฉัน ไซร้ที่ใต้คางจนดิฉันต้องเงยหน้าขึ้นแล้วเขาก็ เปลี่ยนไปไซร้ซอกคออีกข้าง เขาปล่อยการกอดรัดมาจับต้นแขนดิฉันไว้ และพรมจูบต่ำลงมาที่หน้าอก ดิฉันกำลังจะยกแขนขึ้นปิดกั้นแต่ก็ไม่ทัน เขาคลุกหน้าลงไปที่เต้านม “อืมม์ .. ใหญ่ดีจริง ทั้งใหญ่ ทั้งขาว.. เดี๋ยวจะดูดให้หลุดติดปากออกมาเลย ..” ดิฉันหน้าชาวาบเมื่อได้ยินคำพูดของเขา แต่ยังไม่ทันทำอะไรเขาก็งับที่เต้านมทั้งๆ ที่ยังมียกทรงปิดกั้น อยู่ แต่ดิฉันก็รู้สึกวูบวาบด้วยความเสียว ทั้งกลัวทั้งตื่นเต้นระคนกับเสียวมันเป็นความรู้สึกที่สับสนไป หมด แต่ดิฉันก็ยังมีสติพอที่จะหาทางขัดขืน.. เขาพรมจูบลงไปบนก้อนเนินอกที่อัดปลิ้นล้นยกทรงเพราะ ดิฉันเป็นคนหน้าอกใหญ่ สามีชมดิฉันบ่อยๆ ว่าดิฉันนมสวย ไม่เคยมีใครทำกับดิฉันอย่างนี้นอกจากสามี และเขาคนนี้เป็นใครเขากำลังจะข่มขืน ดิฉัน เขาปล่อยมือจากการจับยึดแขนดิฉันแล้วโอบกอด เมื่อแขนดิฉันเป็นอิสระดิฉันจึงพยายามที่จะผลักใบหน้าเขาออกแต่แล้วดิฉันก็ต้องใจหายวาบเพราะเขาปลดตะขอยกทรงด้านหลังอย่างรวดเร็วและยังไม่ทันที่ดิฉันจะคิดแก้ไขอะไรได้ เขาก็เลิกยกทรงดิฉันออก! สองเต้างามของดิฉันก็ปรากฏแก่ตาเขาเต็มหน้า ดิฉันตกตะลึงเห็นดวงตาวาววามเป็นประกายของเขาที่จ้องหน้าอกดิฉันเขม็ง ..ก่อนที่จะได้ทันตั้งตัวเขาก็รูดสายยกทรงออกมาทางแขนดิฉัน ดิฉันยกแขนขึ้นกอดอกปิดบังส่วนสงวน เขาจูบลงบนท่อนแขนและกดหน้าลงที่เนินหน้าอก เขาปลดแขนดิฉันลงด้านข้างอย่างง่ายๆ เหมือนไม่ต้องออกแรง “โอ .. นมสวยจริงๆ .. อื้อฮือม .. จุ๊จุ๊ .. หัวนมสวยมาก.. ” เขาวิจารณ์ซึ่งหน้าดิฉันรู้สึกอายมาก เห็นสายตาของเขาที่มอง หน้าอกดิฉันแล้วรู้สึกใจสะท้าน ทันทีนั้นเขาก็อ้าปากงับที่หัวนมของดิฉัน ลิ้นเขาฉกปราดดุนดันสลับกับ การดูดเลีย เขาอ้าปากกว้างๆ แล้วดูดนมดิฉันเข้าไปอย่างแรงจนดิฉันต้องแอ่นอกตามแรงดูดนั้น เมื่อ ก้อนเนื้อดิฉันอยู่ในปากเขาดิฉันรู้สึกถึงลิ้นที่แข็งๆ ปาดหัวนมดิฉันไปมา เขาคายนมดิฉันออกมาแล้วลาก ลิ้นเลียหัวนมดิฉันจนเปียกชุ่มเขาจูบเคล้าแลบเลียลิ้นไปทั่วทั้งเต้า แล้วก็หันหน้าไปฉกหัวนมดิฉันอีกข้าง อย่างรวดเร็ว “อย่า ไม่ .. อย่าค่ะ ..” ดิฉันพูดวิงวอนเบาจนแทบกระซิบ เขาไม่ฟังเสียงยังคง คลุกเคล้าเต้านมดิฉันอย่างเมามันส์ ลิ้นของเขาร้ายเหลือเกินทั้งฉกทั้งดุน ปากก็ดูดสลับกับเลีย เขา คลุกหน้าลงกับนมดิฉันที่เริ่มครัดเคร่งขึ้นมาด้วยความเสียวซ่าน เขาบดใบหน้าของเขากับหน้าอกดิฉันจนเนื้อนมแทบจะแหลกเหลว เขาดูดหัวนมดิฉัน เลียหัวนมดิฉันอย่างไม่ปรานีสลับซ้ายสลับขวาจนดิฉันเริ่มหอบหายใจแรงขึ้น“ .. อา .. คุณ .. อย่าเลย พอเถอะค่ะ .. อูย .. อือ .. ”
