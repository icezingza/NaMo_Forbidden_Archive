เรียนประจำกินนอนตั้งแต่ยังไม่สิบขวบเพราะแม่ผมดูว่าละหองละแหงกับย่าผมคงเป็นธรรมดาแม่ผัวกับ ลูกสะใภ้ผมคิดอย่างนั้น พอผมโตจึงรู้ความว่าครอบครัวแม่ผมยากจนแบบหาเช้ากินค่ำพ่อผมไปเจอแล้ว ชอบแม่เลยเก็บเอามาเลี้ยงเป็นเมียเพราะแม่ผมจัดว่าสวยๆ แบบผมยังแอบชอบ แน่นอนย่าไม่พอใจ เพราะพ่อเป็นลูกชายคนเดียวและฐานะทางบ้านพ่อดีมากๆ จัดว่าร่ำรวยมีกิจการมากมายปัญหาจึงเกิดขึ้น แต่สำหรับผมปู่ย่ารักหลงผมมากไม่มีปัญหาเพราะผมเป็นหลายชายคนเดียวที่จะสืบสกุล ที่ผมรู้ผมตรวจดี เอนเอแล้วผมเป็นสายเลือดของตระกูลนี้ปู่ย่าเอาใจผมมาตั้งแต่เล็กพยายามแยกผมออกจากแม่จึงให้ ผมไปอยู่ รร.ประจำ ป้าจะไปรับผมมาอยู่ด้วยในวันหยุดไม่มีขาด ป้าเป็นสาวโสดไม่มีสามีจึงรักเลี้ยง ผมอย่างลูก พ่อผมตัดสินใจย้ายออกซื้อบ้านใหม่แยกแม่ออกจากย่าเพื่อตัดปัญหาของแม่กับย่า แต่บ้านพ่อ ก็อยู่ในหมู่บ้านเดียวกับปู่ย่าแค่คนละซอยผมกลับมาก็อยู่บ้านกับย่าผมอยู่มาตั้งแต่เกิดแล้ว ผมแวะไปอยู่ กับแม่บ้างก็ตอนกลางวันตกเย็นมานอนบ้านปู่ พ่อผมจัดว่าเป็นคนเจ้าชู้ตามแบบคนมีสตางค์ที่มีปัญหาบางอย่างแต่พ่อรักผมมากจะพาผมไปเที่ยวด้วยทุก ครั้งที่มีโอกาสย่าไม่ค่อยชอบนักบ่นว่ากลัวผมจะมีนิสัยเหมือนพ่อส่วนปู่บอกผมว่าใช้ชีวิตให้คุ้มดูย่าไม่ค่อย พอใจปู่นักที่ให้ท้ายพ่อกับผม ผมอยู่ รร.ประจำย่าหวังให้ผมเป็นคนอ่อนน้อมมีวินัยแต่มันตรงข้ามผมกลับ เป็นคนกร้านชอบสนุกเฮอาทำให้ป้าที่เลี้ยงผมแทนแม่พูดบ่อยๆ ว่าผมเหมือนพ่อทุกกระเบียดนิ้วรอแค่ว่า โตแล้วจะเจ้าชู้แบบพ่อหรือไม่เท่านั้น ผมเข้าสิบสี่สิบห้าผมเริ่มสนใจเพศตรงข้าม รร.ประจำมีแต่เด็กผู้ชาย ผมกลับบ้านผมจึงสนใจมองญาติ สาวๆ ลูกอาๆ ที่อยู่ที่บ้านมันทำให้ชีวิตผมสดชื่นขึ้นมาก ผมอายุเข้าสิบหกพ่อเอาผมออกจาก รร .ประจำแต่ย่าไม่ให้ผมไปอยู่บ้านพ่อกับแม่ผมก็ไม่คิดอะไรไปๆ มาๆ แค่เดินพอได้เหงื่อผมโตแล้วย่าจะ ห้ามอะไรผมนักก็ไม่ได้บางวันผมนอนค้างบ้านพ่อเพราะดูเป็นอิสระแต่ไม่ค่อยเจอแม่ๆ ถ้าเจอก็ไม่ค่อย คุยอะไรกันมากสิ่งที่ย่าทำกับผมดูได้ผลคือดึงผมออกห่างจากแม่และญาติของแม่จนผมเกือบลืมไปว่ามีแม่ ผู้หญิงที่ผมรู้ว่าเป็นแม่กลายเป็นแค่คนสนิทในความรู้สึกผมป้าเลี้ยงผมเหมือนลูก ผมดูว่าป้าเป็นแม่มากกว่า แม่จริงๆ ผมก็ไม่ได้สนใจอะไรผมเหมือนไม่ตั้งใจจะมีผมแต่มีเพื่อผูกมัดพ่อ ย่าบอกแม่มาปอกลอกพ่อทั้ง พวกญาติๆ ก็มาเกาะกินผมดูว่าก็น่าจะจริงญาติทางแม่ทุกคนพ่อต้องช่วยเหลือตลอดแม่ไม่มีอาชีพอะไร พ่อเปิดร้านสะดวกซื้อให้แม่ดูแลเก็บรายได้ก็ขาดทุนมาตลอดเพราะญาติทางแม่มายุ่งเรื่องการเงินแต่ก็ ยังพออยู่ได้เพราะพ่อหนุนดังนั้นไม่ว่าพ่อจะเจ้าชู้ยังไงพูดอะไรหรือสั่งให้แม่ทำอะไรแม่จะไม่มีปาก เสียงหรือปฏิเสธ ผมเห็นมีผู้หญิงมาอยู่บ้านพ่ออีกคนได้ปีกว่าดูสวยดีผมมารู้ว่าเป็นน้องสาวแม่คงมา ช่วยงานที่ร้านขายของผมเข้าสิบเจ็ดพ่อรู้ดีว่าผมกำลังอยู่ในวัยตกมันสิ่งที่เกิดขึ้นกับผมคือพ่อพาผมไปขึ้น ครูแน่นอน สาวพวกนั้นอายุแก่กว่าผมแต่พ่อจ่ายไม่อั้นเพื่อให้ผมได้ระบายออกทั้งจะได้รู้จักเรื่องเพศ ของจริงไม่แค่ดูจากหนังโป้ แน่นอนผมยังรุ่นไม่เคยก็ตื่นเต้นเป็นธรรมดาแต่ครูผมเป็นมืออาชีพเข้าใจผมดีเธอทำทุกอย่างสุดฝีมือผม ประทับใจเธอมากเมื่อมีครั้งแรกก็มีครั้งที่สองและสามพ่อจะพาผมไปเที่ยวแบบนี้ด้วยตัวเอง ย่ารู้ก็ ตำหนิพ่ออย่างไม่พอใจว่า “ถ้าหลานฉันติดโรคร้ายใครจะรับผิดชอบทุกคนจะเสียใจ” พ่อเป็นคนขวาง ๆ กับย่าแต่ก็ไม่พูดอะไรส่วนปู่รู้ดีว่าผมไม่ใช่เด็กอย่างวันก่อนปู่บอกแค่ว่าให้ป้องกันอย่าลืมตัวส่วนป้าที่ เลี้ยงผมมาบ่นๆ ว่าปู่ชอบให้ท้ายพ่อกับผมวันนั้นพ่อบอกผม “ย่าน่าลำคานแบบนี้หละ” ผมบอก “ย่าหัว โบราณแต่ยังไงก็แม่พ่อเป็นย่าผม” พ่อพยักหน้าบอก “อย่าไปสนใจย่านักเลย พลโตมีประสบการณ์แล้ว พ่อว่าครั้งต่อไปน่าจะเปลี่ยนคนบ้างอย่าจำเจชอบคนไหนแบบไหนก็เลือกเอา” ผมสนิทกับพ่อมากเลยบอกไปแบบตรงๆ “พี่คนนี้ที่เอามาสามครั้งก็ดีแต่จริงๆ ผมชอบแบบแม่” ทำเอา พ่อผงะอมยิ้มแล้วขำถามว่า “จะเอาอย่างนั้นเหรอ” ผมบอก “แม่สวยดีผมแอบชอบ” พ่อหัวเราะนิ่ง คิดอยู่ครู่แล้วถาม “ถ้าได้จะเอาไม?” ผมมองพ่ออย่างงงๆ พูดไปแบบติดตลก “จะได้ไงเมียพ่อนะ” พ่อบอก “พ่อให้พลๆ จะกล้าไมหละ” ผมแสยะยิ้ม “กล้ามันกล้าไม่มีปัญหา แต่เมียพ่อสิจะยอมกับผม เหรอ” พ่อพูดอย่างมั่นใจ “ชีวิตมันกับญาติทางบ้านมันทุกคนยังต้องพี่งพ่ออีกมากสั่งให้มันโดดน้ำมันยัง โดดเลยเชื่อได้เรื่องแค่นี้ไม่ยอมก็ให้มันรู้กัน” ผมว่า “จะดีเหรอยังไงก็แม่ผม” พ่อมองผม “คิดอะไร มากอยากจะเอาไมหละดีด้วยสะอาดปลอดโรคไม่ต้องใส่ถุงยาง” ผมยิ้มรับพ่อหัวเราะตบไหล่ผม “ต้องอย่างนี้สิ รอนิดไม่นานจะจัดการใจแต่อย่าให้ใครรู้มันไม่ดีนัก” ผมคิดพ่อคงพูดเล่นผมรับปากไปอย่างนั้น สองวันต่อมาพ่อบอกให้ผมไปนอนที่บ้านพ่อผมก็ไปทั้งที่ย่าไม่ ค่อยชอบ ผมเห็นแม่หลบๆ หน้าผมก็ดูปกติแม่ไม่ค่อยคุยกับผมเท่าไรนักแต่ที่ดูแปลกคือน้าแป้นน้องสาวแม่ ดูมองผมด้วยสายตาแปลกๆ ผมถามพ่อ “มีอะไรกับผมเหรอถึงอยากให้ผมมานอนที่นี่ ย่าไม่ค่อยพอใจก็ เรื่องสองวันก่อน” พ่อยิ้มๆ ว่า “บอกแล้วอย่าสนใจย่านักที่ชวนมาที่นี่ก็เพื่อจะให้พลเปลี่ยนคู่นอน” ผม ถาม “เราจะไปเที่ยวเหรอผมไม่ได้เตรียมตัวมา” พ่อบอก “ไม่ต้องเตรียมตัวอะไรแค่เตรียมใจก็พอ ” ผมงงๆ ถาม “มันยังไงกัน” พ่อขำว่า “คนที่พลบอกอยากนอนด้วยอยู่ที่นี่จะต้องไปไหน” ผมมองซ้ายขาวไม่เห็นมีใครเลยถาม “ใครกันไม่เห็นมีเลย” พ่อบอก “ก็เมียพ่อไง” ผมอึ้งผงะนึกขึ้น ได้เราคุยกันเมื่อสองวันก่อนผมบอก “นึกว่าพ่อพูดเล่น” พ่อพูดขำๆ “พ่อไม่พูดเล่นพลต้องการอะไรพ่อ ให้ทุกอย่างเท่าที่หาได้” ผมนิ่งครู่ถามกลับ “แล้วเมียพ่อจะยอมเหรอ” พ่อยิ้มบอก “ยอมไม่ยอมก็ ตกลงกันแล้วน้องเมียพ่อยังเอาเลย” ผมตกใจอ้าปากค้างขำออกมา “อะไรพ่อฟันหมดเลยเหรอ” พ่อ ว่า “จะเอาไมหละ พ่อยกให้หมดทั้งสองคน” พ่อหัวเราะ ผมคิดถึงว่าน้าแป้นมองผมแปลกๆ แม่ก็หลบ หน้าผมๆ พูดไม่ออกบอกสั้นๆ “ก็ดี” พ่อบอก “ถ้าได้คนพี่ก่อนแล้วคนน้องจะตามมา” ผมพูดอย่างไม่ แน่ใจสั้นๆว่า “ถ้าได้” พ่อบอก “ต้องได้สิจะมีอะไรไปรอที่ห้องเดี๋ยวจะพาไปส่ง” พ่อหัวเราะ ผมแกล้งถาม “เอาใครไปส่ง” พ่อยิ้ม “ก็ต้องเมียพ่อคนพี่ก่อนสิ” ผมอ้าปากค้างแกล้งพูด “ถ้าได้จริง พ่อก็นอนเหงาสิคืนนี้” พ่อหัวเราะ “ต้องได้สิยังไงพ่อก็ไม่เหงาจะแวะไปคุยกับอีแป้นหน่อย”ผมยิ้มขำ ไปรอที่ห้องด้วยใจระทึกเหมือนวันแรกที่ขึ้นครู รอนานพอควรจนพ่อเปิดประห้องผมพ่อบอก “เอา เจ้าสาว..เออ.. แต่ไม่ค่อยสาวเท่าไรมาส่ง” ผมนั่งอึ้งพ่อฉุดดึงมือแม่พาเข้าห้องผมพ่อพูดกับแม่ “ปอย (ชื่อแม่ผม) แกรู้ใช้ไม่แกจะต้องทำอะไรบ้าง” แม่พยักหน้าก้ม พ่อย้ำทิ้งท้าย “แกรู้ใช่ไมถ้าแก ทำให้พลไม่พอใจแกจะได้อะไร ”แม่ก้มหน้ารับ พ่อดันให้แม่เข้าหาผมพ่อพูดดุแม่ “ยืนทื่ออยู่ได้” บอก ผม “พลมีปัญหาอะไรบอกพ่อ ไม่ต้องเกรงใจ” ผมพยักหน้ารับแล้วพ่อปิดประตูออกไป ผมใจสั่นแต่ทำใจกล้าเรียกแม่ที่ยืนอยู่ “แม่เข้ามาสิ” แม่มายืนใกล้ผมแล้วเริ่มพูด “ยังเรียกแม่อีก เหรอ ทำไมต้องทำแบบนี้” ผมบอก “ที่เรียกแม่เพราะติดปากที่อยากเพราะแม่สวยแล้วพ่อยกให้” ผม คว้าข้อมือแม่ๆ บิดแขนแต่ไม่สะบัดผมบอก “นั่งลงสิ” แม่นั่งที่เตียงข้างผมหันหน้ามองผมอย่างใจผม อย่างไม่พอใจ ผมบอกย้ำ “แม่แค่คำติดปากผมว่าป้าน่าเป็นแม่ผมมากกว่า” แม่ก้มหน้าผมจู่โจมขยับตัว เข้าหาแขนโอบเอวจะว่าไปเป็นครั้งแรกที่ผมได้สัมผัสตัวแม่ผมยื่นมืออีกข้างจะจับอกแม่ๆ สะดุ้งตกใจ ห่อไหล่ขยับตัวหนียกมือกันมือพูดเสียงกร้าว “อย่านะจะทำไรยังไงฉันก็เป็นแม่เธอ” ผมถามกลับ “แม่ เหรอถามจริงๆ เคยเลี้ยงเคยอุ้มผมหรือเปล่า” แม่ผงะอึกอักขยับตัวก้มหน้านิ่งผมพูดอีกอย่างมั่นใจ “พ่อยกแม่ให้ผมคงเพื่อให้ผมมีความสัมพันธ์ลึกซึ้งกับแม่ๆ คงเข้าใจถ้าปฏิเสธผมว่าแม่กับทางญาติมี ปัญหาแน่” แม่นั่งนิ่งก้มหน้าเหมือนพูดไม่ออกสองมือประสานกำแน่นผมขยับตัวเข้าชิดเอาแขนโอบกอด ไหล่แม่ทีนี้แม่นิ่งไม่ขยับหนีแต่ก้มเอียงหน้าไปอีกทางไม่มองผมๆ เอามืออีกข้างจับต้นแขนแม่แล้วขยับไป
