และไม่อยากมีพันธะผูกพันกับใคร ทางออกของผมที่ดีที่สุดก็คือ “การเที่ยวผู้หญิงตามอาบอบนวด” ซึ่งแน่นอนหมอนวดที่ผมมักเรียกมาใช้บริการจะต้องมีอายุอยู่ในระดับ 40-50 ปี ซึ่งก็หาค่อนข้างยาก สเปคของผมก็คือต้องผิวขาวอวบและนมใหญ่ ข้อสำคัญคือต้องใจดีไม่ขี้หงุดหงิด แต่ส่วนใหญ่ที่ผมขึ้นด้วยนั้น มักจะผิดสเปคไปไม่อย่างใดก็อย่างหนึ่ง เช่นบางคนนมใหญ่ผิวขาวแต่บริการแย่และชอบเร่งชั่วโมง บางคนใจดีเอาใจเก่งแต่ผิวคล้ำนมเล็ก อะไรอย่างงั้น มันจึงทำให้ผมไม่เป็นขาประจำของใครคนใดคนหนึ่ง จนกระทั่งผมได้รู้จักกับเพื่อนทาง อินเตอร์เน็ตคนหนึ่ง และเรามีความชอบเหมือนกันคือ “เย็ดคนแก่” เขาได้แนะนำหมอนวดแก่ให้ผม คนหนึ่ง หล่อนอายุ 48 อวบ ขาว นมใหญ่ ทำอยู่สถานบริการแห่งหนึ่ง ผมจึงไม่รอช้า รีบบึ่งไปยัง สถานบริการแห่งนั้นทันที และหมอนวดที่ผมได้เห็นนั้นก็ เป็นไปตามที่เพื่อนผู้นั้นได้กล่าวไว้ทุกประการ เธอชื่อ “พี่นิ่ม” ทำงานเป็นหมอนวดตั้งแต่ยังสาวเอ๊าะๆ และก็ยังยึดอาชีพนี้อย่างเหนียวแน่นจนอายุ ร่วงโรยถึงวัยเกือบ 50 พี่นิ่มถูกใจผมมากครับ
