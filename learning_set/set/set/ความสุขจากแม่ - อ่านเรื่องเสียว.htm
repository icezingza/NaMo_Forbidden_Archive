แต่ผมไม่สนหรอกแม่รักผมซะอย่าง! อาชายเริ่มขยับเอวเร็วขึ้น เร่งจังหวะจนแม่ผมน้ำลายหกไหลยืดออกมา อาบพวงนมทั้งสองข้างของแม่จนเปียกโชกเป็นมันปลาบ ปลายยอดเม็ดหัวนมของแม่ตอนนี้มันแข็งเด่สีชมพูเข้มๆดูน่ารัก ผมเอื้อมมือไปจับที่หัวนมแม่ บี้มันเล่นอย่างสนุกมือ แม่ใช้มือข้างหนึ่งจับควยผมแล้วกระถอกอย่างแรงจนผมเสียวจนลืมตัวบี้หัวนมแม่ แรงๆ แม่หลับตาปี๋เหมือนเจ็บแต่ยังไม่ยอมถอนปากออกจากควยของอาชาย ผมได้ใจยิ่งบี้หนักขึ้นบางครั้งก็ดึงหัวนมแม่ให้ยืดยาวออกมาจนแม่ครางซู๊ดใน ลำคอ พ่อผมลุกมาจากโต๊ะพร้อมกับกล้องถ่ายวีดีโอ พ่อจับจ้องที่เราทุกท่วงท่า บางครั้งพ่อก็นอนลงไปใต้หว่างขาของผมเพื่อที่จะถ่ายภาพแม่กำลังอมควยจากมุม ล่าง แม่ยังคงดูดสลับกันไปมาระหว่างควยผมกับควยอาชาย สักพักพ่อคงทนไม่ไหวก็เลยเอาควยมาจ่อปากแม่อีกอัน แม่ก็รับมันเข้าไว้ในอุ้งปากแต่โดยดีทั้งสามควย ผมผละจากปากของแม่มาซุกหน้าลงกับหว่างหี ตอนนี้มันมีน้ำเยิ้มฉ่ำออกมามากมายผมเลียกินอย่างอร่อยลิ้น อาชายก็ผลักให้แม่นอนหงายลงกับพื้น แล้วอาก็คุกเข่าเอาควยจ่อปากให้แม่ดูดต่อ ส่วนพ่อเอากล้องวีดีโอวางบนขาตั้งเสร็จก็ลงมาช่วยผมเลียหีให้แม่ พ่อเลียหีแม่ที่เปรอะน้ำลายของผมอย่างไม่รังเกียจลิ้นของเรายังชนกันอยู่ บ่อยๆ บางทีพ่อก็เอาลิ้นเข้ามาคว้านในปากผมผมรับลิ้นพ่อเข้ามาจูบอย่างเต็มใจ เราช่วยกันเลียหีแม่จนแม่กระตุก น้ำแม่แตกออกมาเราแย่งกันกินอย่างกระหาย ผมเงยหน้ามองที่อาชายซึ่งตอนนี้กำลังกระเด้าเย็ดปากแม่คนสวยของผมจนน้ำแตก กระเซ็นออกมาเลอะเต็มหน้าแม่ แล้วแม่ก็นอนหัวเราะร่วนอย่างมีความสุข ท่ามกลางความเหนื่อยหอบของอาชาย “อ้าหหห…แม่กับอาเสร็จแล้วสองพ่อลูกนี่ล่ะเป็นไงมั่ง” “ก็อร่อยน่ะซิครับ..น้ำหีแม่หวานจังผมกับพ่อแย่งกันกินอยู่นี่ไงครับ” พ่อลุกขึ้นยืนกำควยตัวเองทำท่าเหมือนจะชักว่าว อาชายรีบลุกขึ้นมานั่งอมควยของพ่อเข้าปากแล้วดูดรูดมันจนน้ำพ่อพุ่งใส่ปากอา ชาย อาชายอมมันไว้แล้วก้มลงมาจูบปากกับแม่ อาชายป้อนน้ำเงี่ยนของพ่อให้แม่กินแบบปากต่อปาก โอ้โหหหห ผมไม่เคยได้รับรู้เรื่องอย่างนี้มาก่อนเลย! พิศดารพันลึกที่สุด แม่กับอาชายจูบปากกันเนิ่นนาน ผมมองภาพนั้นด้วยความรัญจวญใจ ทั้งคู่ต้องถอนปากออกจากันหลังจากที่ผมเอาควยเข้าไปแทรกกลางระหว่างปากของ ทั้งคู่ อาชายหันมาอมควยผมรูดมันสองสามทีแล้วแม่ก็มาแย่งมันเอามาดูดแทน แม่ผลักผมนอนลง เลียควยให้ผมจนถึงกระโปก ลิ้นของแม่แหย่ยาวคว้านมาถึงรูตูดของผมและวนลิ้นเลียมันอยู่อย่างนั้น พ่อเอากล้องมาซูมภาพผมกับแม่อย่างใกล้ชิด แล้วแม่ก็ขึ้นมาคล่อมผมเอาหีสวมควยผมในท่าขย่มตอ เกมส์นี้หีแม่ยังไม่โดนควยใครแหย่เลย ผมได้เย็ดหีแม่เป็นคนแรกหนังหีมันจึงฟิตมากจนผมทนไม่ไหวน้ำแตกใส่รูหีแม่ภาย ในเวลาไม่นาน แล้วแม่ก็ฟุบหน้าลงกอดกับผมหายใจรวยริน “เป็นไงจ๊ะลูก วันนี้ดีไม๊” “ดีที่สุดเลยครับ ผมรักแม่ครับ”ถึงน้ำผมจะแตกแล้วแต่ควยผมยังแข็งปั๋งอยู่ด้วยฤทธิของความ เงี่ยน พ่อผมตั้งขากล้องไว้อย่างเดิม แล้วมานอนหงายข้างๆ ส่งยิ้มให้แม่อย่างรู้ใจกัน แม่ลุกจากผมมานั่งมานั่งคล่อมควยพ่อต่อ แม่เริ่มโขยกอีกแล้ว อาชายเริ่มควยแข็งอีกรอบ อาเดินมาทางหัวพ่อเอาควยจ่อที่ปากให้แม่ดูดให้ แม่คว้ามันไว้แล้วหันมาสบตาหวานกับผมนิดนึงก่อนหันไปอมควยให้อาชาย ผมมองแม่ขย่มควยของพ่อไปพร้อมๆกับดูดควยให้อาชายแล้วมันทำให้ควยผมเริ่มปวด หนึบๆ ยิ่งพวงนมขาวๆทั้งสองข้างของแม่กระเพื่อมไหวไปตามแรงขย่มแล้วมันยิ่งปลุก กำหนัดผมยิ่งขึ้น อ้าหหห..ตูดแม่ยังว่างอยู่นี่!
