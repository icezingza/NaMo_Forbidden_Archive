จนต่างคนมีครอบครัวกัน แต่ถึงวันหยุดที่ไรต้องนัดกันไป เที่ยวที่ต่างๆ เป็นประจำโดยมีครั้งนึ่งเราไปเที่ยวกันที่พัทยา เช่าบังกะโลแบบ 4 ห้องนอน 1 ห้อง โถง มาถึงวันแรกเราก็ให้ลูกๆๆ เราเล่นกันตามสบายทุกคนเล่นทะเล เรา 2 คู่ก็นั่งเตรียมของกิน กันแล้วเราก็นั่งเล่นไพ่ ตามสบายเราจนค่ำ เราก็นั่งกินเหล้าแล้วคุยกันมาเลิกกันตอนตี 2 กว่าจะไล่ ทุกคนนอนกันได้ ผมก็เล่นจนมึน พอเช้าลูกๆๆ ขอเข้าไปที่ห้างในเมืองพัทยา แต่ผมบอกว่าผมยังมึนไม่หายเลย เพื่อน ผมเลยอาสาพาลูกๆๆ เราไปเอง โดยมีเมียผมบอกจะไปซื้อของกินมาเพิ่มส่วนเมียเพื่อนผมบอกนั้น เขาอยู่เคลียของที่บ้านพักเอง พอทุกคนออกไปหมดผมก้เข้าห้องนอนต่อ ผมหลับไปนานพอมารู้สึกตัวมี คนมานอนข้างๆ ผม พอดูอ้าวเป็นเมียเพื่อนผมเอง ผมคิดว่าเขาคงกลัวที่อยู่ห้องคนเดียวเลยมานอน ข้างผม แต่พักเดียวมีมือมาจับที่ควยผม ผมเลยหันไปกอดเขาแล้วถามว่ามันไม่ดีนะแต่เขากลับถามผม ว่าไม่สนใจเขาหรือ ผมนิ่งไปพักแล้วเขาก็พูดต่อว่าเขาเคยเห็นผมแอบเอากางเกงในเขาที่ใส่แล้ว ไปดม แสดงว่าผมแอบชอบเขามันก็จริงผมเลยจูบเขาแล้วเราก็ถอดเสื้อผ้ากันแบบไม่รู้เลยว่ามันหลุด ออกไปหมดตอนไหน ผมตื่นเต้นมากดูดนมเขาแล้วเขามาดูดมาอมควยผม แล้วเขาก็หันหีมาทางหน้าผม แต่ผมไม่เคยเลียหีให้ใครมาก่อน เขาก็บอกให้ผมเลียหีให้เขาดู ด้วยความอยากผมเลยลองทำดูอย่างที่ใจอยากมานานแล้ว มีความรู้สึกเค็มๆ แปลกๆ ดีผมเลย เลียสะเต็มที่โดยเล่นท่า 69 เย็ดปากเขาจนน้ำแตกคาปากทั้งเขาและผม พอได้พักอีกสักครู่เดียวไม่รู้ ผมไปมีเรี่ยวแรงจากไหนมา ควยผมแข็งอีก ที่นี้ผมเสียบหีเมียเพื่อนผมทันที่ เราสอยกันนานมาก เปลี่ยนท่าใหม่ตลอดโดยมีเขาคอยบอก แสดงว่าไอ้เพื่อนผมมันชอบเล่นท่ามาก เพราะดูเขาชำนาญ มากในแต่ละท่า โดยสุดท้ายเขายอมให้ผมเสียบรูตูด ทั้งที่เมียผมไม่เคยยอมเลย ผมเล่นแบบเต็มที่จน แตกในรูตูด แล้วเราก็ต่างคนต่างแยกกันก่อนที่เพื่อนผม+เมียผม+ลูกๆๆ จะกลับมา โดยเมียเพื่อนผม เขาบอกว่าต้องสัญญาว่าผมจะต้องไม่เที่ยวพวกอาบอบนวดและไปเที่ยวผู้หญิงอื่น แล้วเขาจะให้ผมเย็ด อีกเขากลัวเป็นโรค และห้ามนัดเขาออกมาเย็ดกัน ให้คือตอนเรามาเที่ยวด้วยกันเท่านั้น ผมเลยต้อง
