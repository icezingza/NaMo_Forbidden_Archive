ลูกเลียหีแม่ลึก ๆ เลยแม่ชอบ” ผมจัดการทั้งดูดทั้งเลียหีแม่จนน้ำหีแม่ออกมาจนแฉะปากรูหีเต็มไปหมด ผมเลียหีแม่และก็กินน้ำหีแม่ไปด้วย แม่ร้องครวญครางตลอดเวลาพร้อมเอามือกดหัวผมให้อัดกับโหนกหีของแม่อยู่ไปมา บางครั้งกดซะจนผมแทบหายใจไม่ออก “ลูกแม่เลียหีเก่งดีจัง อูยส์ มันเสียวอะไรอย่างนี้ลูกแม่ ลูกจ๋าแม่เสียวหีอยากโดนควยลูกเย็ดจังเลย ลูกช่วยเอาควย็ดหีแม่ทีลูก แม่อยากโดนควยลูกเย็ดจังเลย เร็วลูกแม่” ผมอยากเห็นแม่ตอนมีอารมณ์จัด ๆ จะเป็นอย่างไร ผมจึงดูดเลียหีแม่อย่างหนักต่อไป “โอว ลูกจ๋าอย่าทรมานแม่เลย แม่อยากโดนควย เร็วเย็ดหีแม่ที จะทรมานแม่ไปถึงไหน” แม่เห็นผมยังก้มหน้าก้มตาเลียหีอยู่ไม่ยอมเย็ดซักที ” แม่ทนไม่ไหวแล้ว” ว่าแล้วแม่ลุกขึ้นผลักให้ผมนอนลง จัดการขึ้นคล่อมเอาควยจ่อหีแล้วค่อย ๆกดหีลงมาช้า ๆ หีแม่ยังคงคับแน่นกว่าสาว ๆ บางคนที่ผมเคยผ่านมาเสียอีกคงไม่ได้โดนควยมานาน “โอ ควยลูกทำไมมันใหญ่จัง คับตึงหีแม่ไปหมดแล้ว” แม่ค่อย ๆ อัดหีมาจนมิดแล้วชักออกช้า ๆ ในตอนแรก และค่อย ๆ เร็ว ขึ้น เร็วขึ้น “อูย.ทำไมมันเสียวหีดีอย่างนี้ ครั้งสุดท้ายแม่อัดบดหีแม่กับควยผมจนแน่นพร้อมกับรูหีแม่ขมิบบีบรัดควยผมอย่างรุนแรงจนผมพ่นน้ำควย ใส่รูหีจนน้ำออกมาเต็มรูหีแม่เลย แม่จูบปากผมสักพัก “ลูกแม่เก่งจังเลย แม่ไม่เคยเสียวสุด ๆอย่างนี้มานานแล้ว วันนี้แม่มีความสุขที่สุดเลย ลูกแม่เก่งจัง” แล้วแม่ก็นอนกอดผมจนเช้า แม่เอามือปลุกจนผมมีอารมณ์ขึ้นมาอีก “เมื่อคืนลูกเอาเปรียบแม่ให้แม่ทำให้ เช้านี้ลูกต้องทำให้แม่บ้างจะได้ไม่เอาเปรียบกัน” “เป็นไงหนักไปหน่อยหรือไงตื่นซะสายโด่งเชียว” หลังจากนั้นเราก็สั่งอาหารเช้ามาทานกัน ทานกันไปแม่กับน้าจูน น้าอ้อก็คุยแซวกันไปมาสองแง่สองง่ามตลอดเวลา บางครั้งผมฟังแล้วก็อดเสียวไม่ได้ ตอนหนึ่งน้าจูนก็หันมาถามผมว่า “ต้น น้าอ้อ ชมเหลือเกินนะว่าเก่งเหลือเกิน มาลองประชันกันหน่อยดีไหม” ว่าแล้วน้าจูนก็หันไปมองทางแม่กับน้าอ้อแล้วถามว่า “ว่าไงดีไหม” แล้ว่าแล้วน้าจูนก็เดินมานั่งที่ข้าง น้าอ้อไม่ยอมน้อยหน้าดึงผมไปจูบปากเหมือนกัน เราสองคู่ต่างกอดจูบลูบคลำกันสักพัก มีคนมาเดินเล่นแถวใกล้ที่พักเราจึงหลบกันเข้าไปในห้อง คราวนี้เราปล่อยอารมณ์กันเต็มที่เลย
