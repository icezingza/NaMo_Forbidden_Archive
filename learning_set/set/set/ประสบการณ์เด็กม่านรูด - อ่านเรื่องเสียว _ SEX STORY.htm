แอบดูคนเย็ดกัน เรื่องของผมเกิดขึ้นเมื่อผมมาอยู่ที่บ้านของลุงกับป้าที่อยู่กรุงเทพฯ ผมเป็นคนต่างจังหวัด อยู่ ที่นครสวรรค์ มาทำงานที่กรุงเทพฯ เป็นพนักงานอยู่ที่โรงแรมม่านรูดแห่งหนึ่งย่านบางพลัด ธนบุรีครับ ผมอยู่ที่บ้านของลุงก็ช่วยงานบ้านเป็นค่าตอบแทนไปในตัว ผมเป็นคนที่อยู่ว่างๆ ไม่เป็นเลยต้องหางาน ทำอยู่เรื่อย ที่ข้างบ้านของลุงนั้นมีครอบครัวที่อยู่ติดกันเพียงรั้วกั้นเท่านั้นเอง ผู้ชายชื่อพี่ชัย ส่วนผู้หญิงนั้นชื่อพี่พิม คนที่จะเป็นนางเอกของเรื่องนี้ล่ะครับ เธออายุแก่กว่าผมประมาณ 8 ปี ผมตอนนั้น 19 ปี เธอก็ ประมาณ 27 เห็นจะได้ พี่พิมเป็นคนสวยไม่เบาเลย พี่พิมกับพี่ชัยทำงานกันคนละที่ ทั้งสองมีรถขับกัน คนละคัน พี่ชัยนั้นดูจะเป็นคนธรรมะธรรมโมสักหน่อย เพราะผมเห็นแกส่องพระอยู่เรื่อยๆ ส่วนพี่พิมนั้น ก็เป็นคนที่ชอบแต่งตัวอยู่ไม่น้อยเลย ตั้งแต่ผมมาอยู่ที่บ้านลุงก็ได้รู้จักกับพี่พิมและสนิทสนมกับครอบครัวของเธอจนรู้ว่า นิสัยใจคอของทั้งสอง นั้นเป็นอย่างไร และพี่พิมเองก็มักจะจ้างผมให้ตัดหญ้าหรือรดน้ำต้นไม้อยู่บ่อยๆ และที่เป็นประจำก็คือ ให้ผมล้างรถของเธอ และเธอก็ให้เงินผมครั้งละ 50 บาททุกๆ สองหรือสามวัน และในวันหนึ่งผมก็ โดนพี่พิมเรียกให้ไปช่วยล้างรถให้กับเธอ ส่วนของพี่ชัยแกล้างของแกเองครับ ผมไม่ได้แอ้มเงินของ แกหรอก เย็นวันนั้นผมว่างอยู่พอดี และจะเข้าเวรที่โรงแรมสองทุ่ม เรื่องที่ผมทำงานที่โรงแรมนั้นพี่ พิมไม่รู้หรอก และโรงแรมนั้นก็อยู่ห่างจากปากซอยทางเข้าบ้านไม่เท่าไรนักแค่ดินไปก็ถึงแล้ว พอโดนเรียกให้ไปล้างรถเท่านั้นเองผมก็ดีใจเพราะจะได้เงินพิเศษ เหมือนอย่างเคย และไม่เคย พลาดสักครั้ง พอผมเข้าไปที่บ้านของพี่พิม พี่พิมก็ส่งกุญแจรถให้ผมจัดการล้างรถทันที ผมก็เปิดรถเพื่อที่ จะเช็ดล้างและดูดฝุ่นข้างในเสียก่อนแล้วค่อยล้างข้างนอก ทันทีที่ผมก้มลงไปดึงผ้ายางที่รองเท้าขึ้น เพื่อจะดูดฝุ่นเท่านั้นเองก็เห็น กางเกงในของผู้หญิงถอดขยุ้มกองอยู่ที่พื้นรถ ผมหยิบขึ้นมาดูก็เห็นรอย ด่างเปียกอยู่ตรงเป้ากางเกง เป็นหยดนำเหนียวๆ ที่ยังไม่แห้ง จะมีบางส่วนที่เป็นขอบๆ เท่านั้นเอง ที่แห้ง เพื่อให้รู้ว่าเป็นน้ำอะไร ซึ่งจริงๆ แล้วผมคิดว่ามันต้องเป็นน้ำเสียว ของพี่พิมอยู่แล้วที่เปียกอยู่ เพราะรถของเธอจะเป็นกางเกงในของใครมาหล่นอยู่ นอกจากของเธอเท่านั้นที่ถอดออกมานั่นเอง ผมน่ะเห็นน้ำอย่างนี้ที่ ผ้าปูที่นอนในโรงแรมมาแล้ว เห็นครั้งแรกก็มั่นใจอยู่แล้ว แต่ที่ต้องการดมดู เพราะใจมันอยากจะรู้ว่ากลิ่นของเธอนั้นมันประทับใจขนาดไหน และผมก็ไม่ผิดหวังเลย กลิ่นน้ำเสียว ของเธอออกจะคาวอ่อนๆ ที่เป็นธรรมชาติจนผมเกิดอารมณ์ ขึ้นมา เมื่อมองเข้าไปในบ้านและเห็นเธอเดินไปมาอยู่ผมคิดไกลว่าได้เลียหอย ของพี่พิม เอาดื้อๆ เมื่อผมเอาปลายลิ้นมาเลียที่กางเกงในของเธอเพราะอยากจะชิมรสจนกางเกงในมัน เปียกชื้นขึ้นมาอีกหนหนึ่ง ของผมมันดันกางเกงขึ้นมาอย่างผิดปกติเลยเชียวในตอนนั้น ผมเอากางเกงในใส่กระเป๋ากางเกงเอาไว้และเริ่มล้างรถด้วยใจที่ไม่ค่อยปกตินัก จนเสร็จแล้วผมก็ต้องเอากางเกงในพี่พิมวางไว้ตรงที่เดิม เพราะคิดว่าเธอจะต้องกลับมาเอามันไปอย่างแน่นอน ในระหว่างที่ผมเอาเครื่องดูดฝุ่นเข้าไปเก็บที่ในบ้านนั้นเอง พี่พิมก็เดินมาที่รถและหยิบกางเกงใน กำใส่มือเดินกลับเข้ามาในบ้าน พอดีช่วงนั้นมีโทรศัพท์ดังขึ้นผมเลยรับหูมีเสียงผู้ชายถามว่าผมเป็นใคร ผมเลยบอกว่าผมเป็นน้องชาย เขาขอพูดกับพี่พิม ผมเลยเรียกพี่พิมให้มารับสาย เธอมองหน้าผมแล้ว ยิ้มก่อนที่จะรับโทรศัพท์ไปพูดอย่างเบาที่สุดจนผมที่ยืน เก็บสายไฟอยู่ข้างๆ แทบไม่ได้ยินเสียงเลย พอ พูดเสร็จเธอก็หันมาพูดกับผมว่าช่วยบอกพี่ชัยด้วยว่าเธอจะไปธุระกับเพื่อน คงดึกๆ จะกลับ ในตอนนั้น พี่ชัยอยู่ที่บ้านลุงเพราะส่องพระกันอยู่เป็นประจำตอนเย็นนั่นเอง ผมยังสงสัยว่าพี่พิมทำอะไรกับตัวเองหรือเปล่า ทำไมกางเกงในของเธอถึงได้แฉะออกมาอย่าง มากมายอย่างนั้น หรือเธอเย่อกับใครแล้วเอากางเกงในเช็ดแทนกระดาษ หรือว่าเธอจะเย่อกับใคร ในรถ ผมคิดฟุ้งซ่านจนกลับมาบ้านและเข้าห้องน้ำชักว่าว ไปเสียหนึ่งครั้งเพราะ อารมณ์มันค้างตั้งแต่ได้กลิ่นน้ำหอย ของพี่พิมแล้ว พอแต่งตัวเสร็จผมก็เตรียมออกไปทำงานที่โรงแรม แต่ในระหว่างที่ผมกำลังจะออกจากรั้วบ้านนั้นผมเห็นพี่พิมเดินตัวปลิวออกล่วง หน้าไปก่อน ผมเลยเดินตามไปแต่ห่างกันมาก ผมเห็นพี่พิมขึ้นรถเก๋งคันหนึ่งที่จอดรออยู่ ผมเห็น กท.ชัดเจน แต่ก็ไม่ได้คิดอะไรเพราะคิดว่าเป็นเพื่อนของเธอมารับ ผมเข้ามาลง ชื่อทำงานที่โรงแรมก็เข้าประจำหน้าที่ คือรูดม่านตามหน้าห้อง พอไปถึงเพื่อนมันก็บอก ว่ามีเหยื่อรายใหม่มาให้ดูอีกแล้ว คนนี้สวยสะบัดเลย ผมก็เดินไปที่หน้าห้องเห็นรถสีเดียวคันเดียวกับที่ รับพี่พิมจอดอยู่ผมรู้ ทันทีว่าพี่พิมจะต้องโดนพาเข้าโรงแรมอย่างแน่นอนผมเลยบอกเพื่อนว่า “เฮ้ย…คนนี้ขอดูเดี่ยวๆ หน่อยนะโว้ย” ไอ้เพื่อนมันก็ให้ดู เพราะมันเองก็มีห้องอื่นดูอยู่เหมือนกัน ผม เอากุญแจสำรองมาไขห้องข้างๆ ทันที เรารู้กันอยู่แล้วว่าถ้าห้องไหนมีการแอบดูกันก็จะให้แขกที่เข้า มาใหม่ไปเข้าห้องอื่น การดูของเราก็ไม่ยากเพราะแต่ละห้องนั้นเราทำที่เอาไว้ อย่างแยบยลอยู่แล้ว แขกที่เข้าไปไม่มีทางรู้อย่างแน่นอน พอผมเข้าห้องได้ก็ใจเต้นตึกตักเพราะรู้อยู่แล้วว่าเหยื่อที่ผมจะ แอบดูนั้น เป็นใคร ผมแนบสายตาเข้าไปที่ช่องแอบดูเท่านั้นเองก็ถึงกับตัวชาเมื่อเห็นพี่พิมกำลัง นอนหงายอยู่บนเตียงโดยมีชายหนุ่มคนหนึ่งกำลังก้มหน้าก้มตาดูดเลียที่เต้านม ของพี่พิมที่ขาวสวยเต่งตึงไปทั้งสองเต้า เธอแอ่นอกให้ไอ้หนุ่มมันดูดและขยำมือไปทั้งสองข้างอย่างเมามัน เธอเอามือลูบไล้ไปตามหัวไหล่และ แผ่นหลัง จิกนิ้วเกร็ง หลับตาพริ้ม ส่ายนมไปมาให้ไอ้หนุ่มนั้นดูดเลียอย่างเต็มที่ ผมเองไม่ได้ดูเพียง อย่างเดียว ไอ้จรวดผมมันแข็งจนแทบอยากจะงัดเอาออกมาชักเสียให้ได้เลย แต่ก็คิดได้ว่าหาก เพื่อนมันเข้ามาต้องอายมันแน่ๆ เลย ผมได้แต่ดูด้วยใจมราระทึกไม่น้อย ยิ่งตอนที่ไอ้หนุ่มคนนั้นมันถ่าง ขาพี่พิมออกแล้วก้มหน้าลงแลบลิ้นที่หอยตัวใหญ่ของพี่พิมจนเธอดิ้นบิดส่ายตัวไปมายังกับไส้เดือนโดนขี้ เถ้ายังไงยังงั้นเลย ผมเห็นหม้อของเธอไม่ถนัดนัก แต่ก็พอจะเห็นได้ว่ามันโหนกใหญ่ไม่น้อยเลย ขนก็ ดกมากเสียด้วย อย่างนี้คงจะจริงที่เขาว่าผู้หญิงขนดกๆ นั้นเซ็กส์จัด พี่พิมเองก็เซ็กส์จัด ไม่น้อยเลย ระหว่างที่โดนเลียอยู่นั้นเธอเอามือดึงกดหัวของไอ้หนุ่มคนนั้นติดกับหม้อของ เธอจนกระทั่งตัวเกร็ง กระตุก ผมรู้ทันทีว่าเธอนั้นถึงสวรรค์ไปแล้วหนึ่งครั้งอย่างแน่นอน ไม่งั้นเธอไม่นอนแผ่หอบหายใจจน ตัวโยน เต้านมกระเพื่อมรุนแรงเป็นแน่ ต่อจากนั้นไอ้หนุ่มมันก็จับขาของเธอยกขึ้นพาดบ่า จับจรวดยัด ใส่แล้วขยับเอวซอย จากค่อยๆ ทำจนกระทั่งเร็วจี๋ ผมไม่ได้ยินเสียงของพี่พิมครางหรอกเพราะเพลง ในห้องถูกเปิดจนดังลั่นไปหมด เห็นแค่เพียงตัวของเธอเกร็งกระตุกไปมาก็รู้ว่าเธอนั้นเสียวซ่าน ขนาดไหน ไม่ถึงสิบนาทีไอ้หนุ่มคนนั้นก็ดึงจรวดออกมาฉีดน้ำราดที่หน้าท้องของเธอ ผมไม่เห็นว่าของไอ้นั่นมันยาวใหญ่ขนาดไหน เพราะเห็นทางด้านหลังในตอนที่ทำ พอเสร็จเล้วทั้งคู่ก็พากันเข้าไปในห้องน้ำ ผมเองก็เข้าห้องน้ำจัดการรูดเสียเสร็จไปครั้งหนึ่งหลังจาก ล็อคห้องเรียบร้อยแล้ว พอออกมาก็ขึ้นไปแอบดูต่ออีก ในตอนนี้เห็นเลยว่าของไอ้นั่นมันยาวขนาดไหน ขนาดของมันยาว แต่ไม่ใหญ่เท่าของผม ความยาวดูจะไม่แพ้กันเท่าไหร่หรอก ผมคิดในใจว่าถ้าผมได้ เย่อกับพี่พิมคงจะมันไม่น้อยเพราะเห็นโคกของเธอชัดเจน ในตอนที่เธอนอนแผ่หรากลางเตียงก่อนที่ จะลุกไปห้องน้ำ และกลับมาคราวนี้พี่พิมเป็นคนอยู่ข้างบนก้มหน้าลงดูดจรวดของไอ้หนุ่มนั่นจน แข็งโด่ ขึ้นมาอีกครั้ง เธอเป็นคนขึ้นขย่มจนเต้านมกระเพื่อมขึ้นๆ ลงๆ นานพอดูกว่าเธอจะเกร็งกระตุกด้วย ความเสียวสุดยอดแล้วฟุบหน้าลงหาไอ้หนุ่ม ก่อนที่มันจะลุกขึ้นมาจับให้พี่พิมคลานแล้วมันจัดการซอยทาง ข้างหลัง และขยับที่ขอบเตียงอีกท่าหนึ่งจนเสร็จ ผมออกมาข้างนอกห้องเพราะคิด ว่าทั้งคู่คงไม่ต่อกันอีกอย่างแน่นอน เพื่อนผมมันถามว่ามันส์ไหมวะ ผมก็พยักหน้าบอกกับมัน โดยไม่บอกมันว่าเป็นคนที่ผมรู้จัก ผมบอกให้มันไปรูดม่านแทนในตอนที่ทั้งคู่ออก มาที่หน้าห้อง แต่พอดีเพื่อนมันวิ่งไปอีกทางเพราะมีแขกเข้ามาใหม่ ผมเลยต้องเข้าไปทำหน้าที่เอง พอผมเปิดม่านออกเท่านั้นเอง พี่พิมก็เห็นผม เธอตกใจมาก แต่ไม่ได้แสดงอาการอะไร เธอเข้าไป ในรถและรถก็ขับออกไปโดยเธอยังหันหน้ามามองผมอีกครั้ง วันรุ่งขึ้นเธอไม่ได้ไปทำงานเพราะเป็นวันหยุด พี่ชัยกับลุงของผมไปส่องพระกันที่ท่าพระจันทร์ ผมนอน ในเจ็ดวันต้องมีครั้งหรือสองครั้งอย่างน้อยที่โดนแม่หม้าย หมอนวด พาไปเล่นเสียว พี่ผมโกหกกับพี่พิมก็ไม่ต้องการให้เธอรู้ว่าผมนั้นเป็นขนาดไหน
