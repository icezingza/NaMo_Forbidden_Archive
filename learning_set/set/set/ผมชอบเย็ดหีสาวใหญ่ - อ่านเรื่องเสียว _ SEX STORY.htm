นี่หมายความว่าครูคนนี้ชอบเย็ดกับเด็กผู้ชายแน่ๆ ผมคิด แกพูดไม่ทันขาดคำ ก็อ้าปากอมควย ผมทันที ก่อนที่จะดูดดุนควยของผม อย่างหิวกระหาย เสียงดูดควยดังลั่นห้อง แกหลับตาแน่น ดูดควยผมจนแก้มตอบ
