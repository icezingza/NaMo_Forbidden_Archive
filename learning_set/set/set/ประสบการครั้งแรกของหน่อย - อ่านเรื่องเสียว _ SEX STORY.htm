หน่อยก็ด่ามันกลับไปตามเคย พวกมันหัวเราะชอบใจ กันใหญ่เมื่อเห็นหน่อยโมโหใส่ “หน่อยจ๋ากลับมาเหนื่อยๆให้พี่โต้งไปเดินขึ้นไปส่งไหมจ่ะ” ไอ้โต้งแซว หน่อย “มีงเก็บแรงไว้เตะบอลมีเถอะไอ้โต้ง แรงจะเดินมึงก็จะไม่มีแล้ว” หน่อยก็ด่ามันไป “ถึงแรง เดินโต้งจะไม่มีแต่แรงทำอย่างอื่นโต้งมีนะ” มันเริ่มทะลึ่งกับหน่อยค่ะ “มึงหลอจะมีแรงทำอะไรกูไอ้ โต้ง กล้าก็เอาดิว่ะ” หน่อยท้ามันไปเพราะรู้ว่ามันไม่กล้า แล้วก็เดินขึ้นห้องไป พวกมันก็แซวตามหลัง มาตลอด พอมาถึงห้องหน่อยเหนือ่นมากแต่ก้ร้อนก็เลยจะอาบน้ำก่อนนอนดูโทรทัศน์ตามปกติ หน่อยก็นั่ง ชักโคกฉี่ก่อนเลยค่ะค่ะอั้นมาตั้งแต่ตลาดแล้ว มองดูของตัวเองมันก็ใหญ่ดีนะค่ะ อูมมากๆ เลยค่ะหมอย ก็ดกดำมาก หน่อยภูมิใจกับมันมากเลยค่ะไม่เคยได้ให้ชายคนไหนได้มาทำร้ายมันเลยค่ะ นี่ก็ม.4แล้ว มีแฟนก็หลายคนแต่ไม่เคยได้เสียตัว สักทีเลยค่ะ หน่อยตกใจมากทำ อะไรไม่ถูกยืนอึ้งเลยค่ะ มีเพียงขันอยู่ในมือ ยืนให้ไอ้โต้งมันดูอย่างเต็มตาทุกสัดส่วนเลยค่ะ มันกระโจนเข้ามาเลยค่ะเข้ามากอดหน่อย “อย่าดิ้นนะหน่อย โต้งขอทีนะ” มันเข้ามากอดหน่อย โต้งจับข้อมือทั้งสองข้างของหน่อยค่ะ หน่อยก็พยายามใช้ขาเตะโต้งแต่ไม่ได้แรงไรมากหลอกค่ะพื้นก็ ลื่นแถมเป้นแรงผู้หญิงอีก แต่โต้งสิค่ะแทง เข่ามาที่ท้องหน่อยเลยค่ะ จุกมาก ฟุบลงกับพื้นเลยค่ะ ส่วน โต้งก็ถอดกางเกงของเขาออกค่ะ ตอนนี้ควย โต้งมันชี้โด่อยู่ตรงหน้าหน่อยห่างนิดเดียว เองค่ะ มันทั้งใหญ่ทั้งยาวเลย โต้งจับหน่อยยืนขึ้นค่ะหน่อยก็ไม่มีแรงจะฝืนได้แต่กุมท้องตัวงอเลย
