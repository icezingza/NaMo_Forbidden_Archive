เรื่องเสียวแนว ครอบครัว "พี่สาวกับน้องชาย...ความใกล้ชิดที่เงี่ยนจนหยุดไม่อยู่" บ้านไม้สองชั้นที่ดูเหมือนธรรมดาในสายตาคนอื่น กลับเต็มไปด้วยความลับที่ไม่ควรเปิดเผย เรา—น้อง ชายวัย 19 ปี—พักอยู่กับพี่สาว “พี่มินท์” อายุ 25 ปี สวยสะบัด ผิวขาวนวล หุ่นเอ็กซ์ หน้าอกใหญ่ พอดีมือ ก้นกลมกลึง พี่มินท์เรียนจบแล้วทำงานบริษัท กลับบ้านดึกทุกวัน แต่เวลาอยู่บ้าน เธอชอบ แต่งตัวสบายๆ เสื้อกล้ามบาง กางเกงขาสั้นจู๋จนเห็นกางเกงในลายลูกไม้ ภาพแบบนั้นทำให้ควยเราลุกแข็งแทบทุกครั้งที่เห็น แต่ต้องเก็บอารมณ์ไว้ในใจ...จนกว่าจะถึงคืนที่ฝน ตกหนักคืนนั้น "เสียงฝนกลบ แต่เสียงครางไม่กลบ" ฝนซัดกระจกห้องนั่งเล่นดังสนั่น เรานั่งเล่นเกมอยู่บนโซฟา พี่มินท์เพิ่งอาบน้ำเสร็จ เธอสวมเพียง เสื้อคลุมอาบน้ำสีขาวบางๆ ผมยาวยังเปียกชื้น หยดน้ำเกาะไหล่ เธอนั่งข้างเรา ยกขาขึ้นพาดโต๊ะ ทำให้ผ้าคลุมแง้มเผยเรียวขาอ่อนและขอบกางเกงในสีดำ “เล่นเกมทั้งคืนไม่เบื่อเหรอ” พี่มินท์ถามยิ้มๆ เราตอบไปตาไม่ละจากขาเธอ “ไม่เบื่อ...แต่เห็นพี่ แต่งตัวแบบนี้...คงไม่อยากเล่นแล้ว” เธอหัวเราะ “หื่นเหมือนพ่อเลยนะ” แต่สายตาไม่ได้ปฏิเสธ กลับมองเราด้วยแววตาแปลกๆ คล้ายยั่ว "อย่าพูดว่าผิด ถ้าใจพี่ก็อยาก" เราลุกขึ้นใกล้ เธอไม่ได้ถอยหนี กลับยกแก้วไวน์ขึ้นจิบแล้วเอียงหัว “อยากทำอะไรก็ลองดูสิ” คำท้าทายนั้นเหมือนจุดไฟเงี่ยน เราโน้มไปจูบปากเธอทันที รสไวน์ผสมลมหายใจทำให้ใจเต้นแรง เธอครางในลำคอเบาๆ มือโอบรอบคอเราแทนที่จะผลักออก เสื้อคลุมถูกปลดออกเผยเรือนร่างขาวโพลน นมใหญ่เด้ง หัวนมชมพูแข็งสู้ตา หีโหนกขาวเปียกชุ่มน้ำ เงี่ยนที่ไหลออกมาตั้งแต่เมื่อไหร่ไม่รู้ "หีพี่ตอดแค่นิ้ว...แล้วถ้าเจอควยล่ะ" เราลูบไล้ปลายนิ้วลงไป นิ้วกลางกดเข้าร่องหี น้ำแฉะไหลออกมาติดนิ้วทันที “อ๊ะะะ...น้อง...อย่า แกล้งพี่” แต่ปากเธอกลับครางเสียว มือจิกโซฟาแน่น เราซอยนิ้วแรงขึ้น หีเธอตอดรัดจนเสียงน้ำดังแจะะๆ เธอครางดัง “โอ๊ยยย...เสียวหี!” เราก้มลงเลียหีทันที ลิ้นตวัดที่เม็ดเสียว ดูดแรงๆ เสียงช็วบๆ ดังไปทั่วห้อง พี่มินท์กดหัวเราแน่น “เลียหีพี่แรงๆ อย่าหยุด!” "ควยน้องพร้อมเย็ดหีพี่แล้ว" เราถอดกางเกง ควยแข็งโป๊ก หัวบานแดงเปียกน้ำเงี่ยน เราขึ้นคร่อมพี่มินท์ จ่อควยเข้าร่องหีที่ฉ่ำ รออยู่แล้ว ดันทีเดียวมิดลำ “โอ๊ยยย! แน่นหี!” เธอร้องดัง ร่างกระตุก เรากระแทกถี่ๆ จนเสียงตั๊บๆ ดังสนั่น หีเธอตอดรัดควยแน่น น้ำเงี่ยนไหลเลอะต้นขา พี่มินท์กอด เอวเราคราง “เย็ดแรงๆ อย่าหยุด!” "ยิ่งเสี่ยงยิ่งเสียว" เสียงฝนข้างนอกกลบเสียงครางในบ้าน เรากระแทกแรงขึ้นๆ เธอกัดฟันครางลั่น “อ๊าาาา! แตกใน เลย! พี่อยากได้!” เรากดควยลึกสุดโคน กระตุกปล่อยน้ำควยอุ่นๆ แตกในหีเธอเต็มๆ น้ำไหลทะลักออกมาเปื้อนโซฟา เธอเสร็จตาม ตัวเกร็งสะท้าน "นี่คือความลับของเรา...พี่สาวกับน้องชาย" เรานอนกอดกัน หอบหายใจแรง หีเธอยังตอดควยที่คาอยู่ พี่มินท์จูบเราเบาๆ กระซิบ “อย่าบอกใคร ...แต่คืนนี้พี่อยากอีก” เรายิ้มร่าน รู้แล้วว่าความสัมพันธ์พี่น้องนี้จะไม่กลับไปเหมือนเดิมอีกต่อไป เพราะไฟราคะมันลุกโชน เกินหยุดได้แล้ว Share: // // // ส่งอีเมลข้อมูลนี้ BlogThis! แชร์ไปยัง X แชร์ไปที่ Facebook บทความใหม่กว่า
