ดูท่าทางเหมือนเพื่อนมันจะบอกให้จอดรับกู ไปที่ปากซอยด้วยมันชะลอรถลง กูก็ดีใจนึกว่าจะไม่ต้องเดินตากฝน อีฝนกดกระจกลงนิดนึง มองดูกูที่ ตัวเปียกซกไปทั้งตัว มองแบบเหยียดๆ แล้วก็บอกว่า “โทษทีนะคะ ไหนๆ มันทำท่าทางกระวนกระวาย แล้ว บอกว่า ยางรถมันรั่ว “เอ่อ…พอจะช่วยเราหน่อยได้มั๊ย” มันทำท่าอึกอัก คงสำนึกผิดที่เคยทำกับกูไว้ กูบอกไปว่า “เราก็เปลี่ยนยางรถไม่เป็น… เอางี้ขึ้นรถเราก่อนเดี๋ยวพาไปตาม ช่างมาให้” ตอนแรก มันก็ทำท่าลังเล แต่มันเย็นมากแล้วฟ้าเริ่มมืด เลยจำใจขึ้นรถกู ตอนที่มันขึ้นรถมากูได้กลิ่นสาบสาวผสมกับกลิ่นนำหอมราคาแพง กระตุ้นอารมณ์หื่นกูแบบสุดๆ มันนั่ง เงียบไม่พูดไม่จา จริงๆ กูรู้ว่ามีร้านปะยางอยู่ตรงไหน แต่กูก็แกล้วขับให้ไกลไปเรื่อยๆ จนมันเริ่มผิด สังเกต เลยถามกูว่าจะขับไปถึงไหน กูยิ้มแต่ไม่ตอบ มันเริ่มหน้าซีด แล้วขอร้องให้กูพาไปส่งที่จอดรถ เหมือนเดิม กูยังเงียบ ฝนกลัวรถเปื้อนจริงๆ….เอ…ปล่อยเราไปเถอะนะ” น้ำเสียงกูเริ่มเปลี่ยน กระด้างขึ้น “กะอีแค่รถเปื้อนแค่เนี้ยะนะ!….วันนี้ฝนมานั่งรถเรา…รถเราก็ เปื้อน!” มันลุกลี้ลุกลน “เปื้อนตรงไหน…เดี๋ยว….เดี๋ยว….ฝนทำความสะอาดให้” กูได้แต่ยิ้มเยาะ แล้วเอานิ้วชี้ลงที่ควยกำลังโด่เด่ “เปื้อนตรงนี้…อยากให้ฝนใช้ปากทำความสะอาดให้” มันหน้าซีด เผือกเลย “ปล่อยฝนเถอะ ฝนกลัวแล้ว” กูตะคอก แต่กูรู้ทันเลยถอดถุงเท้ากูเอง (เหม็น ชิบหาย) ยัดปากมันไว้ก่อน แล้วเอื้อมลงไปใต้เตียงหยิบเชือกขึ้นมา แล้วแหกขาอีฝนทั้งสองข้างออก แล้วใช้เชือกมัดแต่ละข้างกับเสาของเตียง ตอนนี้มันได้แต่หลับตาปี๋ บ่นอู้อี้ในลำคอ สภาพของคุณหนูสุด จองหองถูกมัด มีถุงเท้ายัดปาก ดิ้นไปดิ้นมาบนเตียงเป็นภาพที่น่าสยิวสำหรับกูจริงๆ กูไปควานเอากรรไกรมา ค่อยๆ ตัดกระโปรงนักศึกษา ผ่ากลางเป้าเลย จากนั้น กูก็เอากรรไกรถู ไปตามเนินหีที่มีกางเกงในยี่ห้อ victoria secret มันวาวสีขาวปกคลุมอยู่ กูค่อยๆ ใช้กรรไกร ตัดกางเกงในมันออกมา พอกางเกงในพ้นหูพ้นตากูไปแล้ว ก็เผยให้เห็นถึงหีสวยๆ ของคุณหนูที่แคมยัง เบียดชิดติดกัน
