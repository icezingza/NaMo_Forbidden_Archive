*พี่น้องบ้านนี้ควยใหญ่เสียจริง* สวัสดีค่ะผู้อ่านเรื่อง เสียวทุกคน เพราะฉันเผลอพูดออกไป เพราะฉันไม่ได้ตั้งใจ…หรือเพราะว่าลึกๆ ในใจของฉันมัน ปรารถนาเรื่องแบบนี้กันนะ เรื่องเสียวในค่ำคืนนี้จึงเกิดขึ้นมาทั้งๆ ที่มันไม่ควรจะเกิดขึ้นเลยด้วยซ้ำ “ไหนๆ ก็เป็นแฝดกันแล้ว มาเย็ดกันทีเดียวทั้งคู่เลยก็ได้ อยากลองโดนฝาแฝดเย็ดดูเหมือนกัน” ฉัน พูดออกไปด้วยความสนุกสนาน แต่ในตอนนั้นแฟนของฉันกลับเข้ามาหาฉันที่นั่งดูหนังกับพวกเขาอยู่ที่ห้อง รับแขก ก่อนที่จะคร่อมที่ร่างกายของฉันแล้วจับข้อมือทั้งสองข้างเอาไว้ยกขึ้น เขามองฉันแล้วยิ้มออกมา “ได้นะ…เราก็อยากลองดูเหมือนกัน ว่าเรากับน้องเวลารุมเย็ดมันจะหล่อเท่ขนาดไหน ?” “กล้า เหรอ ?” ฉันถามด้วยความใจดีสู้เสือ แต่แล้วทุกๆ อย่างมันก็เป็นคำตอบของฉันแล้ว เมื่อแฟนของฉัน ค่อยๆ ถอยออกไปยืนตรงหน้าฉัน ส่วนน้องชายของเขา แค่เพียงโดนพี่ชายดีดนิ้ว ชายหนุ่มสองคนที่ หน้าตาเหมือนกับราวกับแกะก็มายืนเคียงข้าง แล้วค่อยๆ ถอดกางเกงลงไป ปล่อยให้ร่างกายเปลือย เปล่าปรากฏอยู่ตรงหน้าของฉันตอนนี้ นอกจากสองคนจะหน้าตาเหมือนกันแล้ว ไม่อยากจะเชื่อว่าควยใหญ่ เหมือนกัน อีก ตอนที่ฉันพยายามที่จะหักห้ามใจ แต่ทั้งสองคนก็ก้าวเข้ามาหาฉัน เพื่อที่จะเริ่มเรื่องเสียวในค่ำคืน นี้ ฉันกลืนน้ำลายลงคออึกใหญ่ ชั่งใจอยู่เพียงครึ่งวินาทีแล้วเอื้อมมือไปจับควยของทั้งสองคนกับมือ ก่อนที่จะเริ่มบีบกำกระชับเอาไว้ให้แน่นขึ้นเรื่อยๆ ก่อนที่ควยของทั้งคู่จะเริ่มแข็งขึ้นมา ฉันเริ่มชักรูดควยทั้งสองคนพร้อมๆ กัน จนเสียงครางของเขาทั้งสองคนแว่วขึ้นมา ฝาแฝดกอดคอกัน ไว้แล้วส่งยิ้ม ในขณะที่เสียงครางเริ่มดังขึ้นมาในลำคอ และน้ำเงี่ยนใสๆ ไหลเยิ้มออกมาที่หัวควย ของทั้งคู่ ก่อนที่ฉันจะอ้าปากอมควย ให้แฟนของฉันก่อน เสียงครางของเขาดังขึ้นมาด้วยความเสียวควย ก่อนที่มือของฉันที่กำควยคนน้องเอาไว้ระเริ่มรูดชัก อย่างถี่รัวเพื่อไม่ให้อีกคนนั้นรู้สึกค้างเติ่ง วนนิ้วโป้งไปรอบๆ หัวควยของเขาไปเรื่อยๆ เพื่อกระตุ้น ความเสียวเอาไว้ ก่อนที่จะค่อยๆ หันมาดูดควย ให้เขาทั้งคู่ มันเป็น อย่างนี้อยู่หลายนาที ก่อนที่เขาจะค่อยๆ ถอนตัวเองไปแล้วให้ฉันค่อยๆ เอนกายลงไปที่โซฟาตัวนุ่มนั้น ที่ปรับเป็นเตียงได้ ร่างกายของฉันค่อยๆ ถูกเปลื้องปลดเสื้อผ้าออกอย่างเบามือ ก่อนที่จะค่อยๆ มีผู้ชายสองคนเข้ามา รุมล้อมเล้าโลมร่างกายของฉัน คนหนึ่งจูบปาก ดูดนม ไซ้คอ อีกคนหนึ่งก็เลียหีให้ฉัน คนน้องคือคนที่ เริ่มเลียหีให้ฉัน ซึ่งเขาทั้งสองคนนั้นไม่มีอะไรต่างกันเลย มันเป็นลีลาที่แสนเร้าใจ ฉันเสียวหีจน ร้องครางออกมา พร้อมกับค่อยๆ ปล่อยร่างกายให้ทั้งสองคนกระทำกันอย่างเต็มที่ แล้วในตอนนั้น คนน้องก็ค่อยๆ แทรกกายเข้ามาที่ระหว่างขาของฉัน สองขาถูกจับขึ้นไปพาดบ่าของ เขาเอาไว้ ก่อนที่จะดันควยเข้ามาในรูหีของฉันทันที ซึ่งในตอนนั้น ฉันเองแทบจะตั้งตัวไม่ทันเลย ทีเดียว มันแน่น จนรู้สึกได้เลยว่าความสุขอยู่ตรงหน้าแล้ว เขาดันควยเข้ามาจนสุดทาง เสียงคราง ดังขึ้นมาตอนที่รูหีของฉันคงตอดควยเขาอย่างหนัก แล้วเริ่มขยับร่างกายกระเด้าเย็ดหีของฉันไปตาม จังหวะ ก่อนที่มันจะเริ่มเร็วขึ้นไปเรื่อยๆ ยิ่งแรงขึ้น ฉันก็ยิ่งเสียวหี ร่างกายพยายามที่จะดีดดิ้น แต่ กลับไม่สามารถทำอะไรได้ คนน้องยิ่งส่งเสียงครางออกมาด้วยความเสียวควย ไม่ต่างกับฉัน จังหวะที่เร่งเร้าทำให้ฉันนั้นส่งเสีย งอออกมาอย่างเต็มที่ แต่กลับมีควยของแฟนฉันอุดเข้ามาในปากพอดี นั้นทำให้ฉันไม่สามารถส่งเสียง ใดๆ ออกมาได้ แล้วต้องอมควยให้เขาไปพร้อมๆ กับที่ร่างกายกำลังโดนเย็ดอย่างต่อเนื่องๆ ฉัน กำควยของเขาชักว่าว ไปพร้อมๆ กับดูดควยของเขาในจังหวะที่ไม่ค่อยเป็นตัวเองสักเท่าไหร่ แต่ก็ทำมันออกมาได้อย่างดี จนแฟนของ ฉันนั้นเริ่มทนไม่ไหว จับหัวของฉันนิ่งเอาไว้แล้วกระเด้าปากของฉัน ก่อนที่ทั้งสองพี่น้องจะมองหน้ากัน แล้วเริ่มอัดเรี่ยวแรงกระเด้าเย็ดหี และปากของฉัน ส่ง เสียงคำรามดังขึ้นในจังหวะนั้น ทุกๆ อย่างเร็วขึ้นจนฉันแทบจะหยุดหายใจ ก่อนที่สุดท้ายในจังหวะที่ฉันนั้นไม่ทันตั้งตัว ควยใหญ่ทั้งสอง ดุ้นก็อัดเข้ามาทั้งในรูหีของฉันและลำคอของฉันพร้อมๆ กัน ปลดปล่อยน้ำควยแตกในปากและแตกใน รูหีของฉันราวกับว่าทั้งสองคนนั้นกัน มา
