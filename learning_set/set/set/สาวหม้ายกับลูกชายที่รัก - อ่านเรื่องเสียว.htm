บางคนก็เป็นคลิปวิดีโอ และยังมีภาพของเด็กนักเรียนระดับมัธยมปลาย แบบชุดนักเรียนกับชุดที่ถ่ายตอนอาบน้ำในห้องน้ำ คือคนที่มีแฟนก็เอาแฟนมาแลก คนที่ไม่มีแฟนแต่อยากดูของคนอื่นก็ต้องหามาแลก บางคนเอารูปแม่ บางคนเอารูปน้องสาว หรือคนใกล้ชิดมาแลก แต่ทั้งหมด ไม่ได้เปิดเผยรูปหน้าที่ชัดเจน คือมีการอำพรางหน้าตาไว้ คือเพื่อไม่ให้รู้ว่าหน้าตาที่แท้จริงของสาวในรูปเป็นอย่างไร คุณสาเล่าให้ผมฟังแล้วถามว่า ผมเคยแลกรูปกับใครไหม และเขามีการแลกรูปแฟนกันดูแบบนี้มากไหม ผมก็ตอบว่าเท่าที่ทราบก็มีอยู่พอสมควร ผมเองก็คุยกับกลุ่มเพื่อน ๆ พวกนี้อยู่ และมีหลายคู่ส่งรูปแฟนมาให้วิจารณ์ โดยไม่จำเป็นว่าจะต้องเป็นรูปโป๊เสมอไป บางคนก็แค่ส่งรูปชุดทำงาน ชุดอยู่บ้าน ชุดเที่ยว มาให้ช่วยวิจารณ์ บางคนก็ให้แฟนตัวเองอ่านและสร้างอารมณ์ไปด้วย ซึ่งเราจะเห็นมีเพื่อน ๆ เอารูปแฟนมาโชว์ตามเว็บมากมาย และแต่ละคู่ก้อยากรู้ว่ามีใครคิดอย่างไรกับรูปของเธอบ้าง ส่วนบางคู่ก็ไม่ค่อยกล้าส่งตามเว็บ เพราะมีความกังวล และบางทีก็เป็นมือใหม่ ยังไม่ค่อยกล้ากับกลุ่มที่ใกล้ความเป็นสาธารณะมากนัก เขาก็ส่งรูปแฟนแลกกันดูแบบส่วนตัวในกลุ่ม ซึ่งคู่มือใหม่หลายคู่ก็ส่งมาให้ผมได้ดูและช่วยวิจารณ์ความเซ็กซี่ของแฟนเขาแต่ละคน คุณสาถามผมว่าแล้วผมเอารูปใครไปแลกกันดู ผมบอกว่าผมไม่ได้มีรูปสาวแลก เพื่อน ๆ จะรู้ แต่เขาอยากทราบมุมมองความงามเร้าใจของแฟนเขาในสายตาคนอื่น ๆ และเขาก็มีคู่อื่นแลกกันดูอยู่ด้วยแล้ว ซึ่งบางคู่ก็ให้ผมส่งรูปผมกลับไปให้แฟนเขาดู เพราะแฟนของบางคู่เขาบอกว่า แฟนไม่เคยเห็นท่อนควยของใครอย่างที่อยากเห็นเลย มีแต่ดูทั่ว ๆ ไปตามเว็บ บางคู่ก็ส่งรูปมาแล้วให้ผมทำบางอย่างส่งกลับไป เช่น ทำท่าเอาท่อนไปจ่อตรงก้นแฟนเขา แล้วถ่ายส่งกลับไป เป็นเรื่องที่มีอยู่แล้วไม่ใช่เรื่องใหม่ ผมก็แค่คนหนึ่งที่ได้มีส่วนช่วยความสุขให้กับคู่มือใหม่ที่ยังไม่พร้อม หรือคู่ที่ฝ่ายชายอยากลอง แต่ยังไม่แน่ใจว่าฝ่ายหญิงจะเอาด้วยหรือเปล่า ไม่กล้าบอก ไม่กล้าถาม
